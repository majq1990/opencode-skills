# 电商询价工具

## 功能说明

本skill用于国内主流电商平台商品价格查询与对比，帮助用户找到最低价格。

## 支持平台

- **京东** - JD.com、京东自营
- **天猫** - 天猫旗舰店、天猫超市
- **淘宝** - 淘宝店铺
- **拼多多** - 拼多多百亿补贴
- **其他** - 苏宁、唯品会等

## 工作流程

### 1. 解析请求

首先明确用户的询价需求：
- 商品名称/品牌/型号
- 规格参数（如尺寸、容量等）
- 是否需要特定平台
- 是否需要历史价格参考

### 2. 搜索价格

使用 `tavily_search` 或 `websearch_web_search_exa` 搜索各平台价格：

**搜索策略：**
```
搜索关键词组合：
- "{商品名} {规格} 京东 价格"
- "{商品名} {规格} 天猫 价格"
- "{商品名} {规格} 拼多多 价格"
- "{商品名} {规格} 最低价"
- "{商品名} {规格} 比价"
```

**搜索要点：**
- 搜索多个平台获取全面价格数据
- 注意区分正装和试用装
- 注意区分不同规格（片数/容量）
- 关注促销活动（百亿补贴、限时特价）

### 3. 计算单价

对每个搜索结果计算单片/单件价格：

```
单价 = 总价 / 数量

示例：
- 16片47.8元 → 单片2.99元
- 36片108.88元 → 单片3.02元
- 72片281元 → 单片3.90元
```

### 4. 价格对比

整理对比表格，按单价排序：

| 平台 | 规格 | 总价 | 单价 | 备注 |
|------|------|------|------|------|
| 京东自营 | 16片 | 47.8元 | 2.99元 | 最低正装 |
| 京东自营 | 36片 | 108.88元 | 3.02元 | - |
| 天猫旗舰店 | 4片试用 | 8.9元 | 2.225元 | 仅试用装 |

### 5. 输出报告

生成询价报告，包含：
- 商品基本信息
- 各平台价格对比表
- 最低价推荐
- 购买建议（如批量购买优惠）
- 价格趋势参考（如有历史数据）

## 特殊场景处理

### 找不到价格

如果搜索无结果：
1. 尝试更通用的搜索关键词
2. 建议用户直接访问电商平台查询
3. 提供类似商品的价格参考

### 价格变动频繁

对于价格波动大的商品：
1. 标注"价格仅供参考，以实际为准"
2. 建议使用比价平台查询历史价格
3. 推荐设置降价提醒

### 批量询价

用户需要多个商品询价时：
1. 逐个商品搜索价格
2. 生成综合比价表
3. 提供批量购买建议

## 比价平台参考

推荐用户使用以下比价工具：
- **慢慢买** (manmanbuy.com) - 历史价格查询
- **购物党** - 浏览器比价插件
- **什么值得买** (smzdm.com) - 优惠信息聚合

## 使用示例

### 示例1：单商品询价

**用户输入：** "好奇深睡大师纸尿裤L码多少钱"

**处理流程：**
1. 搜索京东、天猫、拼多多价格
2. 计算单片价格
3. 对比找出最低价
4. 输出询价报告

### 示例2：多平台比价

**用户输入：** "帮我看下iPhone 15在京东和天猫哪个便宜"

**处理流程：**
1. 分别搜索京东和天猫价格
2. 对比同规格价格
3. 推荐更低价格平台

### 示例3：找最低价

**用户输入：** "奶粉最便宜的在哪买"

**处理流程：**
1. 搜索各平台奶粉价格
2. 找出最低价格
3. 提供购买建议

## 注意事项

1. **价格时效性** - 电商价格实时变动，搜索结果仅供参考
2. **平台差异** - 注意自营与第三方店铺差异
3. **规格区分** - 同商品不同规格价格差异大
4. **促销活动** - 百亿补贴、限时特价需特别标注
5. **试用装** - 试用装价格低但数量少，需单独说明
