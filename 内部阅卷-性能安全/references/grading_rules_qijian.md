## 核心判分原则

### 1. URL 红线（考核说明原文）
> 所有涉及业务系统的截图，都必须将系统 URL 截入图中，**未截入 URL 的，默认扣掉一半分数**。

- baseline 中 `need_url:true` 的采分点：视觉细查必须判断 `has_url`。
- 若该项内容做到了（found=yes/partial）但 `has_url=false` → 得分 **×0.5**。
- `need_url:false`（纯命令行/脚本/数据库/手机端截图）不受此规则约束。

### 2. found 三档 → 基础比例
| found | 含义 | ratio |
|---|---|---|
| yes | 关键操作截图齐全，key_check 命中 | 1.0 |
| partial | 做了但不完整（缺关键步骤/统计区空/图层未勾选等） | 0.5 |
| no / missing | 未做或截图无关 | 0.0 |

最终：`awarded = round(score × ratio × (0.5 if need_url且无url else 1), 2)`

### 3. 图数基线（std_min_imgs）只作辅助信号
- 标准答卷每项图数（`std_min_imgs`）用于给视觉 agent 参考"标准答卷大概贴了几张"，**不直接按图数给分**——麒舰判分看内容是否命中 key_check，不是数图。
- 例外：某些"全流程流转"项（S10-2/S10-7），截图明显过少（只有 1 张却要求展示完整流转）应判 partial。

### 4. 新加考点无标准样本（须人工复核）
4 份标准答卷里**没有**以下截图，属新加考点，自动判分置信度低，预览时标 ⚠ 提示人工确认：
- **S2-6** 智信云地图含图层控制（勾选水井盖/街道）
- **S2-10** 玄藏地图预览含图层控制（勾选水井盖/街道）

### 5. 其它易错点
- **S3-4** 岗位权限配置需覆盖市受理员/值班长/派遣员/专业部门四类，少一类判 partial。
- **S9-5** 二级专业部门授权：考核说明要求"答复授权为一级专业部门"，部分标准答卷写法不一，以考核说明为准。
- **S10-5** 申请延期 2 小时：需在截图里看到延期时长字段，看不清判 partial。
- **重复提交**：同名多个 attempt，内容一致时视觉数据复用第一份，两份都提交（Moodle 取最高）。
