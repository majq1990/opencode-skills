# 可见性规则

目标：每条项目反馈记录只让对应人员可见。

自动化已覆盖：
- 创建 `可见人员` 成员多选字段。
- 每行写入项目经理、省份总、大区总、片区总。
- plan 中 `include_sales_manager_in_visibility=true` 时，追加项目销售经理。

当前限制：
- 现有 `dws aitable` 本地命令没有暴露行级权限/按成员字段限制可见的命令。
- 钉钉 MCP 当前也没有 AI 表格行级权限工具。

执行要求：
1. 创建表和写入记录后，必须返回 `可见人员` 字段已填充的结果。
2. 如果没有可用权限 API，不要宣称“权限已限制完成”。
3. 给用户输出一句待配置项：在钉钉 AI 表格前端或后续权限 API 中，将行级可见规则绑定到 `可见人员` 字段。
4. 若后续 `dws aitable` 增加 permission/acl 命令，再补自动配置步骤并实际验证。
