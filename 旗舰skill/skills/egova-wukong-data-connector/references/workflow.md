# 工作流参考

> 用途：说明悟空大屏数据对接 skill 的默认执行顺序和阶段门禁。`SKILL.md` 保留硬规则，本文件展开执行细节。

## 阶段状态

每次响应只能处于以下一种阶段。阶段用于内部控制，不需要在用户答复中输出 `[STAGE]`。

| 阶段 | 触发条件 | 允许输出 |
| --- | --- | --- |
| `GATE_NEG1_SCAN` | 收到用户原始数据对接需求后 | 内部粗检索，不单独输出 |
| `CANDIDATE_REVIEW` | 悟能索引命中候选接口 | 内部读取 `api_flat`、detailDoc、指标枚举，不单独输出 |
| `GATE_0_BLOCKED` | 存在会影响接口、入参、统计、返回结构、映射或脚本的阻塞缺口 | 只输出 `### 已确认`、`### 请选择`、`### 请补充` |
| `FINAL_READY` | 需求、接口资料、静态模板状态、映射策略均足够 | 只输出四段式方案 |
| `FALLBACK_BRANCH` | 悟能无可确认接口或无法满足，且需求没有阻塞口径 | 输出互斥数据源补充分支 |

## 总体顺序

1. 识别用户要展示的业务域和组件目标，例如案件、车辆、人员、部件、事件、设备；统计、排行、地图、列表、指标卡等。
2. 执行 Gate -1：基于用户原始描述粗检索 `domain_indexes/wuneng_api_index.md`，不要先要求用户补充需求。
3. 命中候选接口时，先读取 `knowledge/api_flat.md` 中对应接口摘要；如果索引提供 `detailDoc`，再读取 `knowledge/api_details/**/*.md` 中对应详情文档。
4. 如果是案件或人员指标统计、分组、排行或诊断场景，同时读取 `knowledge/record_index_metrics.md`。
5. 执行 Gate 0：只澄清会改变接口选择、入参、统计结果、返回结构、字段映射或脚本写法的阻塞项。
6. 确认悟空组件静态数据模板状态：有现场模板则以现场模板为准；无模板时才推荐 `result` 格式。
7. 需求和接口资料足够时，输出结论、映射、过滤脚本、需要核对的内容；最后一段只列需要核对的内容，不作为继续索要阻塞信息的入口。
8. 悟能不能满足时，按现场已有接口、已有表/查询逻辑、无明确数据源三种状态之一走 fallback。

## Gate -1：先粗检索悟能接口

- 组件类型未明确、未直接提供静态数据模板、筛选条件未说明，都不阻止粗检索。
- 粗检索只用于发现候选，不等于最终推荐。
- 当前索引没有命中某业务时，只能说“当前索引未找到可确认接口”。
- 不要因为车辆示例多，就把车辆接口套用到其他业务域。
- 用户已直接提供接口返回样例时，可以跳过悟能粗检索，但仍要识别目标 `result` 格式、字段映射和过滤脚本。

## Candidate Review：候选接口复核

命中候选接口后按以下顺序复核：

1. 先用 `domain_indexes/wuneng_api_index.md` 确认业务域、对象、接口类型、场景、关键词、适配组件是否匹配。
2. 再读 `knowledge/api_flat.md`，快速确认方法、接口地址、星桥路径、result 形状、关键字段、阻塞项和风险。
3. 若索引行存在 `detailDoc`，读取详情文档确认请求包装结构、请求示例、返回字段、返回示例和转换建议。
4. 若是案件/人员动态指标，读取 `knowledge/record_index_metrics.md` 确认 `groupList`、展示名和底层字段。
5. 若候选只命中泛化词，或业务域与用户核心对象不一致，判定为未找到可确认接口。

## Gate 0：只澄清阻塞项

只在缺少会改变以下结果的信息时停住：

- 接口选择；
- 请求入参；
- 统计结果；
- 返回结构；
- 字段映射；
- `function filter(data)` 写法。

停在 Gate 0 时，只输出通用 Markdown 文本卡片并停止，不输出四段式方案、映射或脚本。`已确认` 保留用户已经给出的上下文；可枚举缺口写成 `### 请选择` + 编号项，每个编号项下面用 `- A. ...`、`- B. ...`、`- C. ...` 的嵌套无序列表表达选项，默认建议项放 A 且不标注“推荐”，最后一个选项保留“其他，请说明：____”；长文本资料写成 `### 请补充` + 编号填空。多个清单同时出现时，序号必须全局连续。

## 静态模板优先级

1. 用户直接提供悟空组件静态数据模板：以用户模板为准。
2. 用户确认现场已有模板但尚未提供：要求提供模板后再继续。
3. 用户确认现场没有模板：根据展示目标、组件类型和 `knowledge/component_static_schema.md` 推荐 `result` 格式。
4. 未确认是否有模板且会影响映射/脚本：先询问现场是否有模板。

## 工具与外部数据源边界

- 本 skill 默认不主动获取公网真实数据；用户提出“查询、统计、展示某类数据”时，先按数据对接任务理解。
- 默认不得主动调用 `web_search`，也不得把公网网页、公开统计网站或第三方搜索结果作为默认数据源。
- 只有用户明确要求“联网查询”“查询公开数据”“使用公网数据源”时，才可以使用联网搜索；联网结果只能作为参考，不能替代现场接口、SQL、字段映射或组件 `result` 契约。
