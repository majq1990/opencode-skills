## 路径 A：现场已有接口

# 输出要求

1. 不得虚构接口地址、请求参数、返回字段、表名、字段名。
2. 不得把其他业务接口套用到当前业务。
3. 当前索引未命中时，只能说“当前索引未找到可确认接口”。
4. 有现场接口样例时，以现场接口样例为准。
5. 有表字段和 SQL 逻辑时，以现场表字段和 SQL 逻辑为准。 
6. 输出的 `filter(data)` 必须适配目标组件静态数据格式。
7. `data` 默认是接口外层 `result` 本体；只有分页或用户明确说明时，才处理完整响应包。
