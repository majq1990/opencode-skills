# 社招阅卷 Skill

自动阅卷系统，用于评估工程社招笔试答题结果。

## 使用场景

当用户提供阅卷链接（如 `https://assesscenter.italent.cn/Report/SummaryReport?Elink=...`）时，自动完成以下流程：

1. **打开阅卷链接** - 分析页面内容，获取题目信息和学生信息
2. **分析题目** - 识别题型（Shell、Python、SQL、日期处理等）
3. **连接数据库** - 获取正确答案（如需要）
4. **下载答题附件** - 获取学生提交的答案文件
5. **自动评分** - 对比正确答案进行评分
6. **生成报告** - 输出详细的评分报告

## 题型支持

### 1. Shell脚本题
- 检查命令语法正确性
- 验证输出结果
- 评估脚本效率

### 2. Python数据处理题
- 检查代码逻辑
- 验证计算结果
- 评估代码质量

### 3. SQL查询题
- 连接数据库执行验证
- 对比查询结果
- 检查SQL语法

### 4. 日期时间处理题
- 验证计算逻辑
- 检查边界条件处理
- 评估代码健壮性

## 工作流程

### 步骤1：打开阅卷链接并分析页面

使用 Playwright 打开阅卷链接，提取以下信息：
- 考试名称
- 学生姓名
- 题目列表（题号、分值、题目要求）
- 答题状态
- 排名信息

### 步骤2：下载学生答题附件

从页面下载所有答题附件：
- 点击每个题目的"下载答案"按钮
- 保存到临时目录
- 记录文件路径

### 步骤3：读取并分析答案

读取每个答案文件：
- 文本文件直接读取
- Word文档提取文本和图片
- 识别答案格式（代码、截图、文本）

### 步骤4：获取正确答案（如需要）

对于需要验证的题目：
- 连接数据库执行SQL查询
- 获取查询结果作为正确答案
- 记录答案格式

### 步骤5：自动评分

根据题目要求和正确答案进行评分：

**Shell脚本题评分标准：**
- 命令语法正确（20%）
- 输出结果正确（60%）
- 代码效率（20%）

**Python数据处理题评分标准：**
- 代码逻辑正确（40%）
- 计算结果正确（40%）
- 代码质量（20%）

**SQL查询题评分标准：**
- SQL语法正确（20%）
- 查询结果正确（60%）
- 查询效率（20%）

**日期时间处理题评分标准：**
- 计算逻辑正确（40%）
- 边界条件处理（30%）
- 代码健壮性（30%）

### 步骤6：生成评分报告

生成详细的评分报告，包含：
- 基本信息（考试名称、学生姓名、时间等）
- 每题得分和评语
- 总分汇总
- 改进建议


## 注意事项

1. **截图答案处理**：如果学生答案为截图格式，需要人工评分
2. **数据库连接**：确保数据库连接信息正确
3. **文件编码**：注意处理中文编码问题
4. **临时文件**：阅卷完成后清理临时下载文件

## 错误处理

- 网络连接失败：重试3次后报错
- 数据库连接失败：检查连接信息
- 文件读取失败：检查文件格式和编码
- 答案格式异常：标记为需人工评分
