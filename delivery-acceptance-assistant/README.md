# delivery-acceptance-assistant

交付物审查与验收助手。使用说明见 [SKILL.md](SKILL.md)。

## 能力一览

| # | 能力 | 入口 | 关键保证 |
| --- | --- | --- | --- |
| 1 | 交付物审查（三源融合，10 规则） | `scripts/01_collect.py` → `02_audit.py` → `03_report.py` | 交付目录零写入自证；结论分级 |
| 2 | 立项材料生成 | `scripts/04_gen_docs.py` | 模板复制+文本替换，版面零丢失校验 |
| 3 | 实施交付物生成 | `scripts/05_gen_artifacts.py` | SQL 四件套/部署脚本/中间件配置，命名 P0 闸门 |
| 4 | 风险登记册 | `scripts/06_risk_register.py` | 概率×影响分级 + 升级条件自动触发 |

## 自测

```bash
python tests/run_all.py
```

29 个用例：全链路正向回归（内置样例交付目录 → 审查 → 报告 → 生成 → 风险登记）
+ 10 个反向堵截（坏 JSON、缺模板、恒等替换、输出目录在目标内、命名 P0、升级缺回滚等）。

## 设计原则

- **零依赖**：纯 Python 标准库（zipfile/re/json/csv/hashlib），离线可用，无 python-docx 依赖。
- **gap-stop**：前置条件不满足就停并说明原因，不用默认值硬编。
- **模板永不被改写**：生成只写 `--outdir`，模板目录只读。
- **诚实上报**：替换未命中的键、清单外文件、待指派责任人全部如实列出，不美化数字。
