# 原型图视觉还原方法

## 分层还原

| 层 | 优先还原方式 | 备注 |
| --- | --- | --- |
| 背景 | 主题或背景图 | 可切图，但不要覆盖业务组件 |
| 头部 | Title5 / BasicImg / Text | 标题应可编辑 |
| 面板 | BorderBox / BasicImg | 边框可切图，内容组件化 |
| 指标 | BasicInfo / BasicInfo3 | 必须可接数据 |
| 图表 | 悟空图表组件 | 无法识别时先占位 |
| 列表 | 表格/轮播列表组件 | 字段待确认 |
| 地图 | 地图组件或地图占位 | 底图类型待确认 |
| 视频 | EgovaPlayer 或占位 | 需要视频源 |
| 热区 | HotZone / Button | 用于点击、跳转、弹窗 |

## 坐标映射

1. 读取原型图尺寸。
2. 确认目标画布尺寸。
3. 按比例换算 `x/y/width/height`。
4. 保持视觉对齐，优先保证主结构不重叠。
5. 细节误差放到视觉回归阶段修。

## 质量说明

输出时用以下标签说明每个区域：

| 标签 | 含义 |
| --- | --- |
| 可编辑 | 已用悟空组件表达 |
| 半可编辑 | 外壳切图，内容组件化 |
| 静态 | 暂时只能切图或截图 |
| 待确认 | 需要用户确认组件或口径 |
