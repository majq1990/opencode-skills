# 悟空落地安全门禁

## 写前检查

写入悟空前必须确认：

1. 账号是隔离账号。
2. 分组是隔离分组。
3. 记录写入前资源数量。
4. 包名符合规则：`page_`、`pages_`、`project_`。
5. 页面 id、组件 id、数据 id、交互 id 已重新生成。
6. 导入参数包含目标 `groupId`。
7. 用户已明确同意写入。

写入账号必须以当前登录会话或 `unity/user/composite` 只读校验结果为准。禁止使用历史脚本里的 fallback Bearer token 执行导入或写入；若 token 对应用户不是目标隔离账号，必须停止。

## 写后检查

不能只看“上传成功”提示。必须验证：

1. 目标分组列表数量变化。
2. 新资源名称可搜索到。
3. 详情里的 `groupId` 等于目标分组。
4. 新资源可以打开编辑或预览。
5. 默认分组和历史资源没有异常变化。
6. 新资源 `creator` 是目标隔离账号；如果不是，视为导入失败，需要用正确账号重新导入。

## 页面地址规则

已实测的悟空页面编辑入口：

`http://wk.egova.com.cn:8042/wukong/index.html#/create?id={pageId}`

不要臆造 `#/space/screen/edit/{pageId}` 这类地址。导入后若服务端重新分配页面 id，必须先通过列表或导入结果拿到真实 `pageId`，再拼接上述编辑地址。

## 导入经验

已知悟空导入规则：

1. 单页面包使用 `page_*.zip`。
2. 批量页面包使用 `pages_*.zip`。
3. 项目包使用 `project_*.zip`。
4. 批量大屏导入端点是 `unity/page/batch-import`。
5. multipart 字段包括 `file`、`setStaticData`、`groupId`。
6. 导入成功后可能重新分配页面 id，因此不能假设导入后 id 等于包内 id。

## 禁止

1. 禁止写入非隔离分组。
2. 禁止覆盖或删除历史资源。
3. 禁止未经确认点击保存、确定、导入、删除。
4. 禁止把 token、Cookie、客户数据写入 skill、日志或公开仓库。
