# 原型图到悟空大屏工作流

## 目标

把用户提供的原型图、设计稿、截图或 PDF 转成悟空可编辑大屏草稿。

## 流程

1. 收集输入：图、尺寸、业务主题、动态区域、交互区域、接口资料。
2. 图层拆解：外壳层、装饰层、组件层、交互层、数据层。
3. 组件识别：标题、指标卡、图表、表格、地图、视频、筛选器、弹窗。
4. 模板匹配：整屏模板、组件模板、无模板 fallback。
5. 生成 `WukongBlueprint`。
6. 对动态组件调用 `egova-screen-data-connector`。
7. 对配置落地调用 `wukong-screen-builder`。
8. 导入前确认隔离账号、分组、包名、id 重生成、groupId。
9. 导入后验证列表、详情、编辑入口、预览截图。
10. 输出修复清单或下一轮补丁。

编辑入口使用已实测规则：

`http://wk.egova.com.cn:8042/wukong/index.html#/create?id={pageId}`

## 常见布局

| 布局 | 特征 | 优先组件 |
| --- | --- | --- |
| 中心地图左右栏 | 中间地图，左右指标和图表 | Map、BasicInfo、Title5、Tabs、Table |
| 指标驾驶舱 | 多指标、多图表、弱地图 | BasicInfo、Bar、Line、Pie、Rank |
| 列表监控 | 表格和详情为主 | Table、Swiper、Tabs、Popup |
| 视频墙 | 多视频格子和设备列表 | EgovaPlayer、Tree、Select |
| 超宽多专题 | 3840/4800 宽，多区域并列 | BorderBox、Tabs、Map、Cards |

## 停止点

遇到以下情况必须暂停并让用户确认：

1. 要写入悟空。
2. 要覆盖或删除已有资源。
3. 无模板且只能大面积切图，可能影响可编辑性。
4. 数据口径不明确但用户要求真实数据。
5. 原型图区域识别置信度低，影响组件选择。
