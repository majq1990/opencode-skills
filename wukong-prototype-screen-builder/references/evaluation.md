# 评测和验收标准

## 评测样例

首批评测建议覆盖：

1. 有整屏模板可套用的 1920x1080 城市治理大屏。
2. 没有整屏模板但组件可复用的指标驾驶舱。
3. 没有模板、必须组件化重建的强视觉设计稿。
4. 有交互弹窗和筛选器的运行态势屏。

## 验收指标

| 指标 | 通过标准 |
| --- | --- |
| 图层拆解 | 至少区分外壳、装饰、组件、交互、数据 |
| 组件化判断 | 标出可编辑、半可编辑、静态、待确认 |
| 模板策略 | 给出 A/B/C 档模板策略 |
| 蓝图完整性 | 包含 screen、regions、widgets、dataIntents、landing |
| 数据边界 | 未编造接口，动态数据委托给数据 skill |
| 写入安全 | 写前确认、写后列表和详情校验 |
