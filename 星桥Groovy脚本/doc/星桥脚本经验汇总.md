# 调用第三方接口：从Header中移除客户端身份、ip等信息

这些请求头字段，一般是和 客户端身份、请求来源、网络代理 有关。

*   user-agent：标识发起请求的客户端类型（浏览器、操作系统、设备型号等）。
    
*   x-real-ip：表示客户端的真实 IP（由反向代理服务器写入）。
    
    *   获取用户真实 IP 地址，用于定位、防刷、防攻击等。
        
*   x-forwarded-for：记录整个请求链中的客户端 IP（可包含多个）。
    
    *   判断请求是否经过代理、识别原始客户端。
        
    *   常用来做黑名单校验、防攻击识别。
        
*   x-forwarded-proto：告知后端请求最初是通过 HTTP 还是 HTTPS 发起的。
    

为什么移除这些？

如果你模拟请求、绕过网关、做测试或抓包分析。这些头可能：

1.  泄露真实 IP、客户端信息。
    
2.  会被服务端识别出“你是脚本，不是浏览器”，从而限制请求。
    
3.  有时候服务端对 IP 或协议做限制，你可能需要“伪造”或“干净处理”。
    

```groovy
request.removeHeader("user-agent");
request.removeHeader("x-real-ip");
request.removeHeader("x-forwarded-for");
request.removeHeader("x-forwarded-proto");
request.setHeader('User-Agent', 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/123.0.0.0 Safari/537.36 Edg/123.0.0.0');
request.setHeader('Content-Type', 'application/json');
```

## 插入或更新记录

```groovy
var namedQueryTemplate = sql.ofNamed('朱敏MySQL本地数据源');
var jdbcTemplate = namedQueryTemplate.session.jdbcTemplate;

var mergeSQL = '''
    MERGE INTO to_media A USING (
        SELECT ? AS ID, ? AS AJXSBH, ? AS GLLX, ? AS DMTLX, ? AS DMTYT, ? AS CJSJ, ? AS DMTURL, ? AS DMTMC, ? AS DMTLJ FROM DUAL
    ) TMP ON (A.ID = TMP.ID) 
    WHEN MATCHED THEN UPDATE SET 
        AJXSBH = TMP.AJXSBH, GLLX = TMP.GLLX, DMTLX = TMP.DMTLX, DMTYT = TMP.DMTYT, CJSJ = TMP.CJSJ, 
        DMTURL = TMP.DMTURL, DMTMC = TMP.DMTMC, DMTLJ = TMP.DMTLJ
    WHEN NOT MATCHED THEN INSERT (ID, AJXSBH, GLLX, DMTLX, DMTYT, CJSJ, DMTURL, DMTMC, DMTLJ) 
        VALUES (TMP.ID, TMP.AJXSBH, TMP.GLLX, TMP.DMTLX, TMP.DMTYT, TMP.CJSJ, TMP.DMTURL, TMP.DMTMC, TMP.DMTLJ)
'''
var updateRes = jdbcTemplate.update(mergeSQL, [
    map?.ID,map?.AJXSBH,map?.GLLX,map?.DMTLX,map?.DMTYT,map?.CJSJ,map?.DMTURL,map?.DMTMC,map?.DMTLJ
] as Object[])
```
