## 需求

物联网1.0 对接燃气设备基础数据和实时数据，在同一个星桥空接口中完成。

- 星桥接口：`dex-api/free/req-resp`
- 推送方式：前置脚本读取空接口 body，转换后主动调用物联网 1.0 免密接口，并提前结束空接口请求。
- 基础数据接口：`/free/admin/import`
- 实时数据接口：`/free/exchange/equip/list`
- 基础数据设备类型 ID：`505`
- 监测项编码：`CH4`
- 监测项名称：`甲烷`
- 监测项单位：`%LEL`

其他设备基础数据从业务库获取：

```groovy
var namedQueryTemplate = sql.ofNamed('锦州燃气业务库')
var map = namedQueryTemplate.forMap(
    'select enterprise_id,enterprise_name,user_name,x,y,address,business_user_mobile,gas_alarm_code from mf_gas_nonresident_user where gas_alarm_code = :equipCode',
    ['equipCode': 'xxxx']
)
```

## 星桥配置说明

- 将下面的前置脚本、后置脚本配置到同一个空接口 `dex-api/free/req-resp`。
- 前置脚本会根据入参自动分流：
  - `payload.sensorData` 存在时，按实时数据处理。
  - `payload.sensorData` 不存在时，按基础数据处理。
- 脚本中的 `iotBaseUrl` 是现场物联网 1.0 地址，部署时需要替换 IP 和端口。
- 基础数据查不到业务库记录时，会使用入参中的 `deviceCode`、`deviceIdentify/deviceldentify`、`payload.deviceID` 兜底推送。
- 实时数据中多个 `CH4` 传感器会逐条推送相同监测项编码 `CH4`，并在 `detail` 中记录传感器地址和状态。
- 报警转换标准：`Low Alarm`、`High Alarm`、`Prealarm`、`报警` 转为 `alarm=1`，其他状态转为 `alarm=0`。

## 前置脚本

```groovy
import org.springframework.http.HttpHeaders
import com.egova.api.util.http.HttpUtils
import com.egova.json.utils.JsonUtils
import java.text.SimpleDateFormat

// ========== 现场配置：部署时需要替换 IP 和端口 ==========
var iotBaseUrl = 'http://173.16.0.17:8084/iot-api'
var equipTypeId = 505
var dataSourceName = '锦州燃气业务库'

// ========== 工具方法区 ==========
var hasText = { value ->
    return value != null && String.valueOf(value).trim() != ''
}

var toText = { value ->
    return value == null ? null : String.valueOf(value).trim()
}

var toDouble = { value ->
    if (!hasText(value)) {
        return null
    }
    try {
        return Double.parseDouble(String.valueOf(value).trim())
    } catch (Exception ignored) {
        return null
    }
}

var toMillis = { value ->
    if (value == null) {
        return null
    }
    if (value instanceof Number) {
        return ((Number) value).longValue()
    }

    var timeStr = String.valueOf(value).trim()
    if (timeStr == '') {
        return null
    }

    try {
        return Long.parseLong(timeStr)
    } catch (Exception ignored) {
    }

    try {
        var cleanTimeStr = timeStr.replace('T', ' ').replace('Z', '')
        if (cleanTimeStr.length() >= 18 && cleanTimeStr.substring(10, 11) != ' ') {
            cleanTimeStr = cleanTimeStr.substring(0, 10) + ' ' + cleanTimeStr.substring(10)
        }
        cleanTimeStr = cleanTimeStr.take(19)
        var sdf = new SimpleDateFormat('yyyy-MM-dd HH:mm:ss')
        return sdf.parse(cleanTimeStr).getTime()
    } catch (Exception ignored) {
        return null
    }
}

var parsePayload = { value ->
    if (value instanceof Map) {
        return value
    }
    if (!hasText(value)) {
        return [:]
    }
    try {
        var payloadMap = JsonUtils.deserialize(String.valueOf(value), Map.class)
        return payloadMap instanceof Map ? payloadMap : [:]
    } catch (Exception ignored) {
        return [:]
    }
}

var isAlarmStatus = { status ->
    var statusText = toText(status)
    if (!hasText(statusText)) {
        return false
    }
    return statusText.equalsIgnoreCase('Low Alarm') || statusText.equalsIgnoreCase('High Alarm') || statusText.equalsIgnoreCase('Prealarm') || statusText == '报警'
}

var removeEmpty = { sourceMap ->
    return sourceMap.findAll { entry ->
        entry.value != null && !(entry.value instanceof String && entry.value.trim() == '')
    }
}

var pushToIot = { path, pushBody ->
    var response = HttpUtils.postJson(
        iotBaseUrl + path,
        pushBody,
        Map.class,
        { HttpHeaders headers ->
            headers.set('Content-Type', 'application/json')
        }
    ).getBody()
    return response
}

// ========== 主逻辑区 ==========
variables['pushFlag'] = false
variables['pushType'] = ''
variables['pushMsg'] = ''
variables['pushBody'] = ''
variables['pushResult'] = ''

try {
    var bodyStr = request.getBody().getString()
    if (!hasText(bodyStr)) {
        variables['pushMsg'] = 'body为空，未推送'
        return 'api_stop'
    }

    var source = JsonUtils.deserialize(bodyStr, Map.class)
    if (!(source instanceof Map)) {
        variables['pushMsg'] = 'body不是JSON对象，未推送'
        return 'api_stop'
    }

    var payload = parsePayload(source.payload)
    var equipCode = toText(source.deviceCode)
    if (!hasText(equipCode)) {
        variables['pushMsg'] = 'deviceCode为空，未推送'
        return 'api_stop'
    }

    // payload 中包含 sensorData 时按实时数据处理，否则按基础数据处理
    var sensorData = payload.sensorData instanceof List ? payload.sensorData : []

    if (!sensorData.isEmpty()) {
        var pushTime = toMillis(source.eventTime)
        if (pushTime == null) {
            pushTime = System.currentTimeMillis()
        }

        var dataList = []
        for (item in sensorData) {
            if (!(item instanceof Map)) {
                continue
            }

            var sensorName = toText(item.name)
            if (sensorName != 'CH4') {
                continue
            }

            var detailMap = removeEmpty([
                'addr'      : item.addr,
                'unit'      : item.unit,
                'status'    : item.status,
                'dataStatus': payload.dataStatus
            ])

            dataList.add(removeEmpty([
                'fieldCode': 'CH4',
                'value'    : toDouble(item.val),
                'detail'   : JsonUtils.serialize(detailMap),
                'alarm'    : isAlarmStatus(item.status) || isAlarmStatus(payload.dataStatus) ? 1 : 0
            ]))
        }

        if (dataList.isEmpty()) {
            variables['pushMsg'] = '实时数据中未找到CH4监测项，未推送'
            return 'api_stop'
        }

        var pushBody = [[
            'equipCode': equipCode,
            'time'     : pushTime,
            'data'     : dataList
        ]]

        var iotRes = pushToIot('/free/exchange/equip/list', pushBody)

        variables['pushFlag'] = true
        variables['pushType'] = 'realtime'
        variables['pushMsg'] = '实时数据已推送'
        variables['pushBody'] = JsonUtils.serialize(pushBody)
        variables['pushResult'] = JsonUtils.serialize(iotRes)
        return 'api_stop'
    }

    // 基础数据先按 deviceCode 查询业务库，查不到时使用入参兜底
    var dbMap = null
    try {
        var namedQueryTemplate = sql.ofNamed(dataSourceName)
        dbMap = namedQueryTemplate.forMap(
            'select enterprise_id,enterprise_name,user_name,x,y,address,business_user_mobile,gas_alarm_code from mf_gas_nonresident_user where gas_alarm_code = :equipCode',
            ['equipCode': equipCode]
        )
    } catch (Exception e) {
        variables['pushMsg'] = '业务库查询失败，使用入参兜底：' + e.message
    }

    if (!(dbMap instanceof Map)) {
        dbMap = [:]
    }

    var deviceIdentify = toText(source.deviceIdentify)
    if (!hasText(deviceIdentify)) {
        deviceIdentify = toText(source.deviceldentify)
    }
    if (!hasText(deviceIdentify)) {
        deviceIdentify = toText(source.termId)
    }
    if (!hasText(deviceIdentify)) {
        deviceIdentify = toText(source.termld)
    }

    var equipName = toText(dbMap.enterprise_name)
    if (!hasText(equipName)) {
        equipName = toText(payload.deviceID)
    }
    if (!hasText(equipName)) {
        equipName = equipCode
    }

    var address = toText(dbMap.address)
    if (!hasText(address)) {
        address = equipCode
    }

    var iotItem = removeEmpty([
        'uid'              : hasText(deviceIdentify) ? deviceIdentify : equipCode,
        'equipCode'        : equipCode,
        'equipName'        : equipName,
        'equipTypeId'      : equipTypeId,
        'address'          : address,
        'x'                : toDouble(dbMap.x),
        'y'                : toDouble(dbMap.y),
        'serialNumber'     : toText(payload.deviceID),
        'responseUnitId'   : toText(dbMap.enterprise_id),
        'responseUnitName' : toText(dbMap.enterprise_name),
        'responsibleName'  : toText(dbMap.user_name),
        'responsibleMobile': toText(dbMap.business_user_mobile),
        'validFlag'        : 1,
        'fields'           : [
            [
                'fieldCode'   : 'CH4',
                'fieldName'   : '甲烷',
                'fieldUnit'   : '%LEL',
                'dataType'    : 1,
                'genAlarmFlag': 1,
                'displayOrder': 1
            ]
        ]
    ])

    var pushBody = [iotItem]
    var iotRes = pushToIot('/free/admin/import', pushBody)

    variables['pushFlag'] = true
    variables['pushType'] = 'base'
    variables['pushMsg'] = hasText(variables['pushMsg']) ? variables['pushMsg'] + '；基础数据已推送' : '基础数据已推送'
    variables['pushBody'] = JsonUtils.serialize(pushBody)
    variables['pushResult'] = JsonUtils.serialize(iotRes)
    return 'api_stop'
} catch (Exception e) {
    variables['pushMsg'] = '脚本执行异常：' + e.message
    return 'api_stop'
}
```

## 后置脚本

```groovy
import com.egova.json.utils.JsonUtils

// 前置脚本使用 api_stop 时通常不会继续请求空接口；如平台仍执行后置脚本，则返回推送结果
var result = [
    'pushFlag'  : variables['pushFlag'],
    'pushType'  : variables['pushType'],
    'pushMsg'   : variables['pushMsg'],
    'pushBody'  : variables['pushBody'],
    'pushResult': variables['pushResult']
]

return JsonUtils.serialize(result)
```

## 验证要点

- 基础数据样例应推送到 `http://173.16.0.17:8084/iot-api/free/admin/import`，现场需要替换地址。
- 实时数据样例应推送到 `http://173.16.0.17:8084/iot-api/free/exchange/equip/list`，现场需要替换地址。
- `deviceCode` 同时作为 IoT `equipCode` 和业务库 `gas_alarm_code` 查询条件。
- 多个 CH4 传感器会生成多条相同 `fieldCode=CH4` 的实时数据。
- `Low Alarm`、`High Alarm`、`Prealarm`、`报警` 会转换为 `alarm=1`。
