# 管网泄漏灾害预警平台星桥脚本说明

## 1. 脚本文件

- `前置脚本-设备基础数据.groovy`
- `后置脚本-设备基础数据.groovy`
- `前置脚本-实时数据-浓度.groovy`
- `后置脚本-实时数据-浓度.groovy`
- `前置脚本-实时数据-报警.groovy`
- `后置脚本-实时数据-报警.groovy`
- `前置脚本-统一推送.groovy`
- `后置脚本-统一推送.groovy`

如果希望“基础数据、浓度实时、报警实时”都放在一套脚本里，优先使用统一脚本。

## 2. 接口配置建议

- 设备基础数据这套脚本，对应目标接口配置为：`/iot-api/api/admin/import`
- 浓度实时数据这套脚本，对应目标接口配置为：`/iot-api/api/exchange/equip/list`
- 报警实时数据这套脚本，对应目标接口配置为：`/iot-api/api/exchange/equip/list`
- 统一脚本建议挂在空接口：`dex-api/free/req-resp`

当前脚本采用的是“前置脚本改写请求体”的方式，没有在脚本里主动 `HttpUtils.postJson` 推送。
统一脚本采用的是“前置脚本主动推送”的方式，由脚本内部自动分流到不同 IoT 接口。

## 3. 字段映射

### 3.1 设备基础数据

- `deviceId -> uid/equipCode`
- `deviceName -> equipName`
- `address -> address`
- `xLng -> x`
- `yLat -> y`
- `method=delete -> validFlag=0`，其他值按 `validFlag=1`
- 固定监测项：
  - `concentration`，名称“浓度”，数值型，`dataType=1`
  - `alarm_state`，名称“状态”，枚举型，`dataType=2`

### 3.2 浓度实时数据

- `deviceId -> equipCode`
- `list[].recordTime -> time`
- `list[].concentration -> data[0].value`
- `fieldCode` 固定为 `concentration`

### 3.3 报警实时数据

- `deviceId -> equipCode`
- `alarmDate -> time`
- `alarmType -> data[0].detail`
- `fieldCode` 固定为 `alarm_state`

## 4. 需要你确认/替换的地方

- `前置脚本-设备基础数据.groovy` 里的 `configuredEquipTypeId` 需要替换成现场实际的设备类型 ID
- `前置脚本-统一推送.groovy` 里的 `tokenUrl`、`iotBaseUrl`、`clientId`、`clientSecret`、`basicEquipTypeId` 需要按现场替换
- 源文档里带了 `xyType`，当前脚本直接使用 `xLng/yLat` 原值；如果现场要求做坐标系转换，请再补充确认
- 如果报警实时数据还需要把 `alarmState` 映射到 `alarm` 标记，需要你确认对应规则后再加

## 5. 提醒

- 如果后续改成“空接口 `dex-api/free/req-resp` + 前置脚本主动推送”的模式，代码里的目标 IP、端口和鉴权参数都需要按现场环境替换
