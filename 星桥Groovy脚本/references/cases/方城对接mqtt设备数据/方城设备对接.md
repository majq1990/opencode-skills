## 背景
对接设备2.0 设备实时数据


## 数据格式
```
{"data":{"CSQ":14,"battery_level":3666,"temperature":23.274557,"liquid_level_over":0,"liquid_level":0.000000,"water_immersion_state":1,"lean_angle":11,"longitude":0.000000,"latitude":0.000000,"get_location_flag":0,"arming_state":1,"vibration_count":566,"version":"1.0.0.1000","ICCID":"89860841192440171784","IMEI":"864068078836840"}}
```

## 说明
IMEI是设备编码，equipCode

对接的监测项：
lean_angle
temperature
vibration_count
water_immersion_state

## 星桥脚本配置说明

- 星桥接口：使用空接口 `dex-api/free/req-resp` 触发前置脚本和后置脚本。
- 入参方式：将设备上报的单条 JSON 数据作为空接口 body 传入。
- 推送目标：前置脚本主动调用设备 2.0 实时数据接口 `/api/exchange/equip/list`。
- 上报时间：原始数据未提供时间字段，脚本使用接收时的当前系统时间毫秒值。
- 需要按现场替换脚本中的 `tokenUrl`、`iotBaseUrl`、`clientId`、`clientSecret`。

## 前置脚本

```groovy
import org.springframework.http.HttpHeaders
import com.egova.api.util.http.HttpUtils
import com.egova.json.utils.JsonUtils

// ========== 现场配置：部署时需要替换 IP、端口和 token 参数 ==========
var tokenUrl = 'http://10.161.133.68:10050/usercenter-api/oauth/extras/token'
var iotBaseUrl = 'http://173.16.0.17:8084/iot-api'
var clientId = 'usercenter'
var clientSecret = '54ddc335f9'

// 方城设备实时数据字段直接映射为 IoT 监测项编码
var fieldCodes = [
    'lean_angle',
    'temperature',
    'vibration_count',
    'water_immersion_state'
]

// ========== 工具方法区 ==========
var hasText = { value ->
    return value != null && String.valueOf(value).trim() != ''
}

var toText = { value ->
    return value == null ? null : String.valueOf(value).trim()
}

// ========== 主逻辑区 ==========
variables['pushFlag'] = false
variables['pushMsg'] = ''
variables['pushBody'] = ''
variables['pushResult'] = ''

try {
    var bodyStr = request.getBody().getString()
    if (!hasText(bodyStr)) {
        variables['pushMsg'] = 'body为空，未推送'
        return 'api_stop'
    }

    var source = JsonUtils.deserialize(bodyStr, Map.class)
    if (!(source instanceof Map)) {
        variables['pushMsg'] = 'body不是JSON对象，未推送'
        return 'api_stop'
    }

    var equipCode = toText(source['IMEI'])
    if (!hasText(equipCode)) {
        variables['pushMsg'] = 'IMEI为空，未推送'
        return 'api_stop'
    }

    var dataList = []
    fieldCodes.each { fieldCode ->
        if (source.containsKey(fieldCode) && source[fieldCode] != null) {
            dataList.add([
                'fieldCode': fieldCode,
                'value'    : String.valueOf(source[fieldCode])
            ])
        }
    }

    if (dataList.isEmpty()) {
        variables['pushMsg'] = '未找到可推送的监测项，未推送'
        return 'api_stop'
    }

    // 原始数据无时间字段，使用接收时的当前时间
    var pushBody = [[
        'equipCode': equipCode,
        'time'     : System.currentTimeMillis(),
        'data'     : dataList
    ]]

    // 获取 IoT token
    var tokenParams = [
        'url'         : tokenUrl,
        'clientId'    : clientId,
        'clientSecret': clientSecret
    ]
    var iottoken = tokenStore.load('default', tokenParams).value

    // 主动推送到设备实时数据接口
    var iotRes = HttpUtils.postJson(
        iotBaseUrl + '/api/exchange/equip/list',
        pushBody,
        Map.class,
        { HttpHeaders headers ->
            headers.set('Content-Type', 'application/json')
            headers.set('Authorization', 'bearer ' + iottoken)
        }
    ).getBody()

    variables['pushFlag'] = true
    variables['pushMsg'] = '实时数据已推送'
    variables['pushBody'] = JsonUtils.serialize(pushBody)
    variables['pushResult'] = JsonUtils.serialize(iotRes)

    return 'api_stop'
} catch (Exception e) {
    variables['pushMsg'] = '脚本执行异常：' + e.message
    return 'api_stop'
}
```

## 后置脚本

```groovy
import com.egova.json.utils.JsonUtils

// 前置脚本使用 api_stop 时通常不会继续请求空接口；如平台仍执行后置脚本，则返回推送结果
var result = [
    'pushFlag'  : variables['pushFlag'],
    'pushMsg'   : variables['pushMsg'],
    'pushBody'  : variables['pushBody'],
    'pushResult': variables['pushResult']
]

return JsonUtils.serialize(result)
```

## 验证要点

- 示例数据应推送到 `http://173.16.0.17:8084/iot-api/api/exchange/equip/list`，现场需要替换地址。
- `IMEI` 作为 IoT `equipCode`。
- `lean_angle`、`temperature`、`vibration_count`、`water_immersion_state` 按原字段名作为 `fieldCode`。
- 原始数据没有时间字段，`time` 使用脚本接收时的当前毫秒时间戳。
