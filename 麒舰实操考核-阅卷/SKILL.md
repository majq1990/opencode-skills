# 麒舰实操考核 — 自动化阅卷

针对「麒舰实操考核」（目前考次 quiz 259）的自动评分工具。麒舰是城市网格化管理系统，考核涵盖：一键部署与授权、地理数据配置、机构维护、事项/栏目/导航/移动端/工作流/全业务流转 9 大模块。

## 触发条件

- 用户提供包含 `麒舰实操考核-*.docx` 文件的目录路径
- 提及"麒舰阅卷"、"麒舰评分"、"麒舰实操打分"、"qijian grading"

## 运行环境

- Python 3.10+
- 工作目录（默认）：`D:\backup\user1\majq\Desktop\麒舰阅卷_<日期>\`
- 输入：目录下所有 `麒舰实操考核-*.docx` 文件
- 输出：`_grading_v1.md/json/csv` + 每人扣分明细

## 端到端工作流

### Phase 1：解析 docx
```bash
cd <skill_dir>
python scripts/extract_docx.py <workdir>
```
逐份解压 docx → 输出 `_extracted/<name>/text_only.txt`（文字段落 + 图片占位） + `_extracted/<name>/media/`（图片文件）。

### Phase 2：初版评分
```bash
python scripts/grading_qijian.py <workdir>
```
按模块关键词匹配 + 段落附近图片数评估，输出 `_grading_v1.md/json/csv`。

### Phase 3：生成评语（含参考对比）
```bash
python scripts/gen_comments_qijian.py <workdir>
```
基于初版评分 + 参考作答基线，生成每人扣分明细 HTML 版评语，输出 `_grading_final.md`。

### Phase 4：汇报
向用户展示总分排行 + 1 位代表考生的完整扣分明细。**不自动提交**，仅供阅卷参考。

## 评分规则详解（references/grading_rules_qijian.md）

### 核心评分逻辑
- **截图驱动型**（大多数采分点）：按关键步骤截图数量 → 0图=0% / 1图=60% / 2图=80% / 3图=100%
- **特殊规则型**：部署模块需对 6 个系统截图；地理数据需含 URL 和图层可见性

### 注意事项
- 截图必须包含系统 URL（内网IP可接受）——无 URL 的半分
- 星桥同步数据源名称必须改为 usercenter
- 小工具 region 市级必须录入 532800（景洪市）
- 通途矢量报错需删除 *.prj 文件
- 多媒体上传失败需复制 nginx media 配置并改 ip
- 移动端需模板复制（新增模板系统应用为空）

## 答卷格式

docx 格式，命名 `麒舰实操考核-<姓名>.docx`。内容为操作过程记录：关键步骤截图 + 文字描述。每位考生内容在单份 docx 中（不像性能安全分 Q1/Q2）。
