# 页面配置模板

## 基础页面结构

```
页面
├── 筛选区（可选）
│   ├── 日期选择器（startTime / endTime）
│   ├── 下拉框（status / region 等）
│   └── 查询按钮
├── 列表组件
│   ├── 列配置（根据数据源字段）
│   ├── 操作列（编辑 / 删除 / 详情）
│   └── 分页配置
└── 详情弹窗（可选）
    └── 表单组件
```

## 列表组件配置

### 数据源绑定

```javascript
// 页面加载完成时
function() {
    var self = this;
    var listId = 'list_1';  // 列表组件ID
    var viewId = 'ds_tbl_t_xxx';  // SQL视图ID
    
    api.DATA_SOURCE_EXECUTE(viewId, 'ddcat', {
        createTimeStart: '',
        createTimeEnd: ''
    }, function(res) {
        self.$$(listId).refresh(res.result);
    });
}
```

### 筛选参数绑定

```javascript
// 查询按钮点击事件
function() {
    var self = this;
    var startTime = self.$$('date_start').getValue();  // 日期选择器ID
    var endTime = self.$$('date_end').getValue();
    
    api.DATA_SOURCE_EXECUTE(viewId, 'ddcat', {
        createTimeStart: startTime,
        createTimeEnd: endTime
    }, function(res) {
        self.$$('list_1').refresh(res.result);
    });
}
```

### 生命周期事件

```javascript
// 页面加载完成时
function() {
    // 初始化数据查询
    initQuery();
}

// 页面关闭时
function() {
    // 清理资源
    cleanup();
}
```

## 配置步骤

```
1. 新建页面 → 设置页面名称、分组
2. 拖拽筛选组件 → 配置参数绑定
3. 拖拽列表组件 → 绑定数据源（SQL视图）
4. 配置列表列 → 根据数据源字段配置显示列
5. 绑定生命周期 → 页面加载时查询数据
6. 保存 → 发布预览 → 验证功能
```

## 注意事项

- 列表组件的数据源需绑定到已创建的 SQL 视图
- 筛选组件的绑定字段需与 SQL 视图中的参数名一致
- 页面生命周期绑定的 JS 需符合灵珑前端规范（`const self = this;`）
- 空画布提示"从左侧拖拽来添加组件"
