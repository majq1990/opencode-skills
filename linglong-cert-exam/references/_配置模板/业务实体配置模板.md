# 业务实体配置模板

## 实体类型

| 类型 | 说明 | 使用场景 |
|------|------|---------|
| **外部表** | 从外部数据库导入的表 | 业务数据表（如 mis_error_rec） |
| **内部表** | 灵珑平台内部创建的数据表 | 配置数据、字典表、临时表 |

## 创建外部表

### 步骤

```
1. 数据管理 → 业务实体 → 新增实体
2. 选择"外部表"
3. 输入表名（如 mis_error_rec）
4. 导入表结构（通过数据源连接外部数据库）
5. 确认字段列表 → 保存
```

### 第一题外部表清单

| 表名 | 中文名称 | 用途 |
|------|---------|------|
| mis_error_rec | 差错件表 | ⭐第一题核心表 |
| to_site_consumptive | 处置场表 | 关联数据 |
| to_construction_site | 工地表 | 关联数据 |
| tc_vehicle | 车辆表 | 关联数据 |
| tc_vehicle_unit | 车辆单位表 | 关联数据 |
| tc_region | 区域表 | 区域字典 |
| constr_waybill_record | 主表 | 联单记录 |

## 创建内部表

### 步骤

```
1. 数据管理 → 业务实体 → 新增实体
2. 选择"内部表"
3. 输入表名（如 root_xxx）
4. 添加字段：
   - 字段名
   - 字段类型（文本/数字/日期/单选/多选）
   - 是否必填
   - 默认值（可选）
5. 保存
```

### 内部表用途

- 领导看板：存储看板配置数据
- 字典表：存储下拉选项数据
- 临时表：存储计算中间结果

## 实体关联

### 创建关联

```
1. 选择主表实体 → 操作 → 关联
2. 选择从表实体
3. 配置关联字段（主键/外键）
4. 保存
```

### 第一题关联示例

```
mis_error_rec (主)
    └── tc_region (从)
        └── 关联字段：district_id → region_id
```

## 注意事项

- 外部表需确保数据源连接正常
- 内部表创建时需明确字段类型和约束
- 实体关联需在 SQL 视图中显式 JOIN
