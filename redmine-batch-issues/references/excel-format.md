# Excel 格式说明

## 标准格式：项目建设内容匹配分析表

### 文件命名规范

典型文件名：`E3级-{项目名称} 项目建设内容匹配分析{日期时间}.xlsx`

示例：`E3级-天津河西区运管服和市容环境综合整治平台对接 项目建设内容匹配分析20260423 175500.xlsx`

### Sheet 结构

默认 Sheet 名称：`交付内容`

### 列定义

| 列序 | 表头名称 | 数据类型 | 必填 | 说明 |
|------|----------|----------|------|------|
| A | 合同交付系统 | 文本 | 是 | 所属的大系统/产品分类，如"悟空大屏"、"智慧城管"等 |
| B | 合同交付模块名称 | 文本 | 是 | 具体功能模块名称，如"智能采集专题场景"、"案件处置" |
| C | 投标文件功能描述 | 长文本 | 否 | 投标书中对该模块功能的详细描述，可能很长 |
| D | 交付的标准模块名称 | 文本 | 否 | 公司标准产品中对应的模块名称 |
| E | 是否标品 | 文本 | 否 | "标品"或"定制开发" |
| F | 定开分析 | 长文本 | 否 | 定制开发需求的分析说明 |
| G | 是否完成 | 文本 | 是 | "是"表示已完成，"否"或空值表示未完成 |

### 数据示例

| 合同交付系统 | 合同交付模块名称 | 投标文件功能描述 | 交付的标准模块名称 | 是否标品 | 定开分析 | 是否完成 |
|-------------|-----------------|-----------------|-------------------|---------|---------|---------|
| 悟空大屏 | 智能采集专题场景 | 为深入推进河西区... | 可视化产品-监督指挥 | 定制开发 | | 否 |
| 智慧城管 | 案件受理 | 提供案件受理功能... | 案件管理-受理模块 | 标品 | | 是 |

### 筛选逻辑

```
IF 是否完成 == "是" THEN 跳过（不创建 Issue）
ELSE 创建 Redmine Issue
```

"是否完成"为空值、"否"、或其他任何非"是"的值，均视为未完成，需要创建 Issue。
