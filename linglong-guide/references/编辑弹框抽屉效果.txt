编辑弹框抽屉效果
1 使用场景
在不同的业务场景中，对于弹窗出现的位置会有不同的要求，该场景使用弹窗在右侧弹出。
2 效果
在列表页面中点击编辑后编辑页面（表单）从屏幕的右侧弹出。
3 配置
1、配置弹窗右侧；
2、抽屉打开后，取消或保存时，通过脚本关闭弹窗，按钮绑定脚本，关闭弹窗；
（1）取消按钮脚本，直接关闭弹窗
function main() {
    console.log(this);
    if (window.parent) {
        window.parent.postMessage(JSON.stringify({
            event: "close-dialog",
            param: { "XXX": "test" }
        }), "*");
    }
}
（2）提交按钮脚本，提交数据并关闭弹窗
function main() {
    var formPartEle = this.$$element("form_part_p7ick");
    if (formPartEle) {
        let pageRenderElement = this.$$root().$parent.$parent.$parent;
        formPartEle.onSubmit().then(() => {
            if (window.parent) {
                window.parent.postMessage(JSON.stringify({
                    event: "close-dialog",
                    param: { "XXX": "test" }
                }), "*");
            }
        });

    }
}
