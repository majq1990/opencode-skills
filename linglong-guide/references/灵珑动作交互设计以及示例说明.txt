分支嵌套：
IF公式
IF(A,B,C),A必须是逻辑值，如果满足条件 A，则返回 B，否则返回 C
用法：IF(GT(2,1), 1, 0)，返回1
IF_FORMULA公式
用于按条件执行公式。逻辑公式IF，会计算每个表达式，无法选择某个分支执行；因此提供该公式达到按条件执行分支公式的目的。IF_FORMULA(A,B,C),A必须是逻辑值，如果满足条件 A，执行B；否则执行C
用法：注意：如果分支表达式为公式，必须用""双引号包裹起来，否则执行报错。用法示例：IF_FORMULA(GT(2,1), "UPPER(单行文本)", "LOWER(文号字段)")，条件GT(2,1)计算结果为false，因此只会执行第二个分支，不会触发UPPER公式的执行（分支不仅支持公式，也支持常量，比如：IF_FORMULA((GT(2,4), "UPPER(单行文本)",'1')）。

示例脚本
export function onLocationChange(params) {
  if (!params) {
    return;
  }
  const { gridCode } = params;
  let self = this;
  const districtEle = self.$("single_select_2q1j8q");
  const streetEle = self.$("single_select_1m8trm");


  api.DATA_SOURCE_EXECUTE("f63243b0-b33d-4971-a97f-ebae629db54f-cfe4", "api", [
    { name: "cellCode", valueContent: gridCode }
  ], [], "").then(res => {
    debugger
    if (!res.hasError) {
      const data = JSON.parse(res.result);
      console.log(data);
      if (data.success && data.data) {
        const { street, district } = data.data;
        // street 街道信息
        // cell 网格信息
        // community 社区信息
        districtEle.$$setValue(district.regionID);
        streetEle.$$setValue(street.regionID);
        districtEle.onChangeValue();
      }
    }
  }).catch(err => {
    console.error(err);
  });

}

示例讲解
字典管理示例
背景说明
灵珑构建应用涉及下拉字典数据管理，之前是基于用户中心1.0字典管理模块来完成的。但灵珑升级为用户中心2.0之后，用户中心2.0没有该功能。需要通过灵珑构建一个模块来管理应用的字典
字典分组表：script_com_dictionary_group
字典类型表：script_com_dictionary_type，其中groupId为script_com_dictionary_group的id
字典项表：script_com_dictionary_item，其中type为script_com_dictionary_type的id，groupId为script_com_dictionary_group的id，parentId为script_com_dictionary_item的id
页面设计
页面布局
交互说明
字典分组
分组新增：点击新增->弹窗->输入分组信息->保存->刷新分组树，默认选中新增节点
节点单击：点击分组节点数据->右侧字典类型列表刷新显示对应数据
数据加载：打开页面，默认选中第一个分组节点
分组编辑：点击编辑回显，修改->保存->刷新，默认选中为编辑节点
分组删除：点击删除，删除字典分组及以下的字典类型和字典项，物理删除
字典类型
新增类型：新增类型，分组默认为左侧选中的分组节点
字典项设置：获取字典类型->打开字典项管理，展示字典类型下的字典项
字典删除：提示确认->删除字典类型->删除字典项->刷新列表，物理删除
字典项管理
顶部新增字典项：打开字典项表单->保存->刷新字典项管理树（需要赋值字典分组、字典类型、无需赋值上级id）
添加子项：打开字典项表单->保存->刷新字典项管理树（需要赋值字典分组、字典类型、需要赋值上级id）
编辑字典项：点击编辑回显，修改->保存->刷新，默认选中为编辑节点
删除字典项：字典项无下级时，展示删除按钮，删除字典项->刷新列表，物理删除；字典项有下级时，不展示删除按钮，
