灵珑Token配置与使用说明
背景说明
因历史原因公司前后端架构或标准存在不统一情况，在一项目中有 MIS、用户中心 1.0、用户中心 2.0，执法等多套独立认证体系，这些系统通过灵珑平台组装或集成时就需要对token进行置换等操作，一旦处理不当就会存在服务认证失败、会话过期、统一退出等问题。需要对不同系统中认证机制进行规范化说明，以解决此类问题。
Token现状
前端Token相关问题
读取方式不统一
各系统的token取值方式不统一，这会使得在同一个现场前端token管理混乱，开发人员不知道该如何取取哪一个。
用户中心2.0
在cookies中，键为：admin_sso_token
麒舰平台
存在Indexdb中，以加密方式来存储该值，存储格式：${serviceUrl}/auth-access-token-with-type:${value}
用户中心1.0
在cookies中，键为sso_access_token
灵珑平台
在cookies中，键为：linglong:access_token
灵珑应用
在cookies中，键为：applicationId:access_token
MIS应用
在cookies中，键为：eUrbanToken
过期步调不一致
不同认证体系会生成并管理各自的token，致使token的时效性无法统一。所以经常会出现一个系统过期了另外一个系统却可以正常访问
系统Token传递多种
主要存在以下4种传递机制，其中有些项目对此类问题做了限制，如不可以通过url传递、禁用cookies等问题。
通过URL传递
Cookies传递
LocalStorage传递
IndexDB传递
免密连接标准不统一
用户中心免密连接
格式:xxx/sso/authorize?responseType=code&applicationId=${applicationId}&redirectUrl=${redirectUrl}
CAS免密连接
格式:redirectUrl?cas-type=${cas-type}&cas-type=${cas-token}
智信插件免密连接
格式:redirectUrl?token=${token}&tokenType=${tokenType}
后端Token相关问题
认证信息读取
灵珑平台
请求头:Authorization: Bearer ${tokenValue}
Query参数：url?access_token=${tokenValue}
用户中心2.0
请求头:Authorization: Bearer ${tokenValue}
Query参数：url?access_token=${tokenValue}
麒舰平台
请求头:x-Authorization: Bearer ${tokenValue}
Query参数：url?access_token=${tokenValue}
MIS平台
MIS：url?token=${tokenValue}
Token无法相互识别
主入口的token如果是子系统以及其服务无法识别的认证机制，这样就会出现无法正常访问情况。
常见错误配置
大量重复授权逻辑配置
麒舰平台所有的授权认证都写在前置脚本中，所有的几乎都是相关的。
服务地址没有统一管理
授权认证兼容性不足
规范约定

import java.util.regex.Pattern
import com.egova.lowcode.base.util.UserContext
import com.flagwind.application.Application
import com.egova.usercenter.config.NewVerAuthingClientProperties



/**
 * 认证配置常量类
 */
final class AuthConstants {
    static final String ORIGIN_HEADER = 'origin'
    static final String TOKEN_HEADER = 'Authorization'
    static final String TOKEN_HEADER_NEW = 'x-Authorization'
    static final String COOKIE_HEADER = 'Cookie'
    static final String CAS_PREFIX = 'cas'
    static final String BEARER_PREFIX = 'Bearer'
    static final String BEARER_PREFIX_LOWER = BEARER_PREFIX.toLowerCase()
    static final List<String> SUPPORTED_CAS_TYPES = ['admin_sso_token','qijian','v22']
    static final Map<String, String> COOKIE_TOKEN_PATTERNS = [
        'admin_sso_token': 'admin_sso_token',
        'cas_access_token': 'cas_access_token'
    ]
    static final String AUTH_TYPE = "auth_user"
}

/**
 * Token工具类
 */
class TokenUtils {
    private final def tokenStore
    private final def out;
    private final def variables;
    
    TokenUtils(tokenStore,variables, out) {
        this.tokenStore = tokenStore
        this.out = out
        this.variables = variables
    }
    
    /**
     * 从Header中提取Token信息
     */
    def extractTokenFromHeader(String headerValue) {
        if (!headerValue) return null
        
        if (headerValue.contains(":") && headerValue.contains("${AuthConstants.CAS_PREFIX} ")) {
            // 旧格式处理
            def arr = headerValue.split(":")
            return [
                authorizationType: 'cas',
                tokenType: arr[0].split(" ")[1],
                tokenValue: arr[1]
            ]
        } else if (headerValue.startsWith(AuthConstants.BEARER_PREFIX) || 
                  headerValue.startsWith(AuthConstants.BEARER_PREFIX_LOWER)) {
            // Bearer token处理
            def parts = headerValue.split(" ")
            if (parts.size() < 2) return null
            var properties = Application.resolve(NewVerAuthingClientProperties);
            this.out.println("用户中心2.0开启: ${properties.enabled }");;
            return [
                authorizationType: 'Bearer',
                tokenType: properties.enabled ? 
                     "admin_sso_token" : "sso_access_token",
                tokenValue: parts[1]
            ]
        }
        return null
    }

    /**
     * 从Cookie中提取Token信息
     */
    def extractTokenFromCookies(String cookieStr) {
        if (!cookieStr) return null
        for (entry in AuthConstants.COOKIE_TOKEN_PATTERNS) {
            def matcher = (cookieStr =~ /${entry.key}=([^;,\s]+)/)
            if (matcher.find()) {
                if (entry.value == "cas_access_token") {
                    def arr = matcher.group(1).split(":")
                    return arr.length >= 2 ? [
                        authorizationType: 'Bearer',
                        tokenType: arr[0], 
                        tokenValue: arr[1]
                    ] : null
                } else {
                    return [
                        authorizationType: 'Bearer',
                        tokenType: entry.value, 
                        tokenValue: matcher.group(1)
                    ]
                }
            }
        }
        return null
    }
    
    /**
     * 交换Token
     */
    def exchangeToken(url,tokenInfo) {
        if (!url) {
            throw ExceptionUtils.api("无效的token服务地址")
        } 
        if (!tokenInfo?.tokenType || !tokenInfo?.tokenValue||!url) {
            throw ExceptionUtils.api("无效的token信息")
        }
        def authParams = [
            url: url,
            username: UserContext.username(),
            userId: UserContext.userId(),
            casType: tokenInfo.tokenType,
            casToken: tokenInfo.tokenValue
        ]
   
        def token = this.tokenStore.load(AuthConstants.AUTH_TYPE, authParams)
        if (!token?.value) {
            throw ExceptionUtils.api("获取认证token失败")
        }
        return token.value
    }

    /**
     * 设置认证头
     */
    def setAuthHeader(request,tokenInfo) {
         request.removeHeader(AuthConstants.COOKIE_HEADER)
        if (tokenInfo.authorizationType == 'Bearer'){
            request.removeHeader(AuthConstants.TOKEN_HEADER)
            request.setHeader(AuthConstants.TOKEN_HEADER_NEW, "Bearer ${tokenInfo.tokenValue}")
        } else if(tokenInfo.authorizationType == 'cas'){
            request.removeHeader(AuthConstants.TOKEN_HEADER)
            request.setHeader(AuthConstants.TOKEN_HEADER_NEW, "cas ${tokenInfo.tokenType}:${tokenInfo.tokenValue}")
        } else if(tokenInfo.authorizationType == 'queryToken'){
            request.setQueryParam(tokenInfo.tokenType, tokenInfo.tokenValue);
        }

         out.println("==========================")
    }

    def getVariableWithUrl(String key, String defaultValue) {
          def env =  this.variables['ENV'];
        return env[key] ?: defaultValue;
    }

    def getVariableWithParams(String key, String defaultValue) {
        def staticEnv = this.variables['STATIC_ENV']?: [:]
        def env =  this.variables['ENV']
        def value = null;
        if(staticEnv && staticEnv[key]){
            value = staticEnv[key];
        }
        if(!value){
           value =  (env[key]?:"").replace("http://","")  ;
        }
        return value ?: defaultValue;
    }
}

// 主处理逻辑
try {
    // 初始化TokenUtils（需要先获取tokenStore实例）
    // 注意：这里需要根据实际情况获取tokenStore实例

    def tokenUtils = new TokenUtils(tokenStore,variables, out)
    
    // 1. 尝试从Header获取Token
    def tokenInfo = null
    def authHeader = request.getHeader(AuthConstants.TOKEN_HEADER)
    
    if (authHeader) {
        out.println("=========灵珑透传的token=========")
        out.println(authHeader)
        tokenInfo = tokenUtils.extractTokenFromHeader(authHeader)
    }

    // 2. 如果Header中没有，尝试从Cookie获取
    if (!tokenInfo) {
        out.println("没有获取透传的token,尝试从Cookie中获取token...")
        def cookieStr = request.getHeader(AuthConstants.COOKIE_HEADER)
        tokenInfo = tokenUtils.extractTokenFromCookies(cookieStr)
    }

    // 3. 验证Token有效性
    if (!tokenInfo?.tokenValue) {
        throw ExceptionUtils.api("未找到有效的token，无法进行身份验证！")
    }

    // 4. 检查是否支持的类型
    def isSupportedType = AuthConstants.SUPPORTED_CAS_TYPES.any { tokenInfo.tokenType.startsWith(it) }

    out.println("cas_type: ${tokenInfo.tokenType}");
    out.println("cas_token: ${tokenInfo.tokenValue}");

    if (isSupportedType) {
        tokenInfo.authorizationType = 'Bearer';
        tokenUtils.setAuthHeader(request,tokenInfo);
        return 
    }

    def exchangeEndpoint = tokenUtils.getVariableWithUrl('svc_token_qijian',null)

    if(!exchangeEndpoint){
        throw ExceptionUtils.api("没有配置token交换协议服务地址,无法获取服务token")
    }

    // 5. 对于不支持的类型，进行Token交换
    try {
        out.println("=========Token交换=========")
        out.println("auth-type:${AuthConstants.AUTH_TYPE}");
        out.println("endpoint:${exchangeEndpoint}");
        def newToken = tokenUtils.exchangeToken(exchangeEndpoint,tokenInfo);
        out.println("获取新token: ${newToken}");
        def newTokenInfo = [
            authorizationType: 'Bearer',
            tokenType: AuthConstants.AUTH_TYPE, 
            tokenValue: newToken
        ];
        tokenUtils.setAuthHeader(request,newTokenInfo);
    } catch (Exception e) {
        throw ExceptionUtils.api("交换处理失败: ${e.message}");
    }
} catch (Exception e) {
    throw ExceptionUtils.api("Token处理失败: ${e.message}");
}

                        authorizationType: 'Bearer',
                        tokenType: entry.value, 
                        tokenValue: matcher.group(1)
                    ]
                }
            }
        }
        return null
    }

     * 交换Token
     */
    def exchangeToken(url,tokenInfo) {
        if (!url) {
            throw ExceptionUtils.api("无效的token服务地址")
        } 
        if (!tokenInfo?.tokenType || !tokenInfo?.tokenValue||!url) {
            throw ExceptionUtils.api("无效的token信息")
        }
        def authParams = [
            url: url,
            username: UserContext.username(),
            userId: UserContext.userId(),
            casType: tokenInfo.tokenType,
            casToken: tokenInfo.tokenValue
        ]
   
        def token = this.tokenStore.load(AuthConstants.AUTH_TYPE, authParams)
        if (!token?.value) {
            throw ExceptionUtils.api("获取认证token失败")
        }
        return token.value
    }

    /**
     * 设置认证头
     */
    def setAuthHeader(request,tokenInfo) {
         request.removeHeader(AuthConstants.COOKIE_HEADER)
        if (tokenInfo.authorizationType == 'Bearer'){
            request.removeHeader(AuthConstants.TOKEN_HEADER)
            request.setHeader(AuthConstants.TOKEN_HEADER_NEW, "Bearer ${tokenInfo.tokenValue}")
        } else if(tokenInfo.authorizationType == 'cas'){
            request.removeHeader(AuthConstants.TOKEN_HEADER)
            request.setHeader(AuthConstants.TOKEN_HEADER_NEW, "cas ${tokenInfo.tokenType}:${tokenInfo.tokenValue}")
        } else if(tokenInfo.authorizationType == 'queryToken'){
            request.setQueryParam(tokenInfo.tokenType, tokenInfo.tokenValue);
        }

         out.println("==========================")
    }

        return this.env[key] ?: defaultValue;
    }

    def getVariableWithOther(String key, String defaultValue) {
        return (this.env[key]?:"").replace("http://","")  ?: defaultValue;
    }

/**
 * 认证配置常量类
 */
final class AuthConstants {
    static final String ORIGIN_HEADER = 'origin'
    static final String TOKEN_HEADER = 'Authorization'
    static final String TOKEN_HEADER_NEW = 'x-Authorization'
    static final String COOKIE_HEADER = 'Cookie'
    static final String CAS_PREFIX = 'cas'
    static final String BEARER_PREFIX = 'Bearer'
    static final String BEARER_PREFIX_LOWER = BEARER_PREFIX.toLowerCase()
    static final List<String> SUPPORTED_CAS_TYPES = ['admin_sso_token','qijian','v22']
    static final Map<String, String> COOKIE_TOKEN_PATTERNS = [
        'admin_sso_token': 'admin_sso_token',
        'cas_access_token': 'cas_access_token'
    ]
    static final String AUTH_TYPE = "user"
}

/**
 * Token工具类
 */
class TokenUtils {
    private final def tokenStore
    private final def out;
    private final def variables;
    
    TokenUtils(tokenStore,variables, out) {
        this.tokenStore = tokenStore
        this.out = out
        this.variables = variables
    }
    
    /**
     * 从Header中提取Token信息
     */
    def extractTokenFromHeader(String headerValue) {
        if (!headerValue) return null
        
        if (headerValue.contains(":") && headerValue.contains("${AuthConstants.CAS_PREFIX} ")) {
            // 旧格式处理
            def arr = headerValue.split(":")
            return [
                authorizationType: 'cas',
                tokenType: arr[0].split(" ")[1],
                tokenValue: arr[1]
            ]
        } else if (headerValue.startsWith(AuthConstants.BEARER_PREFIX) || 
                  headerValue.startsWith(AuthConstants.BEARER_PREFIX_LOWER)) {
            // Bearer token处理
            def parts = headerValue.split(" ")
            if (parts.size() < 2) return null
            var properties = Application.resolve(NewVerAuthingClientProperties);
            this.out.println("用户中心2.0开启: ${properties.enabled }");;
            return [
                authorizationType: 'Bearer',
                tokenType: properties.enabled ? 
                     "admin_sso_token" : "sso_access_token",
                tokenValue: parts[1]
            ]
        }
        return null
    }

    /**
     * 从Cookie中提取Token信息
     */
    def extractTokenFromCookies(String cookieStr) {
        if (!cookieStr) return null
        for (entry in AuthConstants.COOKIE_TOKEN_PATTERNS) {
            def matcher = (cookieStr =~ /${entry.key}=([^;,\s]+)/)
            if (matcher.find()) {
                if (entry.value == "cas_access_token") {
                    def arr = matcher.group(1).split(":")
                    return arr.length >= 2 ? [
                        authorizationType: 'Bearer',
                        tokenType: arr[0], 
                        tokenValue: arr[1]
                    ] : null
                } else {
                    return [
                        authorizationType: 'Bearer',
                        tokenType: entry.value, 
                        tokenValue: matcher.group(1)
                    ]
                }
            }
        }
        return null
    }
    
    /**
     * 交换Token
     */
    def exchangeToken(url,tokenInfo) {
        if (!url) {
            throw ExceptionUtils.api("无效的token服务地址")
        } 
        if (!tokenInfo?.tokenType || !tokenInfo?.tokenValue||!url) {
            throw ExceptionUtils.api("无效的token信息")
        }
        def authParams = [
            url: url,
            username: UserContext.username(),
            userId: UserContext.userId(),
            casType: tokenInfo.tokenType,
            casToken: tokenInfo.tokenValue
        ]
   
        def token = this.tokenStore.load(AuthConstants.AUTH_TYPE, authParams)
        if (!token?.value) {
            throw ExceptionUtils.api("获取认证token失败")
        }
        return token.value
    }

    /**
     * 设置认证头
     */
    def setAuthHeader(request,tokenInfo) {
         request.removeHeader(AuthConstants.COOKIE_HEADER)
        if (tokenInfo.authorizationType == 'Bearer'){
            request.removeHeader(AuthConstants.TOKEN_HEADER)
            request.setHeader(AuthConstants.TOKEN_HEADER_NEW, "Bearer ${tokenInfo.tokenValue}")
        } else if(tokenInfo.authorizationType == 'cas'){
            request.removeHeader(AuthConstants.TOKEN_HEADER)
            request.setHeader(AuthConstants.TOKEN_HEADER_NEW, "cas ${tokenInfo.tokenType}:${tokenInfo.tokenValue}")
        } else if(tokenInfo.authorizationType == 'queryToken'){
            request.setQueryParam(tokenInfo.tokenType, tokenInfo.tokenValue);
        }

         out.println("==========================")
    }

    def getVariableWithUrl(String key, String defaultValue) {
          def env =  this.variables['ENV'];
        return env[key] ?: defaultValue;
    }

    def getVariableWithParams(String key, String defaultValue) {
        def staticEnv = this.variables['STATIC_ENV']?: [:]
        def env =  this.variables['ENV']
        def value = null;
        if(staticEnv && staticEnv[key]){
            value = staticEnv[key];
        }
        if(!value){
           value =  (env[key]?:"").replace("http://","")  ;
        }
        return value ?: defaultValue;

class TokenUtils {
    private final def tokenStore
    private final def out;
    private final def variables;
    
    TokenUtils(tokenStore,variables, out) {
        this.tokenStore = tokenStore
        this.out = out
        this.variables = variables
    }
    
    /**
     * 从Header中提取Token信息
     */
    def extractTokenFromHeader(String headerValue) {
        if (!headerValue) return null
        
        if (headerValue.contains(":") && headerValue.contains("${AuthConstants.CAS_PREFIX} ")) {
            // 旧格式处理
            def arr = headerValue.split(":")
            return [
                authorizationType: 'cas',
                tokenType: arr[0].split(" ")[1],
                tokenValue: arr[1]
            ]
        } else if (headerValue.startsWith(AuthConstants.BEARER_PREFIX) || 
                  headerValue.startsWith(AuthConstants.BEARER_PREFIX_LOWER)) {
            // Bearer token处理
            def parts = headerValue.split(" ")
            if (parts.size() < 2) return null
            var properties = Application.resolve(NewVerAuthingClientProperties);
            this.out.println("用户中心2.0开启: ${properties.enabled }");;
            return [
                authorizationType: 'Bearer',
                tokenType: properties.enabled ? 
                     "admin_sso_token" : "sso_access_token",
                tokenValue: parts[1]
            ]
        }
        return null
    }

    /**
     * 从Cookie中提取Token信息
     */
    def extractTokenFromCookies(String cookieStr) {
        if (!cookieStr) return null
        for (entry in AuthConstants.COOKIE_TOKEN_PATTERNS) {
            def matcher = (cookieStr =~ /${entry.key}=([^;,\s]+)/)
            if (matcher.find()) {
                if (entry.value == "cas_access_token") {
                    def arr = matcher.group(1).split(":")
                    return arr.length >= 2 ? [
                        authorizationType: 'Bearer',
                        tokenType: arr[0], 
                        tokenValue: arr[1]
                    ] : null
                } else {
                    return [
                        authorizationType: 'Bearer',
                        tokenType: entry.value, 
                        tokenValue: matcher.group(1)
                    ]
                }
            }
        }
        return null
    }
    
    /**
     * 交换Token
     */
    def exchangeToken(url,tokenInfo) {
        if (!url) {
            throw ExceptionUtils.api("无效的token服务地址")
        } 
        if (!tokenInfo?.tokenType || !tokenInfo?.tokenValue||!url) {
            throw ExceptionUtils.api("无效的token信息")
        }
        def authParams = [
            url: url,
            username: UserContext.username(),
            userId: UserContext.userId(),
            casType: tokenInfo.tokenType,
            casToken: tokenInfo.tokenValue
        ]
   
        def token = this.tokenStore.load(AuthConstants.AUTH_TYPE, authParams)
        if (!token?.value) {
            throw ExceptionUtils.api("获取认证token失败")
        }
        return token.value
    }

    /**
     * 设置认证头
     */
    def setAuthHeader(request,tokenInfo) {
         request.removeHeader(AuthConstants.COOKIE_HEADER)
        if (tokenInfo.authorizationType == 'Bearer'){
            request.removeHeader(AuthConstants.TOKEN_HEADER)
            request.setHeader(AuthConstants.TOKEN_HEADER_NEW, "Bearer ${tokenInfo.tokenValue}")
        } else if(tokenInfo.authorizationType == 'cas'){
            request.removeHeader(AuthConstants.TOKEN_HEADER)
            request.setHeader(AuthConstants.TOKEN_HEADER_NEW, "cas ${tokenInfo.tokenType}:${tokenInfo.tokenValue}")
        } else if(tokenInfo.authorizationType == 'queryToken'){
            request.setQueryParam(tokenInfo.tokenType, tokenInfo.tokenValue);
        }

         out.println("==========================")
    }

    def getVariableWithUrl(String key, String defaultValue) {
          def env =  this.variables['ENV'];
        return env[key] ?: defaultValue;
    }

    def getVariableWithParams(String key, String defaultValue) {
        def staticEnv = this.variables['STATIC_ENV']?: [:]
        def env =  this.variables['ENV']
        def value = null;
        if(staticEnv && staticEnv[key]){
            value = staticEnv[key];
        }
        if(!value){
           value =  (env[key]?:"").replace("http://","")  ;
        }
        return value ?: defaultValue;
    }
}

    def extractTokenFromHeader(String headerValue) {

        if (!headerValue) return null

        if (headerValue.contains(":") && headerValue.contains("${AuthConstants.CAS_PREFIX} ")) {

            // 旧格式处理

            def arr = headerValue.split(":")

            return [

                authorizationType: 'cas',

                tokenType: arr[0].split(" ")[1],

                tokenValue: arr[1]

            ]

        } else if (headerValue.startsWith(AuthConstants.BEARER_PREFIX) ||

                tokenValue: parts[1]

                }

            }

/**
 * 认证配置常量类
 */
final class AuthConstants {
    static final String ORIGIN_HEADER = 'origin'
    static final String TOKEN_HEADER = 'Authorization'
    static final String TOKEN_HEADER_NEW = 'Authorization'
    static final String COOKIE_HEADER = 'Cookie'
    static final String CAS_PREFIX = 'cas'
    static final String BEARER_PREFIX = 'Bearer'
    static final String BEARER_PREFIX_LOWER = BEARER_PREFIX.toLowerCase()
    static final List<String> SUPPORTED_CAS_TYPES = ['fac_access_token']
    static final Map<String, String> COOKIE_TOKEN_PATTERNS = [
        'eUrbanToken': 'eUrbanToken',
        'admin_sso_token': 'admin_sso_token',
        'cas_access_token': 'cas_access_token'
    ]
    static final String AUTH_TYPE = "auth_mis_elaw"
}

/**
 * Token工具类
 */
class TokenUtils {
    private final def tokenStore
    private final def out;
    private final def env;
    
    TokenUtils(tokenStore,env, out) {
        this.tokenStore = tokenStore
        this.out = out
        this.env = env
    }
    
    /**
     * 从Header中提取Token信息
     */
    def extractTokenFromHeader(String headerValue) {
        if (!headerValue) return null
        
        if (headerValue.contains(":") && headerValue.contains("${AuthConstants.CAS_PREFIX} ")) {
            // 旧格式处理
            def arr = headerValue.split(":")
            return [
                authorizationType: 'cas',
                tokenType: arr[0].split(" ")[1],
                tokenValue: arr[1]
            ]
        } else if (headerValue.startsWith(AuthConstants.BEARER_PREFIX) || 
                  headerValue.startsWith(AuthConstants.BEARER_PREFIX_LOWER)) {
            // Bearer token处理
            def parts = headerValue.split(" ")
            if (parts.size() < 2) return null
            var properties = Application.resolve(NewVerAuthingClientProperties);
            this.out.println("用户中心2.0开启: ${properties.enabled }");;
            return [
                authorizationType: 'Bearer',
                tokenType: properties.enabled ? 
                     "admin_sso_token" : "sso_access_token",
                tokenValue: parts[1]
            ]
        }
        return null
    }

    /**
     * 从Cookie中提取Token信息
     */
    def extractTokenFromCookies(String cookieStr) {
        if (!cookieStr) return null
        for (entry in AuthConstants.COOKIE_TOKEN_PATTERNS) {
            def matcher = (cookieStr =~ /${entry.key}=([^;,\s]+)/)
            if (matcher.find()) {
                if (entry.value == "cas_access_token") {
                    def arr = matcher.group(1).split(":")
                    return arr.length >= 2 ? [
                        authorizationType: 'Bearer',
                        tokenType: arr[0], 
                        tokenValue: arr[1]
                    ] : null
                } else {
                    return [
                        authorizationType: 'Bearer',
                        tokenType: entry.value, 
                        tokenValue: matcher.group(1)
                    ]
                }
            }
        }
        return null
    }
    
    /**
     * 交换Token
     */
    def exchangeToken(url,tokenInfo) {
        if (!url) {
            throw ExceptionUtils.api("无效的token服务地址")
        } 
        if (!tokenInfo?.tokenType || !tokenInfo?.tokenValue||!url) {
            throw ExceptionUtils.api("无效的token信息")
        }
        def authParams = [
            url: url,
            username: UserContext.username(),
            userId: UserContext.userId(),
            casType: tokenInfo.tokenType,
            casToken: tokenInfo.tokenValue
        ]
   
        def token = this.tokenStore.load(AuthConstants.AUTH_TYPE, authParams)
        if (!token?.value) {
            throw ExceptionUtils.api("获取认证token失败")
        }
        return token.value
    }

    /**
     * 设置认证头
     */
    def setAuthHeader(request,tokenInfo) {
         request.removeHeader(AuthConstants.COOKIE_HEADER)
        if (tokenInfo.authorizationType == 'Bearer'){
            request.removeHeader(AuthConstants.TOKEN_HEADER)
            request.setHeader(AuthConstants.TOKEN_HEADER_NEW, "Bearer ${tokenInfo.tokenValue}")
        } else if(tokenInfo.authorizationType == 'cas'){
            request.removeHeader(AuthConstants.TOKEN_HEADER)
            request.setHeader(AuthConstants.TOKEN_HEADER_NEW, "cas ${tokenInfo.tokenType}:${tokenInfo.tokenValue}")
        } else if(tokenInfo.authorizationType == 'queryToken'){
            request.setQueryParam(tokenInfo.tokenType, tokenInfo.tokenValue);
        }

         out.println("==========================")
    }

    def getVariableWithUrl(String key, String defaultValue) {
        return this.env[key] ?: defaultValue;
    }

    def getVariableWithOther(String key, String defaultValue) {
        return (this.env[key]?:"").replace("http://","")  ?: defaultValue;
    }
}
