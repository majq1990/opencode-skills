列表实现查询框传入值，通过数据模型查询进行卡片列表反选
1 使用场景
业务需求需要做到从麒舰栏目传过来的值，然后根据这个值查询表，然后通过表中返回的数据对当前这个卡片列表进行一个反选的操作，使用卡片列表实现类似表单多选框的效果。
文本主要是讲解，针对数据标签反选这个交互如何实现，文本示例脚本仅在vue3下可用，vue2下可能会有问题，配置思路可参考。
2 效果
客户在选中行列后，点击事件标记右侧弹出嵌入麒舰的灵珑表单，并且实现，上方已经打过标签的，选中效果的回填。
示例中，标签选择是个卡片列表，通过调用数据模型及脚本，实现将列表对应数据标签反选至卡片列表上。

配置页面接收的参数和列表隐藏字段，注意要跟列表种的查询框对应上

                return; // 跳出后续所有代码
            }
            if (curData.includes(';') || curData === undefined) {

                    const filteredData = tableComp.filter(item =>

                            // if (item) {

                                // console.log('计数减一')
