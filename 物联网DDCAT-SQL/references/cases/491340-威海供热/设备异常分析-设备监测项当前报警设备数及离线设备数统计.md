# 设备监测项当前报警设备数及离线设备数统计

## 1. 用户需求描述

按设备类型、设备名称、企业名称筛选设备，返回该范围下的监测项，并按照监测项编码、监测项名称分组，统计每个监测项下当前正在报警的设备数量。

在上述监测项统计结果之外，额外补充一条“离线设备数”记录，用于统计该筛选范围内当前离线的设备数量。

输出字段为：

- 监测项编码
- 监测项名称
- 正在报警的设备数量

业务口径如下：

- 当前监测项是否报警，直接以 `iot_equip_field.alarm_state` 为准
- 设备是否离线，直接以 `iot_equip_status.online_state` 为准
- 统计的是报警设备数量，不是报警记录数
- 按监测项分组统计后，在结果末尾追加一条“离线设备数”汇总记录
- 数据库语法使用瀚高数据库

说明：

- 本需求属于“当前状态”统计，不查询 `iot_equip_alarm`
- 监测项统计结果按 `field_code`、`field_name` 分组
- “离线设备数”不是单独列，而是额外补充一条记录
- 本统计口径依赖 `iot_equip_info`，按技能规则默认增加设备类型参数 `equipTypeId`

## 2. 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `equipTypeId` | String | 是 | 设备类型 ID，按技能规则默认增加 |
| `equipName` | String | 否 | 设备名称，按名称模糊匹配 |
| `manufacturerName` | String | 否 | 企业名称，按名称模糊匹配 |

## 3. 输出字段说明

| 字段名 | 说明 |
|---|---|
| `监测项编码` | 监测项编码，来源于 `iot_equip_field.field_code`；离线汇总行固定返回 `offline_count` |
| `监测项名称` | 监测项名称，来源于 `iot_equip_field.field_name`；离线汇总行固定返回 `离线设备数` |
| `正在报警的设备数量` | 当前该监测项下 `alarm_state = 1` 的去重设备数；离线汇总行表示当前离线设备数 |

## 4. DDCAT SQL 脚本

存在分组聚合与结果拼接，建议在 DDCAT 中添加缓存，建议 `30` 分钟。

```sql
WITH base_device AS (
    SELECT
        ei.equip_id
    FROM iot_equip_info ei
    #tag where()
        AND ei.valid_flag = 1
        #if (equipTypeId != null && equipTypeId != '')
            AND ei.equip_type_id = '${equipTypeId}'
        #end
        #if (equipName != null && equipName != '')
            AND ei.equip_name LIKE '%' || '${equipName}' || '%'
        #end
        #if (manufacturerName != null && manufacturerName != '')
            AND ei.manufacturer_name LIKE '%' || '${manufacturerName}' || '%'
        #end
    #end
),
base_field AS (
    SELECT
        ef.equip_id,
        ef.field_code,
        ef.field_name,
        ef.alarm_state
    FROM iot_equip_field ef
    INNER JOIN base_device bd
        ON ef.equip_id = bd.equip_id
    WHERE ef.field_code IS NOT NULL
      AND TRIM(ef.field_code) <> ''
      AND ef.field_name IS NOT NULL
      AND TRIM(ef.field_name) <> ''
)
SELECT
    t.监测项编码,
    t.监测项名称,
    t.正在报警的设备数量
FROM (
    SELECT
        bf.field_code AS 监测项编码,
        bf.field_name AS 监测项名称,
        COUNT(DISTINCT CASE WHEN bf.alarm_state = 1 THEN bf.equip_id END) AS 正在报警的设备数量,
        1 AS sort_order,
        bf.field_code AS sort_code
    FROM base_field bf
    GROUP BY bf.field_code, bf.field_name

    UNION ALL

    SELECT
        'offline_count' AS 监测项编码,
        '离线设备数' AS 监测项名称,
        COUNT(DISTINCT bd.equip_id) AS 正在报警的设备数量,
        2 AS sort_order,
        'offline_count' AS sort_code
    FROM base_device bd
    LEFT JOIN iot_equip_status es
        ON bd.equip_id = es.equip_id
    WHERE COALESCE(es.online_state, 0) <> 1
) t
ORDER BY t.sort_order ASC, t.sort_code ASC, t.监测项名称 ASC
```

## 5. 返回结果示例

```text
监测项编码     | 监测项名称   | 正在报警的设备数量
------------- | ------------ | ------------------
wd1           | 一次供水温度 | 10

offline_count | 离线设备数   | 3
```

## 6. 计算逻辑说明

### 6.1 设备范围过滤

先从 `iot_equip_info` 中筛出符合条件的设备，作为基础设备集合，过滤条件包括：

- `ei.valid_flag = 1`
- 设备类型 `equip_type_id`
- 设备名称 `equip_name`
- 企业名称 `manufacturer_name`

这样后续监测项统计和离线统计都基于同一批设备，避免口径不一致。

### 6.2 监测项报警设备数统计

当前监测项报警状态来自 `iot_equip_field.alarm_state`，由于需求是“当前状态”统计，因此不使用 `iot_equip_alarm`。

统计方式为：

```sql
COUNT(DISTINCT CASE WHEN bf.alarm_state = 1 THEN bf.equip_id END)
```

含义是：

- 按监测项编码 `field_code`、监测项名称 `field_name` 分组
- 对当前报警设备按 `equip_id` 去重统计

### 6.3 离线设备数补充记录

离线设备数不是新增一列，而是额外补一条汇总记录：

- 编码固定返回 `offline_count`
- 名称固定返回 `离线设备数`
- 数值来自当前离线设备数

离线判定依据：

```sql
COALESCE(es.online_state, 0) <> 1
```

即默认 `online_state = 1` 表示在线，其余状态按离线处理。

### 6.4 结果拼接与排序

结果分两部分：

- 第一部分：监测项报警设备数
- 第二部分：离线设备数汇总记录

通过 `UNION ALL` 进行拼接，并通过排序字段控制：

- 监测项记录先返回
- 离线设备数记录最后返回

## 7. 可执行 SQL

```sql
WITH base_device AS (
    SELECT
        ei.equip_id
    FROM iot_equip_info ei
    WHERE ei.valid_flag = 1
      AND ei.equip_type_id = '41'
      AND ei.equip_name LIKE '%' || '换热站' || '%'
      AND ei.manufacturer_name LIKE '%' || '某供热企业' || '%'
),
base_field AS (
    SELECT
        ef.equip_id,
        ef.field_code,
        ef.field_name,
        ef.alarm_state
    FROM iot_equip_field ef
    INNER JOIN base_device bd
        ON ef.equip_id = bd.equip_id
    WHERE ef.field_code IS NOT NULL
      AND TRIM(ef.field_code) <> ''
      AND ef.field_name IS NOT NULL
      AND TRIM(ef.field_name) <> ''
)
SELECT
    t.监测项编码,
    t.监测项名称,
    t.正在报警的设备数量
FROM (
    SELECT
        bf.field_code AS 监测项编码,
        bf.field_name AS 监测项名称,
        COUNT(DISTINCT CASE WHEN bf.alarm_state = 1 THEN bf.equip_id END) AS 正在报警的设备数量,
        1 AS sort_order,
        bf.field_code AS sort_code
    FROM base_field bf
    GROUP BY bf.field_code, bf.field_name

    UNION ALL

    SELECT
        'offline_count' AS 监测项编码,
        '离线设备数' AS 监测项名称,
        COUNT(DISTINCT bd.equip_id) AS 正在报警的设备数量,
        2 AS sort_order,
        'offline_count' AS sort_code
    FROM base_device bd
    LEFT JOIN iot_equip_status es
        ON bd.equip_id = es.equip_id
    WHERE COALESCE(es.online_state, 0) <> 1
) t
ORDER BY t.sort_order ASC, t.sort_code ASC, t.监测项名称 ASC;
```

## 8. 备注

- 当前统计口径是“当前状态”，不涉及报警记录表 `iot_equip_alarm`
- 当前写法中“离线设备数”这一行复用了输出字段 `正在报警的设备数量`，其值实际表示离线设备总数
- 如果后续前端要求“离线设备数”单独展示为另一列，则需要调整结果结构
- 当前写法基于瀚高数据库兼容 PostgreSQL 的 SQL 语法
