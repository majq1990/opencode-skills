# 企业月度设备离线时长统计

## 1. 用户需求描述

统计企业月度设备离线时长，查询参数为一个月的开始时间和结束时间，输出字段为：

- 企业名称
- 离线时长

业务口径如下：

- 只统计当前仍处于离线状态的设备离线时长
- 离线判定依据：`iot_equip_alarm.value_type_id = '-1'` 且 `end_time IS NULL`
- 统计单位为小时
- 企业名称不能为空
- 按离线时长降序排序
- 仅返回前 9 条
- 数据库语法使用瀚高数据库

说明：

- 本统计口径依赖 `iot_equip_info`，按技能规则默认增加设备类型参数 `equipTypeId`
- 月度离线时长按查询时间范围与当前仍离线记录的时间重叠部分计算
- 如果 `endTime` 晚于当前时间，则统计截止到当前时间；如果 `endTime` 早于当前时间，则统计截止到 `endTime`

## 2. 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `startTime` | String | 是 | 查询开始时间，例如 `2026-03-01 00:00:00` |
| `endTime` | String | 是 | 查询结束时间，例如 `2026-04-01 00:00:00` |
| `equipTypeId` | String | 是 | 设备类型ID，按技能规则默认增加 |

## 3. 输出字段说明

| 字段名 | 说明 |
|---|---|
| `企业名称` | 企业名称，来源于 `iot_equip_info.manufacturer_name` |
| `离线时长` | 企业下正在离线设备在查询时间范围内累计离线时长，单位：小时 |

## 4. DDCAT SQL 脚本
统计较复杂，建议DDCAT中，添加缓存时长半小时。
```sql
#if (startTime != null && startTime != '' && endTime != null && endTime != '')
    WITH offline_detail AS (
        SELECT
            ei.manufacturer_name,
            EXTRACT(
                EPOCH FROM (
                    LEAST(CAST('${endTime}' AS TIMESTAMP), CAST(CURRENT_TIMESTAMP AS TIMESTAMP))
                    - GREATEST(a.alarm_time, CAST('${startTime}' AS TIMESTAMP))
                )
            ) / 3600.0 AS offline_hours
        FROM iot_equip_alarm a
        INNER JOIN iot_equip_info ei ON a.equip_id = ei.equip_id
        #tag where()
            AND ei.valid_flag = 1
            AND ei.manufacturer_name IS NOT NULL
            AND TRIM(ei.manufacturer_name) <> ''
            AND a.value_type_id = '-1'
            AND a.end_time IS NULL
            AND GREATEST(a.alarm_time, CAST('${startTime}' AS TIMESTAMP))
                < LEAST(CAST('${endTime}' AS TIMESTAMP), CAST(CURRENT_TIMESTAMP AS TIMESTAMP))
            #if (equipTypeId != null && equipTypeId != '')
                AND ei.equip_type_id = '${equipTypeId}'
            #end
        #end
    )
    SELECT
        manufacturer_name AS 企业名称,
        ROUND(CAST(SUM(offline_hours) AS NUMERIC), 2) AS 离线时长
    FROM offline_detail
    GROUP BY manufacturer_name
    ORDER BY 离线时长 DESC, 企业名称 ASC
    LIMIT 9
#else
    SELECT
        CAST(NULL AS VARCHAR(200)) AS 企业名称,
        CAST(NULL AS NUMERIC(18,2)) AS 离线时长
    WHERE 1 = 2
#end
```

## 6. 计算逻辑说明

### 6.1 统计对象

只统计当前仍在离线中的设备，判断条件为：

- `a.value_type_id = '-1'`
- `a.end_time IS NULL`

### 6.2 企业筛选

企业信息来自 `iot_equip_info`，统计口径为：

- `ei.valid_flag = 1`
- `ei.manufacturer_name IS NOT NULL`
- `TRIM(ei.manufacturer_name) <> ''`

### 6.3 设备类型筛选

由于本统计口径依赖 `iot_equip_info`，默认增加设备类型参数：

```sql
AND ei.equip_type_id = '${equipTypeId}'
```

### 6.4 离线时长计算

单条离线记录的有效离线时长，取“离线开始时间”与“查询开始时间”中的较大值作为起点，取“查询结束时间”与“当前时间”中的较小值作为终点，计算两者差值并换算成小时。

计算公式：

```text
离线时长（小时） = (min(endTime, 当前时间) - max(alarm_time, startTime)) / 3600
```

SQL 中对应写法：

```sql
EXTRACT(
    EPOCH FROM (
        LEAST(CAST('${endTime}' AS TIMESTAMP), CAST(CURRENT_TIMESTAMP AS TIMESTAMP))
        - GREATEST(a.alarm_time, CAST('${startTime}' AS TIMESTAMP))
    )
) / 3600.0
```

### 6.5 时间范围过滤

只有当离线记录与查询时间范围存在重叠时才参与统计：

```sql
GREATEST(a.alarm_time, CAST('${startTime}' AS TIMESTAMP))
    < LEAST(CAST('${endTime}' AS TIMESTAMP), CAST(CURRENT_TIMESTAMP AS TIMESTAMP))
```

### 6.6 汇总与排序

- 按企业名称 `manufacturer_name` 汇总离线时长
- 结果按 `离线时长` 降序
- 同值时按企业名称升序
- 仅返回前 `9` 条

## 7. 可执行 SQL

```sql
WITH offline_detail AS (
    SELECT
        ei.manufacturer_name,
        EXTRACT(
            EPOCH FROM (
                LEAST(CAST('2026-04-01 00:00:00' AS TIMESTAMP), CAST(CURRENT_TIMESTAMP AS TIMESTAMP))
                - GREATEST(a.alarm_time, CAST('2026-03-01 00:00:00' AS TIMESTAMP))
            )
        ) / 3600.0 AS offline_hours
    FROM iot_equip_alarm a
    INNER JOIN iot_equip_info ei ON a.equip_id = ei.equip_id
    WHERE ei.valid_flag = 1
      AND ei.manufacturer_name IS NOT NULL
      AND TRIM(ei.manufacturer_name) <> ''
      AND a.value_type_id = '-1'
      AND a.end_time IS NULL
      AND GREATEST(a.alarm_time, CAST('2026-03-01 00:00:00' AS TIMESTAMP))
          < LEAST(CAST('2026-04-01 00:00:00' AS TIMESTAMP), CAST(CURRENT_TIMESTAMP AS TIMESTAMP))
      AND ei.equip_type_id = '1001'
)
SELECT
    manufacturer_name AS 企业名称,
    ROUND(CAST(SUM(offline_hours) AS NUMERIC), 2) AS 离线时长
FROM offline_detail
GROUP BY manufacturer_name
ORDER BY 离线时长 DESC, 企业名称 ASC
LIMIT 9;
```

## 8. 备注

- 当前按企业名称 `manufacturer_name` 分组，不包含 `manufacturer_id`
- 如果后续需要“仅统计月内新发生的离线时长”，则需要额外调整时间口径
- 当前写法基于瀚高数据库与 PostgreSQL 的时间函数兼容语法
