# 设备异常数据-室内温度

## 1. 用户需求描述

查询楼宇监测设备列表，返回图片所示表格数据，按“一行一个设备”的方式输出。

返回字段包括：

- 设备名称
- 室内温度
- 在线状态
- 告警状态
- 所属区域
- 所属企业

查询参数为：

- 所属企业
- 设备名称
- 某个监测项是否报警

业务口径如下：

- 设备类型固定，不作为入参，在 SQL 中写死
- 当前设备在线状态、设备告警状态，直接以 `iot_equip_status` 为准
- 当前监测项是否报警，直接以 `iot_equip_field.alarm_state` 为准
- 室内温度使用固定监测项编码查询
- 所属区域只取 `iot_equip_info.district_name`
- 数据库语法使用瀚高数据库

说明：

- 本需求属于“当前状态”列表，不查询 `iot_equip_alarm`
- 当前按前序约定，固定设备类型先写为 `equip_type_id = '501'`
- 本地接口说明样例中已出现 `field_code = 'room_temperature'`、`field_name = '室内温度'`
- 当前推荐按监测项编码查询，因为 `field_code` 上通常有索引，效果可能更好

## 2. 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `manufacturerName` | String | 否 | 所属企业名称，模糊匹配 |
| `equipName` | String | 否 | 设备名称，模糊匹配 |
| `filterFieldCode` | String | 否 | 用于筛选的监测项编码 |
| `fieldAlarmState` | Integer | 否 | 用于筛选的监测项报警状态，`1=告警`，`0=正常` |

补充说明：

- 设备类型固定写死在 SQL 中，不作为参数传入
- 如果只传 `filterFieldCode` 不传 `fieldAlarmState`，表示筛选“包含该监测项”的设备
- 如果同时传 `filterFieldCode` 和 `fieldAlarmState`，表示筛选“该监测项当前是否报警”的设备

## 3. 输出字段说明

| 字段名 | 说明 |
|---|---|
| `设备名称` | 来源于 `iot_equip_info.equip_name` |
| `室内温度` | 固定监测项编码 `room_temperature` 对应的当前值 |
| `在线状态` | 来源于 `iot_equip_status.online_state`，转换为 `在线/离线` |
| `告警状态` | 来源于 `iot_equip_status.alarm_flag`，转换为 `告警/正常` |
| `所属区域` | 来源于 `iot_equip_info.district_name` |
| `所属企业` | 来源于 `iot_equip_info.manufacturer_name` |

## 4. 固定监测项编码说明

本需求只取一个固定监测项：

- `room_temperature`：室内温度固定监测项编码

推荐直接按 `field_code` 查询：

- 可以利用监测项编码索引
- 逻辑比按名称匹配更直接
- 可避免名称变动带来的查询偏差

## 5. DDCAT SQL 脚本

该列表查询涉及基础设备筛选和固定监测项取值，建议在 DDCAT 中添加缓存，建议 `10` 分钟。

```sql
WITH base_equip AS (
    SELECT
        ei.equip_id,
        ei.equip_name,
        COALESCE(NULLIF(TRIM(ei.manufacturer_name), ''), '-') AS manufacturer_name,
        COALESCE(NULLIF(TRIM(ei.district_name), ''), '-') AS region_name,
        COALESCE(es.online_state, 0) AS online_state,
        COALESCE(es.alarm_flag, 0) AS alarm_flag
    FROM iot_equip_info ei
    LEFT JOIN iot_equip_status es
        ON ei.equip_id = es.equip_id
    #tag where()
        AND ei.valid_flag = 1
        AND ei.equip_type_id = '501'
        #if (manufacturerName != null && manufacturerName != '')
            AND ei.manufacturer_name LIKE '%' || '${manufacturerName}' || '%'
        #end
        #if (equipName != null && equipName != '')
            AND ei.equip_name LIKE '%' || '${equipName}' || '%'
        #end
        #if (filterFieldCode != null && filterFieldCode != '' && fieldAlarmState != null)
            AND EXISTS (
                SELECT 1
                FROM iot_equip_field ff
                WHERE ff.equip_id = ei.equip_id
                  AND ff.field_code = '${filterFieldCode}'
                  AND ff.alarm_state = ${fieldAlarmState}
            )
        #elseif (filterFieldCode != null && filterFieldCode != '')
            AND EXISTS (
                SELECT 1
                FROM iot_equip_field ff
                WHERE ff.equip_id = ei.equip_id
                  AND ff.field_code = '${filterFieldCode}'
            )
        #end
    #end
),
room_temp_field AS (
    SELECT
        ef.equip_id,
        MAX(CAST(ef.value AS TEXT)) AS room_temp_value
    FROM iot_equip_field ef
    INNER JOIN base_equip be
        ON ef.equip_id = be.equip_id
    WHERE ef.field_code = 'room_temperature'
    GROUP BY ef.equip_id
)
SELECT
    be.equip_name AS 设备名称,
    rtf.room_temp_value AS 室内温度,
    CASE WHEN be.online_state = 1 THEN '在线' ELSE '离线' END AS 在线状态,
    CASE WHEN be.alarm_flag = 1 THEN '告警' ELSE '正常' END AS 告警状态,
    be.region_name AS 所属区域,
    be.manufacturer_name AS 所属企业
FROM base_equip be
LEFT JOIN room_temp_field rtf
    ON be.equip_id = rtf.equip_id
ORDER BY be.equip_name ASC
```

## 7. 计算逻辑说明

### 7.1 设备基础信息与状态

主表使用 `iot_equip_info`，关联 `iot_equip_status` 获取设备当前状态：

- `online_state` 表示设备是否在线
- `alarm_flag` 表示设备当前是否报警

本需求查询的是“当前状态”，因此不查询 `iot_equip_alarm`。

### 7.2 固定设备类型

设备类型固定，因此在 SQL 中直接写死：

```sql
AND ei.equip_type_id = '501'
```

如果后续固定设备类型变更，只需替换该常量。

### 7.3 所属企业、设备名称筛选

筛选条件分别使用：

```sql
ei.manufacturer_name LIKE '%' || '${manufacturerName}' || '%'
ei.equip_name LIKE '%' || '${equipName}' || '%'
```

为空时不参与过滤。

### 7.4 某个监测项是否报警筛选

通过 `EXISTS` 子查询筛设备，筛选逻辑如下：

- 仅传 `filterFieldCode`：筛选包含该监测项的设备
- 同时传 `filterFieldCode` 和 `fieldAlarmState`：筛选该监测项当前是否报警的设备

对应逻辑：

```sql
EXISTS (
    SELECT 1
    FROM iot_equip_field ff
    WHERE ff.equip_id = ei.equip_id
      AND ff.field_code = '${filterFieldCode}'
      AND ff.alarm_state = ${fieldAlarmState}
)
```

### 7.5 室内温度取值

室内温度通过固定监测项编码直接取值：

```sql
WHERE ef.field_code = 'room_temperature'
```

这样可以直接利用 `field_code` 索引，查询效果通常优于按名称匹配。

### 7.6 所属区域

所属区域按你的要求，只取：

```sql
ei.district_name
```

为空时返回 `-`。

## 8. 可执行 SQL

```sql
WITH base_equip AS (
    SELECT
        ei.equip_id,
        ei.equip_name,
        COALESCE(NULLIF(TRIM(ei.manufacturer_name), ''), '-') AS manufacturer_name,
        COALESCE(NULLIF(TRIM(ei.district_name), ''), '-') AS region_name,
        COALESCE(es.online_state, 0) AS online_state,
        COALESCE(es.alarm_flag, 0) AS alarm_flag
    FROM iot_equip_info ei
    LEFT JOIN iot_equip_status es
        ON ei.equip_id = es.equip_id
    WHERE ei.valid_flag = 1
      AND ei.equip_type_id = '501'
      AND ei.manufacturer_name LIKE '%' || '某供热企业' || '%'
      AND ei.equip_name LIKE '%' || '明湖路机组' || '%'
      AND EXISTS (
            SELECT 1
            FROM iot_equip_field ff
            WHERE ff.equip_id = ei.equip_id
              AND ff.field_code = 'room_temperature'
              AND ff.alarm_state = 1
      )
),
room_temp_field AS (
    SELECT
        ef.equip_id,
        MAX(CAST(ef.value AS TEXT)) AS room_temp_value
    FROM iot_equip_field ef
    INNER JOIN base_equip be
        ON ef.equip_id = be.equip_id
    WHERE ef.field_code = 'room_temperature'
    GROUP BY ef.equip_id
)
SELECT
    be.equip_name AS 设备名称,
    rtf.room_temp_value AS 室内温度,
    CASE WHEN be.online_state = 1 THEN '在线' ELSE '离线' END AS 在线状态,
    CASE WHEN be.alarm_flag = 1 THEN '告警' ELSE '正常' END AS 告警状态,
    be.region_name AS 所属区域,
    be.manufacturer_name AS 所属企业
FROM base_equip be
LEFT JOIN room_temp_field rtf
    ON be.equip_id = rtf.equip_id
ORDER BY be.equip_name ASC;
```

## 9. 备注

- 当前写法按设备一行返回，适合前端表格直接展示
- 当前设备类型常量按前序约定使用 `501`
- 当前室内温度按固定监测项编码 `room_temperature` 查询，推荐优先使用该方案
- 当前写法基于瀚高数据库兼容 PostgreSQL 的 SQL 语法
