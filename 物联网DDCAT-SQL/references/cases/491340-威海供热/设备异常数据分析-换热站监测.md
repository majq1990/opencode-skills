# 固定监测项设备列表查询

## 1. 用户需求描述

查询设备列表，展示形式参考截图，按“一行一个设备、固定监测项横向展开”的方式返回结果。

返回内容包括：

- 设备编码
- 设备名称
- 固定监测项的当前值
- 固定监测项对应的监测项编码
- 固定监测项对应的报警状态
- 设备在线状态
- 设备告警状态
- 所属区域
- 所属企业

查询参数为：

- 所属企业
- 设备名称
- 某个监测项是否报警

业务口径如下：

- 设备类型固定，不作为入参，在 SQL 中写死
- 当前设备在线状态、设备告警状态，直接以 `iot_equip_status` 为准
- 当前监测项是否报警，直接以 `iot_equip_field.alarm_state` 为准
- 返回的监测项是固定的几个，因此使用条件聚合横向展开
- 所属区域只取 `iot_equip_info.district_name`
- 数据库语法使用瀚高数据库

说明：

- 本需求属于“当前状态”列表，不查询 `iot_equip_alarm`
- 当前按本地接口说明示例，固定设备类型先写为 `equip_type_id = '501'`
- 如果实际固定设备类型不是 `501`，只需替换 SQL 中该常量

## 2. 可行性评估

该需求可以通过 DDCAT 实现。

原因如下：

- 设备类型固定，可以直接在 SQL 中写死，无需动态切换类型
- 返回监测项固定，可以通过 `MAX(CASE WHEN ... THEN ... END)` 的方式做横向展开
- 查询的是当前状态，不是报警记录，因此直接查询 `iot_equip_status` 和 `iot_equip_field` 即可
- “某个监测项是否报警”可以通过 `EXISTS` 子查询按 `field_code + alarm_state` 过滤设备

## 3. 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `manufacturerName` | String | 否 | 所属企业名称，模糊匹配 |
| `equipName` | String | 否 | 设备名称，模糊匹配 |
| `filterFieldCode` | String | 否 | 用于筛选的监测项编码 |
| `fieldAlarmState` | Integer | 否 | 用于筛选的监测项报警状态，`1=告警`，`0=正常` |

补充说明：

- 设备类型固定写死在 SQL 中，不作为参数传入
- 如果只传 `filterFieldCode` 不传 `fieldAlarmState`，则表示筛选“包含该监测项”的设备
- 如果同时传 `filterFieldCode` 和 `fieldAlarmState`，则表示筛选“该监测项当前是否报警”的设备

## 5. 固定监测项说明

本需求只使用固定的监测项名称，不做名称兼容扩展。

固定监测项如下：

- `一次供温`
- `一次回温`
- `一次供压`
- `一次回压`
- `二次供温`
- `二次回温`
- `二次供压`
- `二次回压`

如果这些监测项已经对应固定的监测项编码，推荐在生产环境优先使用“按监测项编码查询版”，因为 `field_code` 上通常有索引，过滤和聚合效果可能更好。

推荐将下列占位常量替换为实际固定编码：

- `FIRST_SUPPLY_TEMP_CODE`：一次供温编码
- `FIRST_RETURN_TEMP_CODE`：一次回温编码
- `FIRST_SUPPLY_PRESSURE_CODE`：一次供压编码
- `FIRST_RETURN_PRESSURE_CODE`：一次回压编码
- `SECOND_SUPPLY_TEMP_CODE`：二次供温编码
- `SECOND_RETURN_TEMP_CODE`：二次回温编码
- `SECOND_SUPPLY_PRESSURE_CODE`：二次供压编码
- `SECOND_RETURN_PRESSURE_CODE`：二次回压编码

## 6. DDCAT SQL 脚本

该列表查询涉及基础设备筛选和固定监测项横向聚合，建议在 DDCAT 中添加缓存，建议 `5` 分钟。

```sql
WITH base_equip AS (
    SELECT
        ei.equip_id,
        ei.equip_code,
        ei.equip_name,
        COALESCE(NULLIF(TRIM(ei.manufacturer_name), ''), '-') AS manufacturer_name,
        COALESCE(NULLIF(TRIM(ei.district_name), ''), '-') AS region_name,
        COALESCE(es.online_state, 0) AS online_state,
        COALESCE(es.alarm_flag, 0) AS alarm_flag
    FROM iot_equip_info ei
    LEFT JOIN iot_equip_status es
        ON ei.equip_id = es.equip_id
    #tag where()
        AND ei.valid_flag = 1
        AND ei.equip_type_id = '501'
        #if (manufacturerName != null && manufacturerName != '')
            AND ei.manufacturer_name LIKE '%' || '${manufacturerName}' || '%'
        #end
        #if (equipName != null && equipName != '')
            AND ei.equip_name LIKE '%' || '${equipName}' || '%'
        #end
        #if (filterFieldCode != null && filterFieldCode != '' && fieldAlarmState != null)
            AND EXISTS (
                SELECT 1
                FROM iot_equip_field ff
                WHERE ff.equip_id = ei.equip_id
                  AND ff.field_code = '${filterFieldCode}'
                  AND ff.alarm_state = ${fieldAlarmState}
            )
        #elseif (filterFieldCode != null && filterFieldCode != '')
            AND EXISTS (
                SELECT 1
                FROM iot_equip_field ff
                WHERE ff.equip_id = ei.equip_id
                  AND ff.field_code = '${filterFieldCode}'
            )
        #end
    #end
),
fixed_field AS (
    SELECT
        ef.equip_id,
        ef.field_name,
        ef.field_code,
        CAST(ef.value AS TEXT) AS field_value,
        COALESCE(ef.alarm_state, 0) AS alarm_state
    FROM iot_equip_field ef
    INNER JOIN base_equip be
        ON ef.equip_id = be.equip_id
    WHERE ef.field_name IN (
        '一次供温',
        '一次回温',
        '一次供压',
        '一次回压',
        '二次供温',
        '二次回温',
        '二次供压',
        '二次回压'
    )
)
SELECT
    be.equip_code AS 设备编码,
    be.equip_name AS 设备名称,

    MAX(CASE WHEN ff.field_name = '一次供温' THEN ff.field_value END) AS 一次供温,
    MAX(CASE WHEN ff.field_name = '一次供温' THEN ff.field_code END) AS 一次供温编码,
    MAX(CASE WHEN ff.field_name = '一次供温' THEN CASE WHEN ff.alarm_state = 1 THEN '告警' ELSE '正常' END END) AS 一次供温报警状态,

    MAX(CASE WHEN ff.field_name = '一次回温' THEN ff.field_value END) AS 一次回温,
    MAX(CASE WHEN ff.field_name = '一次回温' THEN ff.field_code END) AS 一次回温编码,
    MAX(CASE WHEN ff.field_name = '一次回温' THEN CASE WHEN ff.alarm_state = 1 THEN '告警' ELSE '正常' END END) AS 一次回温报警状态,

    MAX(CASE WHEN ff.field_name = '一次供压' THEN ff.field_value END) AS 一次供压,
    MAX(CASE WHEN ff.field_name = '一次供压' THEN ff.field_code END) AS 一次供压编码,
    MAX(CASE WHEN ff.field_name = '一次供压' THEN CASE WHEN ff.alarm_state = 1 THEN '告警' ELSE '正常' END END) AS 一次供压报警状态,

    MAX(CASE WHEN ff.field_name = '一次回压' THEN ff.field_value END) AS 一次回压,
    MAX(CASE WHEN ff.field_name = '一次回压' THEN ff.field_code END) AS 一次回压编码,
    MAX(CASE WHEN ff.field_name = '一次回压' THEN CASE WHEN ff.alarm_state = 1 THEN '告警' ELSE '正常' END END) AS 一次回压报警状态,

    MAX(CASE WHEN ff.field_name = '二次供温' THEN ff.field_value END) AS 二次供温,
    MAX(CASE WHEN ff.field_name = '二次供温' THEN ff.field_code END) AS 二次供温编码,
    MAX(CASE WHEN ff.field_name = '二次供温' THEN CASE WHEN ff.alarm_state = 1 THEN '告警' ELSE '正常' END END) AS 二次供温报警状态,

    MAX(CASE WHEN ff.field_name = '二次回温' THEN ff.field_value END) AS 二次回温,
    MAX(CASE WHEN ff.field_name = '二次回温' THEN ff.field_code END) AS 二次回温编码,
    MAX(CASE WHEN ff.field_name = '二次回温' THEN CASE WHEN ff.alarm_state = 1 THEN '告警' ELSE '正常' END END) AS 二次回温报警状态,

    MAX(CASE WHEN ff.field_name = '二次供压' THEN ff.field_value END) AS 二次供压,
    MAX(CASE WHEN ff.field_name = '二次供压' THEN ff.field_code END) AS 二次供压编码,
    MAX(CASE WHEN ff.field_name = '二次供压' THEN CASE WHEN ff.alarm_state = 1 THEN '告警' ELSE '正常' END END) AS 二次供压报警状态,

    MAX(CASE WHEN ff.field_name = '二次回压' THEN ff.field_value END) AS 二次回压,
    MAX(CASE WHEN ff.field_name = '二次回压' THEN ff.field_code END) AS 二次回压编码,
    MAX(CASE WHEN ff.field_name = '二次回压' THEN CASE WHEN ff.alarm_state = 1 THEN '告警' ELSE '正常' END END) AS 二次回压报警状态,

    CASE WHEN be.online_state = 1 THEN '在线' ELSE '离线' END AS 在线状态,
    CASE WHEN be.alarm_flag = 1 THEN '告警' ELSE '正常' END AS 告警状态,
    be.region_name AS 所属区域,
    be.manufacturer_name AS 所属企业
FROM base_equip be
LEFT JOIN fixed_field ff
    ON be.equip_id = ff.equip_id
GROUP BY
    be.equip_id,
    be.equip_code,
    be.equip_name,
    be.online_state,
    be.alarm_flag,
    be.region_name,
    be.manufacturer_name
ORDER BY be.equip_name ASC, be.equip_code ASC
```

## 8. 计算逻辑说明

### 8.1 设备基础信息与状态

主表使用 `iot_equip_info`，关联 `iot_equip_status` 获取设备当前状态：

- `online_state` 表示设备是否在线
- `alarm_flag` 表示设备当前是否报警

本需求查询的是“当前状态”，因此不查询 `iot_equip_alarm`。

### 8.2 固定设备类型

设备类型固定，因此在 SQL 中直接写死：

```sql
AND ei.equip_type_id = '501'
```

如果后续固定设备类型变更，只需替换该常量。

### 8.3 所属企业、设备名称筛选

筛选条件分别使用：

```sql
ei.manufacturer_name LIKE '%' || '${manufacturerName}' || '%'
ei.equip_name LIKE '%' || '${equipName}' || '%'
```

为空时不参与过滤。

### 8.4 某个监测项是否报警筛选

通过 `EXISTS` 子查询筛设备，筛选逻辑如下：

- 仅传 `filterFieldCode`：筛选包含该监测项的设备
- 同时传 `filterFieldCode` 和 `fieldAlarmState`：筛选该监测项当前是否报警的设备

对应逻辑：

```sql
EXISTS (
    SELECT 1
    FROM iot_equip_field ff
    WHERE ff.equip_id = ei.equip_id
      AND ff.field_code = '${filterFieldCode}'
      AND ff.alarm_state = ${fieldAlarmState}
)
```

### 8.5 固定监测项横向展开

由于返回的监测项固定，因此直接按固定 `field_name` 做条件聚合横向展开：

```sql
MAX(CASE WHEN ff.field_name = '一次供温' THEN ff.field_value END)
```

同理展开：

- 当前值
- 对应编码
- 对应报警状态

最终实现“一行一个设备，固定监测项展开列”的效果。

### 8.6 所属区域

所属区域按你的要求，只取：

```sql
ei.district_name
```

为空时返回 `-`。

## 9. 可执行 SQL

```sql
WITH base_equip AS (
    SELECT
        ei.equip_id,
        ei.equip_code,
        ei.equip_name,
        COALESCE(NULLIF(TRIM(ei.manufacturer_name), ''), '-') AS manufacturer_name,
        COALESCE(NULLIF(TRIM(ei.district_name), ''), '-') AS region_name,
        COALESCE(es.online_state, 0) AS online_state,
        COALESCE(es.alarm_flag, 0) AS alarm_flag
    FROM iot_equip_info ei
    LEFT JOIN iot_equip_status es
        ON ei.equip_id = es.equip_id
    WHERE ei.valid_flag = 1
      AND ei.equip_type_id = '501'
      AND ei.manufacturer_name LIKE '%' || '某供热企业' || '%'
      AND ei.equip_name LIKE '%' || '供热机组' || '%'
      AND EXISTS (
            SELECT 1
            FROM iot_equip_field ff
            WHERE ff.equip_id = ei.equip_id
              AND ff.field_code = 'ycgswd'
              AND ff.alarm_state = 1
      )
),
fixed_field AS (
    SELECT
        ef.equip_id,
        ef.field_name,
        ef.field_code,
        CAST(ef.value AS TEXT) AS field_value,
        COALESCE(ef.alarm_state, 0) AS alarm_state
    FROM iot_equip_field ef
    INNER JOIN base_equip be
        ON ef.equip_id = be.equip_id
    WHERE ef.field_name IN (
        '一次供温',
        '一次回温',
        '一次供压',
        '一次回压',
        '二次供温',
        '二次回温',
        '二次供压',
        '二次回压'
    )
)
SELECT
    be.equip_code AS 设备编码,
    be.equip_name AS 设备名称,
    MAX(CASE WHEN ff.field_name = '一次供温' THEN ff.field_value END) AS 一次供温,
    MAX(CASE WHEN ff.field_name = '一次供温' THEN ff.field_code END) AS 一次供温编码,
    MAX(CASE WHEN ff.field_name = '一次供温' THEN CASE WHEN ff.alarm_state = 1 THEN '告警' ELSE '正常' END END) AS 一次供温报警状态,
    MAX(CASE WHEN ff.field_name = '一次回温' THEN ff.field_value END) AS 一次回温,
    MAX(CASE WHEN ff.field_name = '一次回温' THEN ff.field_code END) AS 一次回温编码,
    MAX(CASE WHEN ff.field_name = '一次回温' THEN CASE WHEN ff.alarm_state = 1 THEN '告警' ELSE '正常' END END) AS 一次回温报警状态,
    MAX(CASE WHEN ff.field_name = '一次供压' THEN ff.field_value END) AS 一次供压,
    MAX(CASE WHEN ff.field_name = '一次供压' THEN ff.field_code END) AS 一次供压编码,
    MAX(CASE WHEN ff.field_name = '一次供压' THEN CASE WHEN ff.alarm_state = 1 THEN '告警' ELSE '正常' END END) AS 一次供压报警状态,
    MAX(CASE WHEN ff.field_name = '一次回压' THEN ff.field_value END) AS 一次回压,
    MAX(CASE WHEN ff.field_name = '一次回压' THEN ff.field_code END) AS 一次回压编码,
    MAX(CASE WHEN ff.field_name = '一次回压' THEN CASE WHEN ff.alarm_state = 1 THEN '告警' ELSE '正常' END END) AS 一次回压报警状态,
    MAX(CASE WHEN ff.field_name = '二次供温' THEN ff.field_value END) AS 二次供温,
    MAX(CASE WHEN ff.field_name = '二次供温' THEN ff.field_code END) AS 二次供温编码,
    MAX(CASE WHEN ff.field_name = '二次供温' THEN CASE WHEN ff.alarm_state = 1 THEN '告警' ELSE '正常' END END) AS 二次供温报警状态,
    MAX(CASE WHEN ff.field_name = '二次回温' THEN ff.field_value END) AS 二次回温,
    MAX(CASE WHEN ff.field_name = '二次回温' THEN ff.field_code END) AS 二次回温编码,
    MAX(CASE WHEN ff.field_name = '二次回温' THEN CASE WHEN ff.alarm_state = 1 THEN '告警' ELSE '正常' END END) AS 二次回温报警状态,
    MAX(CASE WHEN ff.field_name = '二次供压' THEN ff.field_value END) AS 二次供压,
    MAX(CASE WHEN ff.field_name = '二次供压' THEN ff.field_code END) AS 二次供压编码,
    MAX(CASE WHEN ff.field_name = '二次供压' THEN CASE WHEN ff.alarm_state = 1 THEN '告警' ELSE '正常' END END) AS 二次供压报警状态,
    MAX(CASE WHEN ff.field_name = '二次回压' THEN ff.field_value END) AS 二次回压,
    MAX(CASE WHEN ff.field_name = '二次回压' THEN ff.field_code END) AS 二次回压编码,
    MAX(CASE WHEN ff.field_name = '二次回压' THEN CASE WHEN ff.alarm_state = 1 THEN '告警' ELSE '正常' END END) AS 二次回压报警状态,
    CASE WHEN be.online_state = 1 THEN '在线' ELSE '离线' END AS 在线状态,
    CASE WHEN be.alarm_flag = 1 THEN '告警' ELSE '正常' END AS 告警状态,
    be.region_name AS 所属区域,
    be.manufacturer_name AS 所属企业
FROM base_equip be
LEFT JOIN fixed_field ff
    ON be.equip_id = ff.equip_id
GROUP BY
    be.equip_id,
    be.equip_code,
    be.equip_name,
    be.online_state,
    be.alarm_flag,
    be.region_name,
    be.manufacturer_name
ORDER BY be.equip_name ASC, be.equip_code ASC;
```

## 10. 备注

- 当前写法按设备一行返回，适合前端表格直接展示
- 如果前端只需要截图中的效果，可以只显示固定监测项的值列，编码列和监测项报警状态列可按需隐藏
- 当前设备类型常量按本地接口样例使用 `501`
- 当前固定监测项只按明确的 `field_name` 查询，不做名称兼容扩展
- 如果固定监测项编码已经明确，推荐优先使用“按监测项编码查询版”
- 当前写法基于瀚高数据库兼容 PostgreSQL 的 SQL 语法
