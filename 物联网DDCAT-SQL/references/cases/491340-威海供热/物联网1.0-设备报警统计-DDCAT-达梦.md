# 物联网1.0 设备报警统计 DDCAT 文档（达梦）

## 1. 用户需求描述

查询设备报警统计数据，输出以下字段：

- 设备编码
- 设备类型
- 设备名称
- 所属区域
- 设备地址
- 报警总数
- 报警类型
- 报警频次(次/天)

查询条件：

- 统计起始时间
- 设备类型
- 报警类型
- 所属区域

说明：

- 本需求属于历史报警记录统计，报警数据口径使用 `iot_equip_alarm`。
- 统计结果依赖 `iot_equip_info`，按 skill 规则默认增加设备类型参数 `equipTypeId`。
- 设备类型名称通过 `iot_dic_equip.equip_type_name` 输出。
- 报警类型名称通过 `iot_dic_equip_value.value_type_name` 输出。
- 数据库方言按达梦数据库编写。

## 2. 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `startTime` | String | 是 | 统计起始时间，例如 `2026-04-01 00:00:00` |
| `endTime` | String | 否 | 统计结束时间，例如 `2026-04-15 00:00:00`；不传默认按当前时间 `SYSDATE` |
| `equipTypeId` | String | 否 | 设备类型ID；本统计口径默认建议传入 |
| `valueTypeId` | String | 否 | 报警类型ID |
| `districtId` | String | 否 | 区域编码，用于匹配 `iot_equip_info.district_id` |

## 3. 输出字段说明

| 字段名 | 说明 |
|---|---|
| `设备编码` | `iot_equip_info.equip_code` |
| `设备类型` | `iot_dic_equip.equip_type_name` |
| `设备名称` | `iot_equip_info.equip_name` |
| `所属区域` | `iot_equip_info.district_name` |
| `设备地址` | `iot_equip_info.address` |
| `报警总数` | 时间范围内报警记录条数 |
| `报警类型` | 优先取 `iot_dic_equip_value.value_type_name`；当 `value_type_id = '-1'` 时固定输出 `离线` |
| `报警频次(次/天)` | `报警总数 / 统计天数`，保留两位小数 |

## 4. DDCAT SQL 脚本

统计涉及时间过滤、字典关联和聚合，建议在 DDCAT 中添加缓存，建议 `10-15` 分钟。

```sql
#if (startTime != null && startTime != '')
SELECT
    ei.equip_code AS "设备编码",
    COALESCE(de.equip_type_name, ei.equip_type_id) AS "设备类型",
    ei.equip_name AS "设备名称",
    ei.district_name AS "所属区域",
    ei.address AS "设备地址",
    COUNT(*) AS "报警总数",
    CASE
        WHEN a.value_type_id = '-1' THEN '离线'
        ELSE COALESCE(dv.value_type_name, a.value_type_id)
    END AS "报警类型",
    ROUND(
        COUNT(*) / CASE
            WHEN (
                #if (endTime != null && endTime != '')
                    TO_DATE('${endTime}', 'YYYY-MM-DD HH24:MI:SS') - TO_DATE('${startTime}', 'YYYY-MM-DD HH24:MI:SS')
                #else
                    SYSDATE - TO_DATE('${startTime}', 'YYYY-MM-DD HH24:MI:SS')
                #end
            ) < 1 THEN 1
            ELSE (
                #if (endTime != null && endTime != '')
                    TO_DATE('${endTime}', 'YYYY-MM-DD HH24:MI:SS') - TO_DATE('${startTime}', 'YYYY-MM-DD HH24:MI:SS')
                #else
                    SYSDATE - TO_DATE('${startTime}', 'YYYY-MM-DD HH24:MI:SS')
                #end
            )
        END,
        2
    ) AS "报警频次(次/天)"
FROM iot_equip_alarm a
INNER JOIN iot_equip_info ei
    ON a.equip_id = ei.equip_id
LEFT JOIN iot_dic_equip de
    ON ei.equip_type_id = de.equip_type_id
LEFT JOIN iot_dic_equip_value dv
    ON a.value_type_id = dv.value_type_id
   AND dv.valid_flag = 1
#tag where()
    AND ei.valid_flag = 1
    AND a.alarm_time >= TO_DATE('${startTime}', 'YYYY-MM-DD HH24:MI:SS')
    #if (endTime != null && endTime != '')
        AND a.alarm_time < TO_DATE('${endTime}', 'YYYY-MM-DD HH24:MI:SS')
    #end
    #if (equipTypeId != null && equipTypeId != '')
        AND ei.equip_type_id = '${equipTypeId}'
    #end
    #if (valueTypeId != null && valueTypeId != '')
        AND a.value_type_id = '${valueTypeId}'
    #end
    #if (districtId != null && districtId != '')
        AND ei.district_id = '${districtId}'
    #end
#end
GROUP BY
    ei.equip_id,
    ei.equip_code,
    ei.equip_type_id,
    de.equip_type_name,
    ei.equip_name,
    ei.district_name,
    ei.address,
    a.value_type_id,
    dv.value_type_name
ORDER BY "报警总数" DESC, "设备名称" ASC, "设备编码" ASC
#else
SELECT
    CAST(NULL AS VARCHAR(64)) AS "设备编码",
    CAST(NULL AS VARCHAR(64)) AS "设备类型",
    CAST(NULL AS VARCHAR(128)) AS "设备名称",
    CAST(NULL AS VARCHAR(128)) AS "所属区域",
    CAST(NULL AS VARCHAR(255)) AS "设备地址",
    CAST(NULL AS INTEGER) AS "报警总数",
    CAST(NULL AS VARCHAR(64)) AS "报警类型",
    CAST(NULL AS DECIMAL(18,2)) AS "报警频次(次/天)"
FROM dual
WHERE 1 = 2
#end
```

## 6. 计算逻辑说明

### 6.1 报警总数

- 数据来源：`iot_equip_alarm`
- 统计口径：满足筛选条件的报警记录 `COUNT(*)`

### 6.2 报警类型

- 优先通过 `iot_dic_equip_value.value_type_name` 输出报警类型名称
- 当 `a.value_type_id = '-1'` 时，固定输出 `离线`
- 若字典表未匹配到名称，则回退输出 `a.value_type_id`

### 6.3 设备类型

- 优先通过 `iot_dic_equip.equip_type_name` 输出设备类型名称
- 若字典表未匹配到名称，则回退输出 `ei.equip_type_id`

### 6.4 报警频次(次/天)

计算公式：

```text
报警频次(次/天) = 报警总数 / 统计天数
```

统计天数口径：

- 使用 `startTime` 到 `endTime` 的日期差
- 若未传 `endTime`，使用达梦当前时间 `SYSDATE`
- 使用 `CASE WHEN ... < 1 THEN 1` 兜底，避免除零或短时间区间导致分母过小

### 6.5 过滤条件

- 时间：`a.alarm_time >= startTime`，`a.alarm_time < endTime`
- 设备类型：`ei.equip_type_id = equipTypeId`
- 报警类型：`a.value_type_id = valueTypeId`
- 所属区域：`ei.district_id = districtId`

## 7. 可执行 SQL（示例参数）

```sql
SELECT
    ei.equip_code AS "设备编码",
    COALESCE(de.equip_type_name, ei.equip_type_id) AS "设备类型",
    ei.equip_name AS "设备名称",
    ei.district_name AS "所属区域",
    ei.address AS "设备地址",
    COUNT(*) AS "报警总数",
    CASE
        WHEN a.value_type_id = '-1' THEN '离线'
        ELSE COALESCE(dv.value_type_name, a.value_type_id)
    END AS "报警类型",
    ROUND(
        COUNT(*) / CASE
            WHEN (
                TO_DATE('2026-04-15 00:00:00', 'YYYY-MM-DD HH24:MI:SS')
                - TO_DATE('2026-04-01 00:00:00', 'YYYY-MM-DD HH24:MI:SS')
            ) < 1 THEN 1
            ELSE (
                TO_DATE('2026-04-15 00:00:00', 'YYYY-MM-DD HH24:MI:SS')
                - TO_DATE('2026-04-01 00:00:00', 'YYYY-MM-DD HH24:MI:SS')
            )
        END,
        2
    ) AS "报警频次(次/天)"
FROM iot_equip_alarm a
INNER JOIN iot_equip_info ei
    ON a.equip_id = ei.equip_id
LEFT JOIN iot_dic_equip de
    ON ei.equip_type_id = de.equip_type_id
LEFT JOIN iot_dic_equip_value dv
    ON a.value_type_id = dv.value_type_id
   AND dv.valid_flag = 1
WHERE ei.valid_flag = 1
  AND a.alarm_time >= TO_DATE('2026-04-01 00:00:00', 'YYYY-MM-DD HH24:MI:SS')
  AND a.alarm_time < TO_DATE('2026-04-15 00:00:00', 'YYYY-MM-DD HH24:MI:SS')
  AND ei.equip_type_id = '501'
  AND a.value_type_id = '2'
  AND ei.district_id = '371002'
GROUP BY
    ei.equip_id,
    ei.equip_code,
    ei.equip_type_id,
    de.equip_type_name,
    ei.equip_name,
    ei.district_name,
    ei.address,
    a.value_type_id,
    dv.value_type_name
ORDER BY "报警总数" DESC, "设备名称" ASC, "设备编码" ASC;
```

## 8. 备注

- 当前设备地址按 `iot_equip_info.address` 直接输出。
- 当前“设备类型”优先按 `iot_dic_equip.equip_type_name` 输出，未匹配到时回退 `iot_equip_info.equip_type_id`。
- 当前“所属区域”按 `iot_equip_info.district_id` 精确匹配；如果前端传的是区域树父级编码，需要改为前缀匹配。
