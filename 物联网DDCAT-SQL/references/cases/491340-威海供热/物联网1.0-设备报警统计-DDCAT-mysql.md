# 物联网1.0 设备报警统计 DDCAT 文档

## 1. 用户需求描述

查询设备报警统计数据，输出以下字段：

- 设备编码
- 设备类型
- 设备名称
- 所属区域
- 设备地址
- 报警总数
- 报警类型
- 报警频次(次/天)

查询条件：

- 统计起始时间
- 设备类型
- 报警类型
- 所属区域

说明：

- 需求属于历史报警记录统计，使用 `iot_equip_alarm` 作为报警数据口径。
- 数据库方言按默认 MySQL 编写。

## 2. 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `startTime` | String | 是 | 统计起始时间，例如 `2026-04-01 00:00:00` |
| `endTime` | String | 否 | 统计结束时间，例如 `2026-04-15 00:00:00`；不传默认按当前时间 `NOW()` |
| `equipTypeId` | String | 否 | 设备类型ID（建议传入，符合设备口径默认规则） |
| `valueTypeId` | String | 否 | 报警类型ID |
| `districtId` | String | 否 | 区域编码，用于匹配 `iot_equip_info.district_id` |

## 3. 输出字段说明

| 字段名 | 说明 |
|---|---|
| `设备编码` | `iot_equip_info.equip_code` |
| `设备类型` | `iot_equip_info.equip_type_id` |
| `设备名称` | `iot_equip_info.equip_name` |
| `所属区域` | `iot_equip_info.district_name` |
| `设备地址` | `iot_equip_info.address` |
| `报警总数` | 时间范围内报警记录条数 |
| `报警类型` | `iot_equip_alarm.value_type_id` |
| `报警频次(次/天)` | `报警总数 / 统计天数`，保留两位小数 |

## 4. DDCAT SQL 脚本

统计涉及多条件过滤和聚合，建议在 DDCAT 中添加缓存，建议 `10-15` 分钟。

```sql
#if (startTime != null && startTime != '')
SELECT
    ei.equip_code AS 设备编码,
    ei.equip_type_id AS 设备类型,
    ei.equip_name AS 设备名称,
    ei.district_name AS 所属区域,
    ei.address AS 设备地址,
    COUNT(*) AS 报警总数,
    a.value_type_id AS 报警类型,
    ROUND(
        COUNT(*) / GREATEST(
            TIMESTAMPDIFF(
                SECOND,
                '${startTime}',
                COALESCE(NULLIF('${endTime}', ''), NOW())
            ) / 86400.0,
            1
        ),
        2
    ) AS `报警频次(次/天)`
FROM iot_equip_alarm a
INNER JOIN iot_equip_info ei
    ON a.equip_id = ei.equip_id
#tag where()
    AND ei.valid_flag = 1
    AND a.alarm_time >= '${startTime}'
    #if (endTime != null && endTime != '')
        AND a.alarm_time < '${endTime}'
    #end
    #if (equipTypeId != null && equipTypeId != '')
        AND ei.equip_type_id = '${equipTypeId}'
    #end
    #if (valueTypeId != null && valueTypeId != '')
        AND a.value_type_id = '${valueTypeId}'
    #end
    #if (id != null && id != '')
        AND ei.district_id = '${districtId}'
    #end
#end
GROUP BY
    ei.equip_id,
    ei.equip_code,
    ei.equip_type_id,
    ei.equip_name,
    ei.district_name,
    ei.address,
    a.value_type_id
ORDER BY 报警总数 DESC, 设备名称 ASC, 设备编码 ASC
#else
SELECT
    CAST(NULL AS CHAR(64)) AS 设备编码,
    CAST(NULL AS CHAR(64)) AS 设备类型,
    CAST(NULL AS CHAR(128)) AS 设备名称,
    CAST(NULL AS CHAR(128)) AS 所属区域,
    CAST(NULL AS CHAR(255)) AS 设备地址,
    CAST(NULL AS SIGNED) AS 报警总数,
    CAST(NULL AS CHAR(64)) AS 报警类型,
    CAST(NULL AS DECIMAL(18,2)) AS `报警频次(次/天)`
WHERE 1 = 2
#end
```

## 6. 计算逻辑说明

### 6.1 报警总数

- 数据来源：`iot_equip_alarm`
- 统计口径：满足筛选条件的报警记录 `COUNT(*)`

### 6.2 报警频次(次/天)

计算公式：

```text
报警频次(次/天) = 报警总数 / 统计天数
```

统计天数口径：

- 使用 `startTime` 到 `endTime` 的秒差除以 `86400`
- 若未传 `endTime`，使用当前时间 `NOW()`
- 使用 `GREATEST(..., 1)` 兜底，避免除零

### 6.3 过滤条件

- 时间：`a.alarm_time >= startTime`，`a.alarm_time < endTime`
- 设备类型：`ei.equip_type_id = equipTypeId`
- 报警类型：`a.value_type_id = valueTypeId`
- 所属区域：`ei.distric_id LIKE CONCAT(id, '%')`（按区域编码前缀筛选）

## 7. 可执行 SQL（示例参数）

```sql
SELECT
    ei.equip_code AS 设备编码,
    ei.equip_type_id AS 设备类型,
    ei.equip_name AS 设备名称,
    ei.district_name AS 所属区域,
    ei.address AS 设备地址,
    COUNT(*) AS 报警总数,
    a.value_type_id AS 报警类型,
    ROUND(
        COUNT(*) / GREATEST(
            TIMESTAMPDIFF(
                SECOND,
                '2026-04-01 00:00:00',
                '2026-04-15 00:00:00'
            ) / 86400.0,
            1
        ),
        2
    ) AS `报警频次(次/天)`
FROM iot_equip_alarm a
INNER JOIN iot_equip_info ei
    ON a.equip_id = ei.equip_id
WHERE ei.valid_flag = 1
  AND a.alarm_time >= '2026-04-01 00:00:00'
  AND a.alarm_time < '2026-04-15 00:00:00'
  AND ei.equip_type_id = '501'
  AND a.value_type_id = '2'
  AND ei.district_id = '371002'
GROUP BY
    ei.equip_id,
    ei.equip_code,
    ei.equip_type_id,
    ei.equip_name,
    ei.district_name,
    ei.address,
    a.value_type_id
ORDER BY 报警总数 DESC, 设备名称 ASC, 设备编码 ASC;
```

## 8. 备注

- 当前设备地址按 `iot_equip_info.address` 直接输出。
- 若前端展示需要设备类型名称，可在 SQL 中补充设备类型字典表关联（当前按类型ID输出）。
