# 企业月度设备低温报警记录数统计

## 1. 用户需求描述

统计企业月度设备低温报警记录数，查询参数为一个月的开始时间和结束时间，输出字段为：

- 企业名称
- 低温报警记录数

业务口径如下：

- 低温报警记录数 = 一个月内低温报警类型的报警记录条数
- 企业名称不能为空
- 按低温报警记录数降序排序
- 仅返回前 9 条
- 数据库语法使用瀚高数据库

说明：

- 低温报警通过 `iot_equip_alarm.value_type_id` 进行筛选
- 本统计口径关联 `iot_equip_info`，按技能规则默认增加设备类型参数 `equipTypeId`
- 当前按企业名称 `manufacturer_name` 分组，不包含 `manufacturer_id`

## 2. 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `startTime` | String | 是 | 查询开始时间，例如 `2026-03-01 00:00:00` |
| `endTime` | String | 是 | 查询结束时间，例如 `2026-04-01 00:00:00` |
| `equipTypeId` | String | 是 | 设备类型ID，按技能规则默认增加 |
| `valueTypeId` | String | 是 | 低温报警类型ID |

## 3. 输出字段说明

| 字段名 | 说明 |
|---|---|
| `企业名称` | 企业名称，来源于 `iot_equip_info.manufacturer_name` |
| `低温报警记录数` | 时间范围内企业低温报警记录总数 |

## 4. DDCAT SQL 脚本
统计较复杂，建议添加ddcat缓存，建议10分钟
```sql
#if (startTime != null && startTime != '' && endTime != null && endTime != '')
    SELECT
        ei.manufacturer_name AS 企业名称,
        COUNT(*) AS 低温报警记录数
    FROM iot_equip_alarm a
    INNER JOIN iot_equip_info ei ON a.equip_id = ei.equip_id
    #tag where()
        AND ei.valid_flag = 1
        AND ei.manufacturer_name IS NOT NULL
        AND TRIM(ei.manufacturer_name) <> ''
        AND a.value_type_id = '${valueTypeId}'
        AND a.alarm_time >= '${startTime}'
        AND a.alarm_time < '${endTime}'
        #if (equipTypeId != null && equipTypeId != '')
            AND ei.equip_type_id = '${equipTypeId}'
        #end
    #end
    GROUP BY ei.manufacturer_name
    ORDER BY 低温报警记录数 DESC, 企业名称 ASC
    LIMIT 9
#else
    SELECT
        CAST(NULL AS VARCHAR(200)) AS 企业名称,
        CAST(NULL AS NUMERIC(18,0)) AS 低温报警记录数
    WHERE 1 = 2
#end
```

## 6. 计算逻辑说明

### 6.1 报警记录来源

低温报警记录来自 `iot_equip_alarm` 表，通过：

```sql
a.value_type_id = '${valueTypeId}'
```

识别低温报警类型。

### 6.2 企业筛选

企业信息来自 `iot_equip_info`，统计口径为：

- `ei.valid_flag = 1`
- `ei.manufacturer_name IS NOT NULL`
- `TRIM(ei.manufacturer_name) <> ''`

### 6.3 时间范围过滤

报警时间口径为：

```sql
a.alarm_time >= '${startTime}'
AND a.alarm_time < '${endTime}'
```

### 6.4 设备类型筛选

由于本统计口径关联 `iot_equip_info`，默认增加设备类型参数：

```sql
AND ei.equip_type_id = '${equipTypeId}'
```

### 6.5 汇总与排序

- 按企业名称 `manufacturer_name` 分组统计报警记录数
- 按 `低温报警记录数` 降序
- 同值时按企业名称升序
- 仅返回前 `9` 条

## 7. 可执行 SQL

```sql
SELECT
    ei.manufacturer_name AS 企业名称,
    COUNT(*) AS 低温报警记录数
FROM iot_equip_alarm a
INNER JOIN iot_equip_info ei ON a.equip_id = ei.equip_id
WHERE ei.valid_flag = 1
  AND ei.manufacturer_name IS NOT NULL
  AND TRIM(ei.manufacturer_name) <> ''
  AND a.value_type_id = 'LOW_TEMP'
  AND a.alarm_time >= '2026-03-01 00:00:00'
  AND a.alarm_time < '2026-04-01 00:00:00'
  AND ei.equip_type_id = '1001'
GROUP BY ei.manufacturer_name
ORDER BY 低温报警记录数 DESC, 企业名称 ASC
LIMIT 9;
```

## 8. 备注

- 当前低温报警类型使用参数 `valueTypeId` 传入，如果后续已经固定低温报警类型编码，可以将该条件写死
- 当前按企业名称 `manufacturer_name` 分组，不包含 `manufacturer_id`
- 当前写法基于瀚高数据库兼容 PostgreSQL 的 SQL 语法
