# Color Theory Reference — 色彩理论参考

---

## 一、色彩模式选择指南

| 使用场景 | 推荐模式 | 原因 |
|----------|----------|------|
| 功能性图标（UI导航、工具栏） | 纯色 | 清晰易辨，不分散注意力 |
| 品牌图标（LOGO附件、营销） | 渐变 | 视觉冲击强，品牌感强 |
| 小程序/APP | 纯色或极简渐变 | 小尺寸清晰度优先 |
| PPT/汇报 | 渐变或莫兰迪色 | 整体统一，专业感强 |
| 插画风图标 | 多色+轻渐变 | 表现力丰富 |

## 三、渐变色彩搭配原则

### 类比色渐变（和谐、统一）
- 蓝→青：`#1677ff → #13c2c2`
- 紫→粉：`#722ed1 → #eb2f96`
- 绿→青：`#52c41a → #13c2c2`

### 对比色渐变（活力、冲击）
- 橙→蓝：`#fa8c16 → #1677ff`
- 红→紫：`#f5222d → #722ed1`

### 渐变方向推荐

| 方向 | linearGradient 参数 | 适合场景 |
|------|---------------------|----------|
| 垂直（上→下） | `x1="0" y1="0" x2="0" y2="1"` | 自然感、重力感 |
| 水平（左→右） | `x1="0" y1="0" x2="1" y2="0"` | 流动感、进度感 |
| 对角（左上→右下） | `x1="0" y1="0" x2="1" y2="1"` | 现代感、动感 |
| 反对角（右上→左下） | `x1="1" y1="0" x2="0" y2="1"` | 个性、设计感 |

### 渐变品质分级

| 等级 | 特征 | 代表色组 |
|------|------|----------|
| 极简渐变 | 同色系浅→深，差异小 | `#667eea → #764ba2` |
| 自然渐变 | 相邻色相，过渡自然 | `#56ab2f → #a8e063` |
| 霓虹渐变 | 高饱和对比色，强烈 | `#f72585 → #4cc9f0` |
| 金属渐变 | 中性灰+高亮，质感强 | `#b8c6db → #f5f7fa` |

## 四、WCAG 无障碍对比度规范

### 对比度要求

| 等级 | 最低对比度 | 适用场景 |
|------|------------|----------|
| AA（推荐） | 4.5:1（普通文字）/ 3:1（大文字） | 通用UI |
| AAA（最高） | 7:1 | 无障碍场景 |

### 常见背景色下推荐图标色

**白色背景（#ffffff）下推荐图标色：**
```
深蓝: #1677ff  → 对比度 3.82:1（大图标可用）
深灰: #262626  → 对比度 15.3:1 ✅
品牌蓝: #0958d9 → 对比度 6.2:1 ✅
```

**深色背景（#141414）下推荐图标色：**
```
白色: #ffffff   → 对比度 19.7:1 ✅
浅灰: #d9d9d9   → 对比度 13.2:1 ✅
亮蓝: #69b1ff   → 对比度 8.1:1 ✅
```

## 五、常见场景配色方案

### 金融/理财类图标
```yaml
主色: "#1677ff"   # 信任、专业
辅色: "#52c41a"   # 增长、盈利
警示: "#f5222d"   # 风险
中性: "#8c8c8c"   # 说明
```

### 健康/医疗类图标
```yaml
主色: "#13c2c2"   # 清洁、安全
辅色: "#52c41a"   # 健康
强调: "#1677ff"   # 专业
```

### 科技/数码类图标
```yaml
渐变: ["#667eea", "#764ba2"]   # 科技紫
渐变: ["#4cc9f0", "#4361ee"]   # 科技蓝
纯色: "#1677ff"               # 清晰蓝
```

### 生活/消费类图标
```yaml
主色: "#fa8c16"   # 温暖、活力
渐变: ["#fbbf24", "#f87171"]  # 日落橙红
辅色: "#eb2f96"               # 粉红活力
```

### 教育/学习类图标
```yaml
主色: "#1677ff"               # 专业蓝
渐变: ["#43e97b", "#38f9d7"]  # 清新绿
辅色: "#722ed1"               # 学术紫
```
