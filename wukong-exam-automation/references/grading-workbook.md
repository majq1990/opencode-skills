# 阅卷分配表生成

## 原则

直接复制原始阅卷模板，保留格式、截图列、公式、行高、列宽和阅卷细表。不要重建细表。

## 总表列建议

总表保留这些列：大区、区域、姓名、工号、岗位体系、备注、阅卷地址、账号、备注、实操阅卷人、实操分数、实操通过情况、笔试分数、笔试通过情况、综合分数、综合通过情况。

备注列设置为 `wordWrap=clip`，固定列宽和数据行高。

## 考官 sheet

1. 清空旧考生姓名和旧阅卷记录。
2. 保留每名考生 3 列：扣分、扣分说明、得分。
3. 第 1 行放考生姓名，第 2 行放子表头，第 3 行放总扣分/总得分公式。
4. 未作答人员不进入考官 sheet，进入 `未作答（0分）`。

## 总表公式

`实操分数` 不手填，按 `实操阅卷人` 和姓名联动：

```text
=IF(J2="",0,IFERROR(IF(J2="考官1",INDEX('考官1'!3:3,MATCH(C2,'考官1'!1:1,0)+2),IF(J2="考官2",INDEX('考官2'!3:3,MATCH(C2,'考官2'!1:1,0)+2),IF(J2="考官3",INDEX('考官3'!3:3,MATCH(C2,'考官3'!1:1,0)+2),0))),0))
```

综合分使用容错公式，避免未阅卷时 `#VALUE!`：

```text
=SUM(IFERROR(K2*0.7,0)+IFERROR(M2*0.3,0))
```

通过情况按 70 分线。

## 校验

- 总表人员数等于参考人员数。
- 未作答 sheet 人员等于无页面无项目查询结果。
- 考官 sheet 截图列仍有图片单元格。
- 公式校验 0 错误。
- 笔试成绩匹配结果有摘要。
