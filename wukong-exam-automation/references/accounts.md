# 人员名单与账号录入

## 输入字段

人员名单至少需要：

- 姓名
- 工号
- 岗位/岗位体系
- 大区/区域
- 是否参考

可选字段：悟空账号、考官/实操阅卷人、备注。

## 处理规则

1. 只处理 `是否参考=是` 的人员。
2. 若名单已有账号，优先使用名单账号。
3. 若无账号，按历史规则从姓名和工号派生，生成后必须输出映射清单供核对。
4. 导入前查询现有 `wukong.com_user`，避免重复插入。
5. 导入后抽查账号能登录悟空入口。

## SQL 注意事项

- 不改 `admin`。
- 写入前备份或至少导出将影响的账号列表。
- 密码、盐值和加密方式沿用当前环境约定；最终答复不要明文展开密码散列。
- 对失败账号单独列出姓名、账号、原因。
