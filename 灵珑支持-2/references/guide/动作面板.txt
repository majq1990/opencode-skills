动作面板
简介
用户可以通过【动作面板】去写 JS 代码，从而实现自己的业务逻辑或逻辑判断。
通过动作面板，可以更加方便的组织和复用代码实现复杂交互。
编辑脚本，在“高级-绑定动作”里引用。

2.2 内置动作显示/隐藏组件
绑定动作中设置组件的展示与隐藏
使用前置动作控制选项值，选择选项一隐藏单行文本1，选择选项二展示单行文本1
function handleRadioChange(){
  let _this = this;
  let flag = _this.getText();
  let disqualifiedReasonComponent = _this.$("text_input_6pfiby");
  if(flag == '选项一'){
 //当单选组件选择是时，默认的隐藏下拉多选组件
    disqualifiedReasonComponent.setBehavior("HIDDEN");
  }else if(flag == '选项二'){
 //当单选组件选择是时，默认的显示下拉多选组件
    disqualifiedReasonComponent.setBehavior("NORMAL");
  }
}
2.3 自定义动作
自定义动作 面板支持自己编写 js 代码，js 代码至少为一个可执行函数
可点击“全屏”按钮或取更大的脚本编辑空间，并可以引用已有的脚本模板，全屏模式修改完之后需要点击右上角确定按钮将编辑的内容带回。
可以点击“验证”按钮，验证脚本是否有明显的语法问题
2.4 动作弹框-页面JS
可以给整个表单绑定动作也可给单个组件绑定动作，例如给单行文本组件绑定动作，选择高级-添加绑定动作，可以选择：
onAddonAfterClick(扩展组件单击)
onChange(值修改后)
onFocus(获得焦点后)
onBlur(失去焦点后)
动作面板中通过 export function 导出的函数名，会在动作面板中被识别
在动作弹窗中新增动作，会在动作面板添加一个空的函数，格式如：export function xxx() {}
通过 this.params 获取参数
可以在页面JS中绑定要执行的函数，并设置参数

2.5 前置动作
前置动作基于js脚本，为执行响应动作之前的动作，主要用来做前置条件判断，以决定后续动作是否执行，故必须要返回true或者false
2.6 后置动作
后置动作基于js脚本，是在执行响应动作完成之后再执行的动作，比如响应动作为打开表单新增数据，新增之后，需要刷新列表，一般是在后置动作中进行配置。
