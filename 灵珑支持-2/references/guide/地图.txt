5 轨迹播放
PC端和移动端均可以播放轨迹
5.1 移动端轨迹播放
移动端预览时打开地图，当前人员有轨迹信息时自动定位到轨迹位置，下方显示轨迹日期和时间段，显示轨迹播放的进度条和倍速，默认为1.0X，可选0.5X，2.0X，5.0X。
当切换倍速后轨迹播放停止。可以在进度条上拖动快进查看轨迹，拖动后不改变轨迹的播放状态；
切换日期和时间，图上实时显示轨迹位置，没有轨迹时不显示，播放按钮置灰。
5.2 PC端轨迹播放
PC端预览表单时打开地图，可以设置地图加载完时显示轨迹，也可以通过点击按钮显示轨迹。
人员轨迹：当前人员有轨迹信息时自动定位到轨迹位置，下方显示轨迹日期和时间段，显示轨迹播放的进度条和倍速，进度条显示的是有轨迹的时间段，倍速默认为1.0X，可选0.5X，1.0X，2.0X，5.0X，10.0X和20.0X。
当切换倍速后轨迹播放停止。可以在进度条上拖动快进查看轨迹，拖动后不改变轨迹的播放状态；
在指定的可见图层可以看见轨迹上显示箭头，箭头的宽度和间隔，也可以不显示箭头。
切换日期和时间，图上实时显示轨迹位置，没有轨迹时不显示，播放按钮置灰。
5.3 移动端轨迹配置
步骤主要是给“地图”组件增加“轨迹图层”，添加触发轨迹图层的按钮或动作入口，添加动作脚本，打开移动表单时地图上就会显示轨迹位置和播放轨迹的工具栏。
图上数据要求：地图服务里包含人员或车辆轨迹数据。数据准备参见：
在移动表单部件选中“地图”组件，在“图层”配置页点【增加图层】选择“轨迹图层”。
点击列表里的轨迹图层，可以修改样式属性：
图层名称：根据需要修改，在列表里便于区分人员或车辆等；
图层启用：默认开启，即图上显示轨迹工具栏；当关闭时图上不显示轨迹工具栏；
图层id：在触发轨迹图层的脚本里作为参数传入；
轨迹类型：人员轨迹和车辆轨迹，选中后分别可以选择人员或车辆的显示图标；
轨迹样式-箭头间隔：默认50px，值域范围[1-50]，

车辆轨迹
图标样式：

（2）车辆轨迹可选样式

5.4 PC端轨迹配置
主要配置和移动端一致。
轨迹图层的属性。
轨迹宽度：值域范围[]1-20]；
轨迹箭头：默认开启；
箭头间隔：默认50px，值域范围[1,50]；
可见层级：默认6，值域范围[1-19]；
显示轨迹的配置：
（1）第一种方式：地图组件“高级”增加“地图加载完成”动作，配置动作脚本
function main() {
  this.$$("map_base_d8il2h").$$showLocalObjectTrace("traceLayer_geaguv", 4, "2018-06-20", {}, {
        traceBreak: false,
        traceBreakThreshold: 500,
        showHeatMap: false,
        nosignalLabel: true,
        requestType: 1,
        startHour: "08:00:00",
        endHour: "22:00:00",
        tracedig: true
    })
}
参数说明：
（2）第二种方式：在表单里增加【自定义按钮】点击时触发显示轨迹
export function mappc() {
