2 变量
2.1 变量声明
在JavaScript中，变量是用于存储数据的容器，可以使用var、let和const关键字来声明变量。其中，const声明的是常量，不可更改。
// 使用 var 声明变量
var myVar = "Hello World";
console.log(myVar) // "Hello World"
myVar = "yeah"
console.log(myVar) // "yeah"

// 使用 let 声明变量
let myLet = 123;

// 使用 const 声明常量，不可再更改此常量的值
const myConst = true;
【注】建议默认使用const，如果变量的值会被改变，则使用let。var和let的区别见2.3
js变量的命名规则
变量名由 字母，数字，_，$组成，不能用数字开头。
变量名不能重复，后声明的会覆盖先声明的
// 合法的变量名
var myVar;
var _myVar;
var $myVar;
var myVar123;

// 不合法的变量名
var 123myVar; // 变量名不能以数字开头
var my-var;   // 变量名不能包含连字符
2.2 变量作用域
在JavaScript中，变量的作用域是指变量在代码中可见的范围。JavaScript中有两种作用域：全局作用域和局部作用域。
全局作用域的变量在整个代码中都可见和访问，而局部作用域的变量只在定义它们的代码块中可见和访问。以下是一个变量作用域的示例：
var globalVar = "I am a global variable";

function myFunc() {
  var localVar = "I am a local variable";
  console.log(globalVar); // 可以访问全局变量 "I am a global variable"
  console.log(localVar);  // 可以访问局部变量 "I am a local variable"
}

myFunc();
console.log(globalVar); // 可以访问全局变量 "I am a global variable"
console.log(localVar);  // 无法访问局部变量  not defined
2.3 var、let的区别
var是函数作用域，let是块作用域
使用 var 声明变量：
var x = 10;

function foo() {
  var y = 20;
  console.log(x); // 输出 10
  console.log(y); // 输出 20
}

foo();
console.log(x); // 输出 10
console.log(y); // 报错，y 未定义
在这个示例中，我们使用 var 声明了变量 x 和 y。变量 x 被声明在全局作用域中，变量 y 被声明在函数作用域中。在函数 foo() 内部，我们可以访问变量 x 和 y。在函数外部，我们只能访问变量 x，因为变量 y 的作用域被限制在函数内部。
使用 let 声明变量：
let x = 10;

if (true) {
  let y = 20;
  console.log(x); // 输出 10
  console.log(y); // 输出 20
}

console.log(x); // 输出 10
console.log(y); // 报错，y 未定义
在这个示例中，我们使用 let 声明了变量 x 和 y。变量 x 被声明在全局作用域中，变量 y 被声明在 if 语句的块级作用域中。在 if 语句块内部，我们可以访问变量 x 和 y。在 if 语句块外部，我们只能访问变量 x，因为变量 y 的作用域被限制在 if 语句块内部。
let不能在定义之前访问该变量，但是var可以。
let必须先声明，再使用。而var先使用后声明也行，只不过直接使用但没有定义的时候，其值是undefined。var有一个变量提升的过程：在变量声明之前引用变量，也不会出现错误，因为变量已经被声明了，只是还没有被赋值，默认为初始化一个undefined。
let不能被重新定义，但是var可以
因此为了避免不必要的错误，优先使用let。

3.1 数据类型分类
3.3.1 基础类型和引用类型
在JavaScript中，数据类型可以分为以下几类。
基本数据类型 6种
数字（Number）：用于表示数字，例如123。
字符串（String）：用于表示文本，必须用单引号'' 或双引号""括起来，例如"Hello World"。
布尔值（Boolean）：用于表示真或假，只有两个取值：true和false。
空值（null）：用于表示空值或不存在的值。
未定义（undefined）：用于表示未定义的值。
符号（symbol）：用于表示唯一的标识符。符号是ES6引入的新数据类型。
【注】
null、true、false，如果是用单引号'' 或双引号""括起来的就是字符串string类型。要注意区分。
引用数据类型
对象（Object）：用于表示复杂的数据结构，例如数组、函数或自定义对象。
数组（Array）：用于表示一组有序的值，例如[1, 2, 3]。
函数（Function）：用于表示可执行的代码块，可以接受输入参数并返回输出结果。

3.3.5 数据类型的隐式转换
在JavaScript中，有些情况下会发生数据类型的隐式转换。这种转换是由JavaScript引擎自动执行的，而不需要显式调用转换方法。以下是一些常见的情况：
字符串和数字的加法运算：如果一个字符串和一个数字进行加法运算，会将数字隐式转换为字符串，然后将两个字符串拼接在一起。例如：
let str = "123";
let num = 456;
console.log(str + num); // 输出 "123456"
比较运算符：如果两个值类型不同，JavaScript会尝试将它们转换为相同的类型，然后进行比较。通常情况下，字符串会被转换为数字进行比较。例如：
console.log("2" > 1); // 输出 true
console.log("01" == 1); // 输出 true
逻辑运算符：逻辑运算符&&和||会返回一个值，这个值可以是任意类型。如果运算符的两个操作数类型不同，JavaScript会将它们转换为布尔值。例如：
console.log("hello" && 0); // 输出 0
console.log(null || "world"); // 输出 "world"

4.1 算术运算符
用来进行数学运算的运算符，包括加、减、乘、除、取余等。例如：

【注意】

如果加号有一边是字符串，则另一边也转成字符串，变成字符串的拼接，需要调用 Number 方法，转成数字，再进行相加
如果有一边是对象，则对象调用 toString 得到字符串表示，再进行计算
console.log(1 + 2);// 3

4.5 三目运算符

}

5.2 循环语句
循环语句用于重复执行某段代码，常见的循环语句包括while循环、do-while循环、for循环和for...in循环。
5.2.1 for循环
for循环用于重复执行某段代码，通常用于循环次数已知的情况。语法如下：
for (initialization; condition; increment) {
  // 循环体
}
initialization用于设置循环变量的初始值；condition用于设置循环变量的结束条件；increment用于设置循环变量的递增方式。例如：
for (let i = 0; i < 4; i++) {
  console.log(i);
}
// 0 1 2 3 4
在上述代码中，循环从0开始，每次递增1，直到小于4为止。
5.2.2 for...in 循环
for...in循环用于遍历对象的属性。语法如下：
for (key in object) {
  // 循环体
}
key是一个变量名，用于存储对象的属性名；object是一个对象。例如：
let person = {
  name: "张三",
  age: 20,
  gender: "男"
};
for (let key in person) {
  console.log(key + ": " + person[key]);
}
//"name: 张三"
//"age: 20"
//"gender: 男"
【悟空中的实际应用】
区域级联选择交互案件相关的组件。需要根据选择区域的regionType传递不同字段的参数。如regionType为COUNTRY时，需传districtId=区域id，但其他级别的字段值需要清空
function converter(data) {
    const { regionType, id } = data.current;
    const dataKey = {
        "CITY": "cityId", // 市级
        "COUNTRY": "districtId", // 区级
        "STREET": "streetId", //街道级
        "COMMUNITY": "communityId", // 社区级
        "CELL": "cellId", // 网格级
    }
    for (const key in dataKey) {
        const queryKey = dataKey[key];
        data[queryKey] = ""; // 清除所有字段的值
        if (regionType === key) data[queryKey] = id; // 将对应区划层级的字段赋值为区划id，如点击区级，则 districtId = id
    }
    return data;
}
5.2.3 while 循环
while循环用于在条件为真时重复执行某段代码。语法如下：
while (condition) {
  // 当条件为真时执行的代码块
}
在每次循环中，先计算条件的值，如果为真，则执行代码块；然后再次计算条件的值，直到条件为假为止。例如：
let i = 0;
while (i < 4) {
  console.log(i);
  i++;
}
// 0 1 2 3
在上述代码中，循环从0开始，每次递增1，直到小于4为止。
5.2.4 do-while循环
do-while循环用于至少执行一次某段代码，并在条件为真时重复执行。语法如下：
do {
  // 至少执行一次的代码块
} while (condition);
先执行代码块，然后计算条件的值，如果为真，则继续循环；否则，退出循环。例如：
let i = 0;
do {
  console.log(i);
  i++;
} while (i < 4);
// 0 1 2 3
6 函数
JavaScript中的函数是一段可重复使用的代码块，可以接受输入参数并返回输出结果。函数可以用来封装一些重复的代码，以及实现某些功能。
6.1 函数的创建和调用
// 声明
        function fn(){
            console.log('i am function');
        }
        // 通过名称和括号来调用
        fn();

// 表达式声明函数
        let fn1 = function(){
            console.log('我是函数');
        }
        fn1();
函数可以被视为一个值，可以像其他值一样进行传递和存储。例如：
let func = function(x) {
  return x * x;
};
let result = func(3);
console.log(result); // 输出9
在上述代码中，函数被赋值给变量func，并可以像其他值一样进行传递和存储。
6.2 函数的传参
函数定义时，在()中可以定义任意数量的参数，该参数就可以当做函数内部的变量来使用，它可以从函数外部接收数据，拿到函数内部进行运算使用。
一般来说，在声明函数时，所写的参数叫做 形参（占位，等待接收数据，也可以当作变量）；在调用时 传递的真正的数据值，称为实参。
将实参传递给形参，也可以当作给形参变量赋值。
// 声明函数时  定义形参
function sum(n1,n2){
    console.log(n1,n2);
    console.log(n1 + n2)
}

//调用函数，将实参传递给形参
sum(10,30);
let a = 12; 
let b = 13;
sum(a,b)
6.3 函数的返回值
函数可以返回一个值，这个值可以被存储在一个变量中，供函数外部使用这个值。
函数使用关键字return来返回结果。
函数中默认就有return返回值，如果没有写，默认返回undefined。
返回的值可以是任意类型。
return一次只能返回一个数据，当希望返回多个值时，使用数组或对象。
例如：
function square(x) {
  return x * x;
}
let result = square(2);
console.log(result); // 输出4
在上述代码中，square函数接受一个参数x，并返回它的平方值。
同理，悟空的数据过滤函数filter接收一个参数data，是此组件接口返回的数据。在这个函数中对数据进行一定处理并返回。
function filter(data) { // data为组件的静态数据/动态数据接口返回的数据
  // 在过滤函数中对数据进行处理
   return data;
}
【注意】当函数执行遇到了return就返回了，return后写的所有代码都不再执行。
function f1(a, b) {
  console.log(a)
   return a;
  console.log(b)
}

f1(1,2); //  1
6.4 箭头函数
箭头函数可以更简洁地定义函数，适用于一些简单的函数。
语法如下：
(parameters) => { statement }
其中，parameters是函数的参数列表，可以是0个或多个参数，多个参数之间用逗号分隔；statement是函数的执行语句，可以是一条语句或多条语句，如果是多条语句则需要用花括号括起来。
例如，以下是一个使用箭头函数定义的加法函数：
let sum = (num1, num2) => num1 + num2;
// 等同于
let sum = function(num1, num2) {
  return num1 + num2;
};
sum(2, 3) // 5
在上述代码中，使用箭头函数定义了一个加法函数sum，它接受两个参数num1和num2，并返回它们的和。因为箭头函数只有一条语句，所以可以省略花括号和return关键字。
let f1 = () => 5;//不需要参数或需要多个参数，就使用一个圆括号代表参数部分。
// 等同于
let f1 = function () { return 5 };
【注】如果返回的内容为对象，需加上()避免歧义。
//由于大括号被解释为代码块，所以如果箭头函数直接返回一个对象，必须在对象外面加上括号，否则会报错。
// 报错
let getTempItem = id => { id: id, name: "Temp" };

// 不报错
let getTempItem = id => ({ id: id, name: "Temp" });

8.3 数组的循环遍历
数组通常用于存储一组有序的数据，例如字符串、数字、对象等。在实际开发中，我们经常需要对数组进行遍历，以执行一些操作，例如：访问数组中的每个元素，并对每个元素执行一个操作；查找或过滤数组中符合条件的元素；将数组中的每个元素映射为另一个值，并构建一个新的数组等。
以下是数组遍历的常见方法。
8.3.1 every()
用于检查数组中的所有元素是否满足指定的条件，并返回一个布尔值。
接受一个参数，即一个回调函数，该回调函数用于检查每个元素是否满足条件。如果所有元素都满足条件，则返回true，否则返回false。
在遇到第一个不满足条件的元素时就会停止检查，并返回false。
如果数组为空，则every()方法将返回true
let arr = [2, 4, 6, 8];
let isEven = arr.every(function(element) {
  return element % 2 === 0;
});
console.log(isEven); // 输出 true
在上述代码中，every()方法被用来检查数组arr中的所有元素是否都是偶数。在执行every()方法之后，回调函数会对数组中的每个元素进行检查，如果所有元素都是偶数，则返回true。
8.3.2 some()
用于检查数组中是否存在符合指定条件的元素，并返回一个布尔值。
接受一个参数，即一个回调函数，该回调函数用于检查每个元素是否符合条件。如果至少一个元素符合条件，则返回true，否则返回false。
在遇到第一个符合条件的元素时就会停止检查，并返回true。
如果数组为空，则some()方法将返回false。
let arr = [1, 3, 5, 7];
let hasEven = arr.some(function(element) {
  return element % 2 === 0;
});
console.log(hasEven); // 输出 false
在上述代码中，some() 方法被用来检查数组arr中是否存在偶数。在执行some()方法之后，回调函数会对数组中的每个元素进行检查，如果至少一个元素是偶数，则返回true。
8.3.3 map()
用于遍历数组中的每个元素，并对每个元素执行一个函数，然后将返回的结果存储在一个新数组中。
不会修改原始数组，而是返回一个新的数组。
let arr = [1, 2, 3];
let doubleArr = arr.map(function(element) {
  return element * 2;
});
console.log(doubleArr); // 输出 [2, 4, 6]
在上述代码中，map()方法被用来将数组arr中的每个元素乘以2，并将结果存储在一个新数组doubleArr中。
可以使用箭头函数简化map()方法的使用，例如。
let arr = [1, 2, 3];
let doubleArr = arr.map(element => element * 2);
console.log(doubleArr); // 输出 [2, 4, 6]
在数据过滤中的使用示例如下。
let arr1 = [
  {name:"1",text:"类型1",num:1},
  {name:"2",text:"类型2",num:2},
  {name:"3",text:"类型3",num:3},
]

let res = arr1.map(g=>{
  return {
    value: g.num,
    name: g.name,
    text: g.text
  }
})
console.log(res) // 返回一个新数组
8.3.4 forEach()
用于遍历数组中的每个元素，并对每个元素执行一个函数。
let arr = ["apple", "banana", "orange"];
arr.forEach(function(element) {
  console.log(element);
});
// 输出 "apple", "banana", "orange"
在上述代码中，forEach()方法被用来遍历数组arr中的每个元素，并对每个元素执行一个函数，将元素打印到控制台上。
在数据中的使用示例如下。
let arr1 = [
  {name:"1",text:"类型1",num:1},
  {name:"2",text:"类型2",num:2},
  {name:"3",text:"类型3",num:3}
]

arr1.forEach(g=>{
  g.value = g.num;
  console.log(g.text)
})
【注】map()方法与forEach()方法的区别。
forEach()方法不会返回一个新的数组，而是对每个元素执行一次回调函数。而map()方法会返回一个新的数组，其中包含对每个元素执行回调函数后的结果。
forEach()方法会对数组中的每个元素执行回调函数，但不会使用回调函数的返回值。而map()方法会对数组中的每个元素执行回调函数，并使用回调函数的返回值来构建一个新的数组。
8.3.5 filter()
用于遍历数组中的每个元素，并对每个元素执行一个函数，返回一个新数组，其中包含满足条件的元素。
let arr = [-1, 2, 3, 4, 5];
let newArr = arr.filter(function(element) {
  return element > 0;
});
console.log(newArr); // 输出 [2, 3, 4, 5]
在上述代码中，filter()方法被用来筛选数组arr中大于0的数，并将结果存储在一个新数组newArr中。
可以使用箭头函数简化filter()方法的使用，例如。
let arr = [-1, 2, 3, 4, 5];
let newArr = arr.filter(() => element > 0);
console.log(newArr); // 输出 [2, 3, 4, 5]
8.3.6 reduce()
用于将数组中的所有元素合并为一个单独的值。
接受一个参数，即一个回调函数，该回调函数用于对数组中的每个元素执行操作，并返回一个累加值。
回调函数接受两个参数，即累加器和当前值，其中累加器是上一次调用回调函数时返回的值，而当前值是当前元素的值。
let arr = [1, 2, 3, 4, 5];
let sum = arr.reduce(function(accumulator, currentValue) {
  return accumulator + currentValue;
}, 0);
console.log(sum); // 输出 15
在上述代码中，reduce()方法被用来将数组arr中的所有元素相加，并将结果存储在变量sum中。
可用箭头函数简化使用。
let arr = [1, 2, 3, 4, 5];
let sum = arr.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
console.log(sum); // 输出 15

let max = arr.reduce((accumulator, currentValue) => Math.max(accumulator, currentValue));
console.log(max); // 输出 5

let average = arr.reduce((accumulator, currentValue, index, array) => {
  accumulator += currentValue;
  if (index === array.length - 1) {
    return accumulator / array.length;
  } else {
    return accumulator;
  }
}, 0);
console.log(average); // 输出 3
在上述代码中，箭头函数和展开运算符被用来简化reduce()方法的使用。第一个例子用来计算数组arr中所有元素的和；第二个例子用来查找数组arr中的最大值；第三个例子用来计算数组arr中所有元素的平均值。

10.2 dayjs
dayjs是一个轻量级的JavaScript日期库，用于解析、验证、操作和格式化日期。在悟空脚本配置中常使用它的API来处理与时间有关的参数。
10.2.1 dayjs() 解析日期
使用dayjs()函数来解析日期，它可以接受一个日期字符串和格式化字符串作为参数，或者接受一个JavaScript Date对象作为参数。例如：
const date1 = dayjs('2022-05-19');
const date2 = dayjs('2022-05-19', 'YYYY-MM-DD');
const date3 = dayjs(new Date());
10.2.2 format() 格式化日期
使用format()方法来将日期格式化为指定的字符串。它接受一个格式化字符串作为参数，例如：
const date1 = dayjs('2022-05-19');
const formattedDate = date1.format('YYYY年MM月DD日');
console.log(formattedDate); // 输出 2022年05月19日
10.2.3 startOf()  endOf() 开始时间 结束时间
用于返回一个新的dayjs对象，该对象表示从当前日期或时间开始或结束的时间段。
接受一个字符串作为参数，该字符串指定了要返回的时间段。这些时间段包括“year”（年份）、“month”（月份）、“week”（周）、“day”（日）、“hour”（小时）、“minute”（分钟）和“second”（秒）。
dayjs().startOf('day').format('YYYY-MM-DD HH:mm:ss') // 今天00:00:00
dayjs().endOf('day').format('YYYY-MM-DD HH:mm:ss') // 今天23:59:59
dayjs().startOf('month').format('YYYY-MM-DD HH:mm:ss') // 本月第一天
dayjs().endOf('month').format('YYYY-MM-DD HH:mm:ss') // 本月最后一天
dayjs().startOf('year').format('YYYY-MM-DD HH:mm:ss') // 今年第一天
dayjs().endOf('year').format('YYYY-MM-DD HH:mm:ss') // 今年最后一天
10.2.4 subtract() 减去指定的时间量
用于从一个日期中减去指定的时间量。它接受一个数字和一个时间单位作为参数，并返回一个新的dayjs对象，表示减去指定时间量后的日期。
const date1 = dayjs('2022-05-19');
const date2 = date1.subtract(1, 'day'); // 从date1减去1天
const date3 = date1.subtract(1, 'month'); // 从date1减去1月
const date4 = date1.subtract(1, 'year'); // 从date1减去1年

console.log(date1.format('YYYY-MM-DD')); // 输出 2022-05-19
console.log(date2.format('YYYY-MM-DD')); // 输出 2022-05-18
console.log(date3.format('YYYY-MM-DD')); // 输出 2022-04-19
console.log(date4.format('YYYY-MM-DD')); // 输出 2021-05-19
在上述代码中，使用1dayjs()1 函数创建一个表示指定日期的dayjs对象date1。然后，使用subtract()方法从date1对象中减去1天、1个月和1年，并分别创建3个新的dayjs对象date2、date3和date4。最后，使用format()方法将这些dayjs对象格式化为指定的日期字符串，并输出它们的值。
悟空中常见的场景为获取近7天、近1月、近1年的时间参数。
dayjs().format('YYYY-MM-DD HH:mm:ss')
// 时间加减(加传负数) 年:year 月:month 日:day 时:hour 分:minute 秒:second   
dayjs().subtract(1, 'year').format('YYYY-MM-DD HH:mm:ss') // 当前时间减一年
dayjs().subtract(30, 'day').format('YYYY-MM-DD HH:mm:ss') // 当前时间减30天
dayjs().subtract(7, 'day').format('YYYY-MM-DD HH:mm:ss') // 当前时间减7天
10.2.5 add() 加上指定的时间
用于给当前日期加上指定的时间量。它接受一个数字和一个时间单位作为参数，并返回一个新的dayjs对象，表示加上指定时间量后的日期。
const date1 = dayjs('2022-05-19');
const date2 = date1.add(1, 'day');
const date3 = date1.add(1, 'month');
const date4 = date1.add(1, 'year');

console.log(date1.format('YYYY-MM-DD')); // 输出 2022-05-19
console.log(date2.format('YYYY-MM-DD')); // 输出 2022-05-20
console.log(date3.format('YYYY-MM-DD')); // 输出 2022-06-19
console.log(date4.format('YYYY-MM-DD')); // 输出 2023-05-19
10.2.6 isBefore() isSame()  isAfter() 日期的比较
使用isBefore()、isSame()和isAfter()方法来比较两个日期的先后顺序。它们接受一个日期对象作为参数，例如：
const date1 = dayjs('2022-05-19');
const date2 = dayjs('2022-05-20');

console.log(date1.isBefore(date2)); // 输出 true
console.log(date1.isSame(date2)); // 输出 false
console.log(date1.isAfter(date2)); // 输出 false
