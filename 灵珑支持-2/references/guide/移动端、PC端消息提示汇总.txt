移动端、PC端消息提示汇总
1 使用场景
在一些表单、列表的按钮交互中，用户点击后可以提示用户操作是否成功，或者一些比较耗时的操作，可以用loading效果，让用户很直观的感受到这个耗时操作要等等，又或者某些场景，用户需要选择一些数据才能进行后续操作，这时候可以使用警告提示，提醒用户需要选择数据后才能进行后续的操作等等。
2 效果
PC端成功提示：
PC端失败（错误）提示：
PC端常规提示：
PC端警告提示：
PC端加载提示：
移动端成功提示：
移动端失败（错误）提示：
移动端加载提示：
3 配置
在任意需要提示的地方，选择下面脚本里，对应的提示脚本即可：
function main() {

    // PC端提示消息    
    this.$message.success('成功消息'); // PC端成功消息
    this.$message.error('错误消息'); // PC端错误消息
    this.$message.info('常规消息'); // PC端常规消息
    this.$message.warn('警告消息'); // PC端警告消息
    this.$message.warning('警告消息'); // PC端警告消息
    this.$message.loading('加载中'); // PC端加载中消息

    // 移动端提示消息
    this.$ztToast.success('操作成功'); // 移动端成功消息
    this.$ztToast.fail('操作失败'); // 移动端失败消息
    this.$ztToast.loading('加载中'); // 移动端加载中消息

}
