# 数据源选择规则

> 用途：判断优先走悟能接口、现场接口、ddcat 还是 SQL 查询。

## 外部数据源边界

本 skill 默认只处理悟空大屏组件数据对接，不主动获取公网真实数据。用户提出“查询、统计、展示某类数据”时，先理解为需要寻找可对接的数据来源、确认 `result` 契约、生成字段映射和过滤脚本，而不是直接联网查公开网页。

默认不得主动调用 `web_search`，也不得把公网网页、公开统计网站或第三方搜索结果作为默认数据源。只有用户明确要求“联网查询”“查询公开数据”“使用公网数据源”时，才可以使用联网搜索；联网结果只能作为参考资料，最终仍需回到现场接口、SQL/ddcat、字段映射和组件 `result` 契约。

## 优先级

1. 优先检索悟能接口索引 `domain_indexes/wuneng_api_index.md`。
2. 命中候选且 detailDoc 可确认字段、筛选、统计粒度和返回结构时，优先推荐悟能接口。
3. 悟能接口无法满足或当前索引无可确认接口时，再进入 fallback。
4. fallback 按现场状态选择一种路径：已有接口、暂无接口但有表/查询逻辑、接口和表都不明确。

## 悟能接口推荐要求

推荐悟能接口时必须输出：

- 接口名称；
- 请求方式；
- 接口地址；
- 星桥接口路径地址；
- 响应主路径；
- 响应形态。

`接口地址` 是真实调用路径，例如 `/api/cgdb/vehicle/group`。

`星桥接口路径地址` 必须来自 `dexApiPath` 或用户材料。`dexApiPath` 为空、缺失或待确认时，输出：

```text
星桥接口路径地址：待确认
```

不要把接口地址和星桥接口路径地址混用。

## 不能编造的信息

不得凭经验编造：

- 接口地址；
- 请求方式；
- 请求参数；
- 响应字段；
- 嵌套返回结构；
- 统计口径；
- 表名；
- 字段名；
- 星桥接口路径地址。

## detailDoc 优先级

`domain_indexes/wuneng_api_index.md` 只用于接口粗筛，不能替代接口详情文档。

- 索引命中且有 `detailDoc` 时，先读详情文档再推荐接口、映射或脚本。
- 详情文档优先级高于索引摘要。
- 如果索引与详情文档冲突，以详情文档为准，并在需要核对的内容中提示现场核对。
- 如果 page/detail/list/tree 类接口缺少详情文档，同时用户要求字段映射或脚本，应停在 Gate 0 的“接口资料待补充”。
