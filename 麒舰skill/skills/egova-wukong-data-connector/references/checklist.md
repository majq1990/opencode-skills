# 悟空大屏数据对接门禁检查清单

> 用途：作为 `SKILL.md` 的快速复核清单，确保生成字段映射和 `function filter(data)` 前没有跳过关键门禁。

## 1. Gate -1：先粗检索悟能接口

- [ ] 已基于用户原始描述检索 `domain_indexes/wuneng_api_index.md`。
- [ ] 已按业务域、业务对象、场景、关键词、统计维度、筛选条件和适配组件综合判断候选接口。
- [ ] 已排除仅由泛化关键词造成的误命中；业务域不一致时未推荐跨域接口。
- [ ] 未命中时只说明“当前索引未找到可确认接口”，不套用其他业务域接口。
- [ ] 命中候选时，已优先读取 `knowledge/api_flat.md` 中对应摘要。
- [ ] 命中候选且存在 `detailDoc` 时，已读取对应详情文档。

## 2. Gate 0：只澄清阻塞项

- [ ] 已判断是否存在会改变接口选择、入参、统计结果、返回结构或脚本写法的歧义。
- [ ] 存在阻塞项时，只输出通用 Markdown 文本卡片并停止。
- [ ] `已确认` 只包含用户已明确给出的事实，不包含推测字段、假设表名或方案建议。
- [ ] 可枚举缺口用 `### 请选择` + 编号项，且 A/B/C/D 选项写成编号项下的嵌套无序列表（`- A. ...`），不能顶格，也不要只用空格加 `A.` 文本；默认建议项放 A 且不标注“推荐”，最后一个选项保留“其他，请说明：____”；长文本资料用 `### 请补充` + 编号填空。
- [ ] 待补充项让用户直接回复选项字母或补空白，不要求重发完整需求。
- [ ] 多个清单同时出现时，序号全局连续。
- [ ] 停在 Gate 0 时，没有输出结论、映射、过滤脚本或假设字段。
- [ ] 用户需求明确指向具体个人健康信息、身份可识别信息、个人隐私或单个自然人查询时，已停止输出个人查询方案，只保留按区域、组织、时间等维度汇总统计且不返回个人明细的补充清单；没有使用“脱敏”“匿名化”“匿名统计”等措辞。


## 3. 静态模板状态

- [ ] 用户已提供悟空组件静态数据模板，或已确认现场没有模板。
- [ ] 有现场模板时，以现场模板作为目标 `result` 形状。
- [ ] 无现场模板时，才结合展示目标和 `knowledge/component_static_schema.md` 推荐 `result` 格式，并标注待现场确认。

## 4. 数据源选择

- [ ] 推荐悟能接口时，输出接口名称、请求方式、接口地址和星桥接口路径地址。
- [ ] `dexApiPath` 为空、缺失或待确认时，输出 `星桥接口路径地址：待确认`，不自行编造。
- [ ] 悟能无法满足时，按现场已有接口、暂无接口但有表/查询逻辑、接口和表都不明确三种状态之一分支补充。
- [ ] 未在用户明确要求联网查询、查询公开数据或使用公网数据源前，没有调用 `web_search`，也没有把公网搜索结果当作默认数据源。

## 5. 字段映射

- [ ] 已说明原始来源字段到组件目标字段的映射关系。
- [ ] 已区分确认字段、样例推断字段和待现场确认字段。
- [ ] 原始结构与目标结构一致时，明确说明无需复杂转换，仅做空值兜底。

## 6. 过滤脚本

- [ ] 脚本为完整 `function filter(data) { ... }`。
- [ ] 默认 `data` 是公司响应外层的 `result` 本体，除非用户明确说明传入完整响应包。
- [ ] 使用 ES5 写法：`var`、传统 `function`，不使用箭头函数、`let`、`const`、可选链。
- [ ] 包含基础兜底：空 `data`、期望数组但非数组、空数字字段、空字符串字段。
- [ ] 返回组件期望的 `result` 数据形状，而不是原始接口响应。

## 7. 最终输出

- [ ] 默认只输出四段：结论、映射、过滤脚本、需要核对的内容。
- [ ] “需要核对的内容”只列落地前需要现场核对的联调事项，不作为继续向用户索要阻塞信息的入口。
- [ ] 需要用户继续输入才能生成正确方案时，已停在 `### 请补充`，没有进入最终四段式。
- [ ] 非阻塞默认假设写在结论中，不放入“需要核对的内容”。
- [ ] 表 / SQL fallback 未说明数据库类型时，普通聚合 SQL 默认按 MySQL 兼容写法；没有把“数据库/schema”当默认阻塞项。
- [ ] 不输出需求摘要、PRD、计划或完整思考过程。
