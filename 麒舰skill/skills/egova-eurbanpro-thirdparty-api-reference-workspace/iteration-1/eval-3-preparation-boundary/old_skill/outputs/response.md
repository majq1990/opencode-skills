# 第三方联调前准备材料与账号

这个问题超出了当前 api-reference skill 的范围。

本 skill 专注于回答具体的 API 接口、字段、请求示例和协议规则等问题。您询问的"联调前需要准备什么材料和账号"属于**总体接入方案设计**和**前置配置**范畴，不在本 skill 处理范围内。

**建议您使用 `preparation-guide`（第三方对接前置指南）skill 来获取以下内容：**
- 联调前需要准备哪些账号（如 openapi_token 申请）
- 需要哪些前置材料和配置
- 接入模式的判断与选择
- 字段对齐方案

如果您在准备工作完成后，需要查询某个具体接口的参数、请求示例或字段规则，欢迎回来使用本 skill。
