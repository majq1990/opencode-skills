# 动作自定义脚本实战踩坑集

来源：灵珑认证考题二「PC工作台（新）」联调实战（2026-07-25，考核环境 8.130.36.66:8080）。
适用于灵珑页面构建器写 onclick / didMount / onChange 等自定义动作脚本的通用场景。

## 空容器被框架隐藏

**现象**：echarts.init 拿到 0×0 节点，图画不出来。设计态容器可见，预览/运行态消失。

**原因**：灵珑给无子组件的容器加 `empty` class → CSS `display:none`。JS 操作前确认目标容器里放了至少一个组件（如文本组件），不在「隐藏容器」里。

**验证**：`getComputedStyle(el).display` ≠ `none`；`el.offsetWidth > 0`。

## 页面存在重复实例，id 不唯一

**现象**：`getElementById('xxx_csshandler_generate')` 拿到的是背景页实例，点击/修改无效果。
自测：预览弹窗里有完整页面渲染 + 页面背后有一个全尺寸渲染实例（Vue2/Vue3 选项或背景页），两套同 id 的 `_csshandler_generate` 节点。

**解法**：用 `querySelectorAll` 过滤可见性，永远取弹窗内那份：

```js
var all = Array.from(document.querySelectorAll('[id="组件id_csshandler_generate"]'));
var target = all.filter(function(el) {
    var r = el.getBoundingClientRect();
    return r.width > 0 && r.height > 0;
}).pop();
```

此模式用于：取容器（echarts.init）、取按钮（模拟点击）、取下拉（读实时值）、取日期输入框（读 value）。

## 动作脚本只允许一个顶层 main

**现象**：脚本贴进去保存，点预览弹窗 → 整体脚本不执行（页面加载异常但无显式错误）。控制台报 `TypeError: Cannot read properties of undefined (reading 'bind')`。

**原因**：灵珑动作执行器通过正则提取 `function main(context)` 为入口，顶层辅助函数打乱解析。`buildEmptyAxis` 等工具函数必须放在 main 函数体内部。

**例外**：页面JS（页面JS动作执行器）和部件设计器里可能不同，但自定义动作/生命周期全部只认一个 `main`。

## $$setValue 后值未渲染同步

**现象**：重置按钮的清空 `$$setValue([])` + 设日期 + 立刻触发查询 → 查询读到旧条件，数据没变，要点第二次查询才正确。

**原因**：`$$setValue` 是异步的，组件模型更新后 DOM 输入框和 `$$model(...).props.defaultValue` 的同步需要一次 tick。立即触发的查询读到的仍是旧值。

**解法**：轮询 DOM 确认新值已渲染再触发查询（最多 3 秒超时兜底）：

```js
var expectStart = '2026-07-01'; // 刚设的日期
var tryClick = function(times) {
    var pickers = Array.from(document.querySelectorAll('[id="日期组件_csshandler_generate"]'));
    var picker = pickers.filter(function(el) { ...可见性过滤... }).pop();
    var inputs = picker ? picker.querySelectorAll('input') : [];
    var domStart = inputs.length >= 2 ? (inputs[0].value || '') : '';
    var btn = 同上可见性过滤拿查询按钮;

    if (btn && domStart.indexOf(expectStart) === 0) { btn.click(); return; }
    if (times > 0) { setTimeout(function() { tryClick(times - 1); }, 200); }
    else if (btn) { btn.click(); } // 超时兜底
};
tryClick(15);
```

## $$model defaultValue 同步有延迟

**现象**：改了日期下拉立刻点查询，数据不是新条件的。

**原因**：`$$model('xxx').props.defaultValue` 在组件初始渲染后不会随用户交互实时更新，部分场景下用户操作后 model 未同步。

**解法**：日期范围控件直接读 DOM 输入框的 `value` 属性（总是当前值），model 只做回退：

```js
var startRaw = '', endRaw = '';
try {
    var pickers = Array.from(document.querySelectorAll('[id="日期组件_csshandler_generate"]'));
    var picker = ...可见性过滤...;
    var inputs = picker ? picker.querySelectorAll('input') : [];
    if (inputs.length >= 2) { startRaw = inputs[0].value || ''; endRaw = inputs[1].value || ''; }
} catch(e) {}
if (!startRaw && !endRaw) { /* 回退 model */ }
```

select 下拉被清空时 `$$model().props.defaultValue` 可能为 null，`.value` 读前加 `&&` 守卫。

## onChange 值提交时序

**现象**：下拉（天/周/月）切换后，onChange 动作触发查询，查询的 `$$getFormValue()` 读到旧粒度。

**原因**：onChange 触发瞬间，表单值可能尚未提交到外层的表单 render 对象。

**解法**：onChange 里把新粒度写 window 全局，查询脚本优先读全局再回退表单值：

onChange 脚本：
```js
var els = Array.from(document.querySelectorAll('[id="下拉_csshandler_generate"]'));
var sel = ...可见性过滤...;
var label = sel ? sel.textContent.trim() : '';
var map = { '天': 'day', '周': 'week', '月': 'month' };
Object.keys(map).forEach(function(k) {
    if (label.indexOf(k) === 0) window.__xxxVal = map[k];
});
// 延迟触发查询
```

查询脚本取值：
```js
var cicleType = window.__xxxVal || formData.root_700mg8.single_select_4darpr;
```

## 表单部件改动作必须保存+发布

**现象**：在「日周月切换」表单部件的组件高级面板配了 onChange 脚本，预览切换下拉没反应。

**原因**：表单部件设计器里的修改只存到部件源，页面引用的部件版本未更新。必须点表单设计器的「保存」+「发布」，页面才能接收到新版本的动作配置。

## Monaco 编辑器残留旧内容

**现象**：用 `keyboard.insertText` 或粘贴脚本后，语法错误 `Unexpected token`。

**原因**：脚本编辑器中若 `Ctrl+A` 未全选（焦点在别处或编辑器内有 hidden layer），旧代码+新代码叠加混在一起。

**解法**：每次改完点「验证」按钮；报错则清空编辑器再重贴。

## 下拉/日期弹层展开时点击被吞

**现象**：弹层（antd calendar/select dropdown）展开状态下点查询按钮，第一次点击无响应。

**原因**：antd 弹层的遮罩或事件机制拦截了第一次点击（用于关闭弹层），第二次才落到按钮。

**解法**：操作习惯上先点空白处关弹层再点查询；非脚本问题。

## ECharts 图表渲染要点

- 容器必须可见且有尺寸（`offsetWidth > 0`）才能 init/setOption
- `echarts.getInstanceByDom(dom) || echarts.init(dom)` 防重复 init
- `setOption(opt, true)` 第二参 notMerge 防止粒度切换时数据叠加
- `setTimeout(() => chart.resize(), 300)` 防容器后布局完成导致挤压变形
- scroll/流动容器里 `resize` 监听只注册一次
- 空数据也要出图：按查询范围生成全 0 轴，yAxis min/max 加全 0 保护
- 面积图样式参考：`smooth:true, showSymbol:false, areaStyle 线性渐变, label:false, xAxis boundaryGap:false, axisLabel interval:'auto'`

## didMount 生命周期自动刷新

**坑**：`self.$$('查询按钮').$el.click()` 在 didMount 会拿到背景重复实例，点无效。

**解法**：轮询直到找到可见按钮再触发，同「页面存在重复实例」模式。

```js
function main(context) {
    var tryClick = function(times) {
        var all = Array.from(document.querySelectorAll('[id="查询按钮_csshandler_generate"]'));
        var target = all.filter(function(el) {
            var r = el.getBoundingClientRect();
            return r.width > 0 && r.height > 0;
        }).pop();
        var btn = target && target.querySelector('button');
        if (btn) { btn.click(); return; }
        if (times > 0) setTimeout(function() { tryClick(times - 1); }, 500);
    };
    setTimeout(function() { tryClick(10); }, 500);
    return;
}
```
