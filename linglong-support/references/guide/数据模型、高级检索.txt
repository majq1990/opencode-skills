后置字段拼接使用场景
现场数据量太大，单纯用视图的性能不行；
列表的查询字段需要处理复杂逻辑，例如需要实现在工单描述字段中输入“AAA，BBB”需要在sql中需要查出来既包含AAA，也需要包含BBB的数据；
需要根据用户权限来判断过滤当前人是否有查看全部部门的数据，还是只能查看自己部门数据的优先过滤；
需要注意的点目前这种方式构建的列表，无法根据字段升序降序排列。

String formatTaskNumbers(String taskNum) {
    if (!taskNum?.trim()) return "''"
    
    def buffer = new StringBuilder()
    int start = 0
    int end = taskNum.indexOf(',')
    
    while (end != -1) {
        def num = taskNum.substring(start, end).trim()
        if (num) buffer.append("'${num.replace("'", "''")}',") // 处理单引号转义
        start = end + 1
        end = taskNum.indexOf(',', start)
    }
    
    def lastNum = taskNum.substring(start).trim()
    if (lastNum) buffer.append("'${lastNum.replace("'", "''")}'")
    
    buffer.length() > 0 ? buffer.toString() : "''"
}
