# **一、试题背景**

现需在灵珑平台中配置一个移动端流程办理应用，用于支撑违建问题从新增上报到处置、核查、核实、办结的全流程闭环。

完成表单设计、流程模板配置、移动端列表配置、节点办理配置和移动端办理页面创建。包括：
1. 移动端可新增一条违建问题数据，并自动启动流程；
2. 数据按流程依次进入处置、核查、核实、办结节点；
3. 各节点可在移动端查看待办数据并进行办理；
4. 办理过程支持批转下一节点，符合要求的节点支持退回上一节点；
5. 已办结数据进入查阅列表，可查看基本信息和办理经过。
6. 系统自动生成案件号，并在各节点列表中展示，用于识别当前办理案件。

# 三、配置任务要求（20分）

## **1\. 流程模板配置**

需在灵珑中配置流程模板，要求如下：
1. 流程包含开始节点、结束节点，以及处置、核查、核实、办结四个业务节点；
2. 处置节点由处置员01账号受理，可将数据批转至核查节点；
3. 核查节点由核查员01账号受理，可退回至处置节点，也可批转至核实节点；
4. 核实节点由核实员01账号受理，可退回至核查节点，也可批转至办结节点；
5. 办结节点由管理员01账号受理，可退回至核实节点，也可进行办结处理；
6. 各节点办理表单字段应可见、可编辑，案件号字段除外；
7. 节点流转后，数据应进入下一节点对应的移动端列表。



## **2\. 表单设计**

| 案件号 | 流水号 | 否 | 自动生成，流水号格式按年月日生成 |
| 信息来源 | 文本输入 | 是 | 用于记录问题来源 |
| 产权单位 | 文本输入 | 是 | 用于记录产权单位 |
| 联系人 | 文本输入 | 是 | 用于记录联系人 |
| 使用单位 | 文本输入 | 是 | 用于记录使用单位 |
| 违建位置 | 文本输入 | 是 | 用于记录违建位置 |
| 创建时间 | 日期时间 | 是 | 用于记录创建时间 |

## **3\. 移动端页面列表**

移动端页面需配置 5 个 tab，分别为：
1. 处置；
2. 核查；
3. 核实；
4. 办结；
5. 查阅。

各 tab 列表需展示以下字段：

| **字段** | **说明** |
|----------|----------|
| 案件号 | 案件唯一编号 |
| 节点名称 | 当前流程节点 |
| 处理人 | 当前节点处理人 |
| 创建时间 | 数据创建时间 |
| 操作按钮 | 待办节点显示“办理” |

## **4\. 处置 tab 要求**

处置 tab 需满足以下要求：
1. 列表展示字段为案件号、节点名称、处理人、创建时间；
2. 列表操作按钮为“办理”；
3. 处置列表上方或页面右下角需配置新增悬浮按钮；
4. 点击新增悬浮按钮后打开新增表单；
5. 处置员01账号新增数据后，数据应自动启动流程并进入处置节点；
6. 处置员01账号可在处置 tab 中办理该数据，并批转至核查节点；
7. 数据批转后，应从处置 tab 待办列表移出，进入核查 tab。



## **5\. 核查 tab 要求**

核查 tab 需满足以下要求：
1. 核查员01账号登录后，可在核查 tab 查看从处置节点批转过来的数据；
2. 列表展示字段与处置 tab 一致；
3. 操作按钮为“办理”；
4. 办理时表单字段可见、可编辑，文号字段除外；
5. 可将数据退回处置节点；
6. 可将数据批转至核实节点。



## **6\. 核实 tab 要求**

核实 tab 需满足以下要求：
1. 核实员01账号登录后，可在核实 tab 查看从核查节点批转过来的数据；
2. 列表展示字段与处置 tab 一致；
3. 操作按钮为“办理”；
4. 办理时表单字段可见、可编辑，文号字段除外；
5. 可将数据退回核查节点；
6. 可将数据批转至办结节点。



## **7\. 办结 tab 要求**

办结 tab 需满足以下要求：
1. 管理员01账号登录后，可在办结 tab 查看从核实节点批转过来的数据；
2. 列表展示字段与处置 tab 一致；
3. 操作按钮为“办理”；
4. 办理时表单字段可见，文号字段除外；
5. 可将数据退回核实节点；
6. 可对数据进行办结处理；
7. 办结后，该数据应进入查阅 tab。



## **8\. 查阅 tab 要求**

查阅 tab 需满足以下要求：
1. 展示已办结数据；
2. 巡查员01账号可查看已办结数据；
3. 列表展示字段案件号、创建人、创建时间、结束时间；
4. 可查看数据基本信息；
5. 可查看办理经过；
6. 查阅 tab 不应提供继续办理按钮。



## **9\. 移动办理页面创建**

需在移动应用中创建移动办理页面，并将该页面与流程办理、列表操作、新增入口正确关联。

移动办理页面需满足：

可承载新增表单；

可承载各节点办理表单；

可根据当前节点展示正确的办理按钮；

可查看基本信息和办理经过；

在移动端访问时布局正常、字段清晰、按钮可点击。

# **四、流程验证要求**

完成配置后，需按以下路径验证：
1. 使用处置员01账号登录移动端；
2. 进入处置 tab，点击新增悬浮按钮；
3. 填写信息来源、产权单位、联系人、使用单位、违建位置并提交；
4. 数据启动流程并出现在处置 tab；
5. 处置员01办理并批转至核查；
6. 使用核查员01账号登录，确认数据出现在核查 tab；
7. 核查员01办理，可验证退回处置，也可批转至核实；
8. 使用核实员01账号登录，确认数据出现在核实 tab；
9. 核实员01办理，可验证退回核查，也可批转至办结；
10. 使用管理员01账号登录，确认数据出现在办结 tab；
11. 管理员01办理，可验证退回核实，也可办结；
12. 使用巡查员01账号登录，确认办结数据出现在查阅 tab，并可查看基本信息和办理经过。
