## 2. 通用判别原则（重要）

1. **效果优先**：先看查看模式（#/view）的呈现效果，配置/接口核查为辅。
2. **查看+编辑双模式**：查看模式看效果；编辑模式（URL 把 `view` 改成 `create`）看组件树、数据页接入方式、图层列表。两者同时开。
3. **动态接口 vs 静态数据**（2.2.x 核心判别）：编辑模式选中模块 → 右侧「数据」页 → 看「接入方式」：
   - 静态数据 = 没走接口 → 该行接口+数据分全扣
   - 动态数据 = 走了接口 → 再看接口分类/过滤器是否正确
   - 模板自带的静态占位值（高发来源：120巡查上报/50市民投诉/20热线12345/190智能上报/78微信上报/13其他）**值不变 = 没走接口**
4. **地图没点位 = 效果不存在**：图层类（2.4.x/2.5.3/2.6.x）若地图上无点位/无效果，即使配置在也按效果不存在判扣；但有配置操作痕迹可给操作记录分（如 0.5）。
5. **交互类看行为**：点击/切换后要有预期效果（弹窗打开、图层显隐、数据变化、请求重发）。弹窗出现但内容空白、图层无变化都算未实现。
6. **截图比对**：2.1.x 必须与阅卷表 E 列示例截图/模板大屏（悟空认证大屏-城管秩序，pageId 4813ea09-82da-4c95-923b-ea19f21e3fc8）逐项比对。
7. **核心扣分点对应评分说明**：按每行的分项结构扣（如 2.3.2 有「反查2分+下拉框4分」两个子项，分别判定，不能一票全扣）。

- 交互链：`POST /wukong-api/free/interaction/chain`（**交互链在这里，不在 page/detail 的 interaction 字段**，后者全 null 是正常的）
- 弹窗/页面组件的交互是否生效看行为；page-hook 为空不代表无交互
