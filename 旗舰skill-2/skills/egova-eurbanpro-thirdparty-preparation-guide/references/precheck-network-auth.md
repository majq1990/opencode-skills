# 前置检查：网络、授权、代理人

## 适用信号
- 还没开始联调。
- 现场一开始就报 404、认证错误、代理用户认证失败。

## 必做检查
### 网络
- 第三方 -> 我方：第三方需要调用我方麒舰接口。
- 我方 -> 第三方：我方需要访问第三方附件 URL。
- 如果附件需要回拉，必须验证我方服务器能访问第三方多媒体地址。

### 应用与凭证
- 每个第三方都应在应用管理中新增一个应用。
- 新增后同步 `clientId`、`clientSecret` 给第三方。
- 第三方拿到凭证后，按标准链路获取 token。

### 对接系统配置
关键字段：
- `sys_code` / 应用编码
- `client_id` / `client_secret`
- `agent_username`
- `local_flag`
- `auto_assign_flag`

### 对接代理人
- 对接代理人对应的是用户中心中的登录账号。
- 建议每个第三方独立账号，避免越权。
- 若报“非当前案件办理人”“无权限进行该操作”，先查代理人是否有岗位权限。

### 配置刷新
- 完成配置后调用 `/unity/openapi/config/clear-sys-config`。
- 不刷新时，现场常出现“表里改了，但实际调用仍旧失败”的现象。

## 快速结论
只要网络、应用凭证、对接系统、代理人、配置刷新这 5 件事没做完，就不要开始判断接口参数本身。
