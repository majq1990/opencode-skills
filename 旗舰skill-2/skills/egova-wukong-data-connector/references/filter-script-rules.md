# 过滤脚本规则

> 用途：生成悟空大屏可直接粘贴的 `function filter(data)`。

## 入参约定

默认 `data` 是公司接口外层响应的 `result` 本体。

公司接口完整外层通常类似：

```json
{
  "hasError": false,
  "result": [],
  "message": null,
  "tag": null,
  "totalCount": 0
}
```

但悟空默认把外层 `result` 传给 `filter(data)`，所以脚本默认不要访问：

- `data.result`；
- `data.totalCount`；
- `data.hasError`。

只有用户明确说明传入完整响应包，或组件确实需要完整外层信息时，才处理这些字段。

## ES5 兼容

脚本必须使用 ES5 写法：

- 使用 `var`；
- 使用传统 `function`；
- 不使用箭头函数；
- 不使用 `let` / `const`；
- 不使用可选链；
- 不使用现代数组或对象语法作为默认方案。

## 基础兜底

脚本至少考虑：

- `data` 为空；
- 期望数组但实际不是数组；
- 数字字段为空、非数字或字符串数字；
- 字符串字段为空；
- 来源字段缺失。

## 返回要求

返回组件期望的 `result` 数据形状，而不是原始接口响应。

如果来源 `result` 与目标组件静态数据格式一致，可以只做空值兜底。

## 字段映射先于脚本

只有映射和过滤策略清楚后才生成完整脚本。生成脚本前先形成轻量过滤策略，必要时参考 `templates/filter_patterns.md`：

- 输入形状：array、object、number、tree、page rows；
- 输出形状：组件期望的 `result` 结构；
- 字段映射：来源字段、目标字段、类型；
- 兜底策略：数组、字符串、数字、对象缺失时如何返回；
- 是否需要排序、截取 TopN、分组或树转平铺。

如果关键字段、数组路径、分页路径或统计口径未确认，先停在 Gate 0，不要写假设脚本。
