# 部署流程指南

## 一、首次部署完整流程（7 步）

### 前置条件
- 以 **root 用户**登录主控服务器
- 服务器操作系统在支持列表内（见 `os-compatibility.md`）
- 系统时间与互联网时间一致
- 已获取部署包（oneinstall_v2 目录完整）

### 步骤 0: 进入部署目录
```bash
cd /path/to/oneinstall_v2
chmod +x install.sh
./install.sh
```

### 步骤 1: 安装本地源（菜单选项 `0`）

**为什么需要**: 信创环境通常没有互联网，本地源提供所有依赖包的离线安装能力。

**执行方式**:
- Ubuntu 系统: 自动调用 `i_create_repo_apt.sh`，基于 apt 源
- 其他系统: 自动调用 `i_create_repo_yum.sh`，基于 yum 源

**源文件位置**: `src/repo/` 目录下按 OS 分类存放的 rpm/deb 包

**预期结果**: 
- 显示本地源创建成功
- 自动安装主控节点工具软件（unzip、arthas、安全检测工具等）
- 自动处理磁盘挂载

**常见问题**:
- 如果报"安装本地源失败"，说明缺少依赖包，需要将缺失包放到 `src/repo/` 对应 OS 目录下重新执行
- 本地源会通过 Nginx 提供服务（端口 7777），确保防火墙放行

### 步骤 2: 安装 Ansible（菜单选项 `1`）

**为什么需要**: Ansible 是所有自动化部署任务的核心引擎。

**自动执行的操作**:
1. 安装 Ansible（Ubuntu 用 apt，其他用 yum）
2. Anolis 系统额外安装 `ansible-core` + `community-general`/`community-postgresql` 集合
3. 配置 `/etc/ansible/ansible.cfg`：
   - `gathering = explicit`（不自动收集 facts）
   - 开启日志 `/var/log/ansible.log`
   - 关闭跳过主机显示
4. 自动检测并设置主控机 IP，写入 `ansible/group_vars/all.yml`
5. 安装 NTP 服务端
6. 安装 JDK（主控节点需要）

**预期结果**: 显示"安装完成"

**注意**: NTP 已安装，请确保服务器时间正确。如有互联网可用 `ntpdate ntp.aliyun.com` 同步。

### 步骤 3: 增加服务器（菜单选项 `2`）

**为什么需要**: 告诉主控机有哪些子控节点需要管理。

**支持的操作**:
| 操作 | 说明 |
|---|---|
| `0` 添加服务器 | 输入 IP + SSH 端口，自动配置 SSH 免密，同步本地源配置 |
| `a` 增加 IP 地址 | 仅添加 IP（RDS 云数据库场景，不执行免密） |
| `1` 删除服务器 | 从节点列表中移除 |

**添加服务器的完整流程**:
1. 输入服务器 IP（自动校验格式）
2. 输入 SSH 端口（默认读取 `all.yml` 中的 `devops_ssh_port`，通常为 22）
3. 自动执行 SSH 免密配置（生成 ed25519 密钥对，复制公钥到目标机器）
4. 自动同步配置到目标服务器：
   - `/etc/os-release`
   - yum 源配置文件 `/etc/yum.repos.d/egova-oneinstall-local.repo`
   - 磁盘自动挂载脚本 `automount.sh`

**节点信息存储位置**: `ansible/inventory/hosts.yml`

### 步骤 4: 应用服务部署（菜单选项 `3`）

这是核心步骤。选择后进入二级菜单：

#### 4.1 选择服务类型
| 选项 | 说明 |
|---|---|
| 1 | V14 智信云标准（标准城管） |
| 2 | 麒舰平台微服务 |
| 3 | 基础平台微服务（灵珑、悟空、星桥、用户中心等） |
| 4 | 一网统管业务线微服务 |
| 5 | 城市运管服微服务 |
| 6 | 城市生命线微服务 |
| 7 | 执法业务线微服务 |
| 8 | GIS 微服务 |
| 9 | AI 微服务 |
| 10 | 明镜执法微服务 |

#### 4.2 选择部署方式（仅选项 1 和 10 有子选项）

**一站式部署** (`i_one_software.sh`):
- 所有服务装在同一台服务器
- 选择一个节点 → 自动将所有角色绑定到该节点 → 执行安装
- 适用: 演示、测试、小型项目

**分布式部署** (`i_multi_software.sh`):
- 不同角色分配到不同服务器
- 交互式配置每台服务器对应的角色（IP 配置界面）
- 支持增加从节点（如数据库从库）
- 自动校验: 必填项检查、IP 重复检查、主从约束检查
- 适用: 生产环境

**轻量化部署** (`i_tiny_software.sh`):
- 只安装标记为 `tiny_flag=1` 的核心组件
- 选择一个节点 → 自动安装
- 适用: 资源受限环境

**单独微服务安装**（选项 3-9）:
- 通过 `i_microservice.sh` 交互式安装
- 流程: 选择微服务 → 配置依赖组件 → 选择目标服务器 → 执行安装
- 适用: 按需部署特定微服务

#### 4.3 分布式部署的 IP 配置规则

界面中显示的编号规则：
- 纯数字（如 `1`、`2`）: 主节点
- 数字+序号（如 `21`）: 从节点1
- `x` 前缀: 特殊关联选择（如 GIS 关联服务器）
- `a` 前缀: 增加从节点
- `y`: 确认配置开始安装
- `N`: 删除对应服务器配置

**自动校验规则**:
- 带 `*` 的为必填项
- 业务库和统计库主节点不能在同一台服务器
- MIS 有从节点时，人脸服务只能装在从节点
- TDengine 和 TDengine3 不能在同一台服务器
- ES 服务器存在时，对应 Web 服务器不能为空

#### 4.4 安装执行流程

`i_common_software.sh` 是所有部署模式的通用安装引擎：

1. **修改 MySQL 代理配置** — 判断是否需要 Cetus 代理
2. **生成待安装元数据** — 从 `multi_server.yml` 生成到 `metadata.yml`
3. **按类型依次安装**:
   - software（MySQL、Redis、Nginx、Nacos 等）
   - microservice（灵珑、悟空、星桥等）
   - service（Tomcat 类应用）
4. **灵珑组件初始化** — 如果存在灵珑服务
5. **配置出口 Nginx** — 自动配置反向代理路由
6. **输出部署信息** — 显示所有服务的 IP、端口、登录地址

### 步骤 5: 配置出口 Nginx（菜单选项 `101`）

**使用场景**: 微服务独立部署时，手动配置 Nginx 路由。

**操作流程**: 选择微服务类型 → 选择出口 Nginx 节点 → 自动配置路由

> 注意: 分布式/一站式部署会自动配置出口 Nginx，通常不需要手动执行。

### 步骤 6: 基准检查（菜单选项 `b`）

**检查内容**:
- Redis 连接检查
- 各节点性能基线

**操作**: 输入 Redis 连接信息（IP、端口、密码）→ 自动检查所有已添加节点

### 步骤 7: 安全加固（菜单选项 `p` / `s`）

- `p` 系统打补丁: 选择服务器 → 执行内核优化 + 安全补丁
  - **注意**: 执行后 root 用户禁止密码登录，只能密钥+密码方式
  - 新增 egova 用户（默认密码 Z@Tpwd@2024，首次登录需改密码）
- `s` 安全加固工具箱: 弱密码检测、漏洞 JAR 检测等

## 二、菜单选项 `4` — 软件部署工具箱

适用于**单独安装**某个软件组件（非完整场景部署）。

**支持的软件**（在 `ansible/inventory/software_tools.yml` 中配置）:
- MySQL、Redis、Nginx、Nacos、Zookeeper、Kafka
- MinIO、Elasticsearch、TDengine
- Cetus（数据库代理）
- 等

**操作流程**: 选择软件 → 配置参数（端口、密码等） → 选择目标服务器 → 安装

## 三、菜单选项 `m` — 一键切换信创数据库

**支持的数据库**: 达梦(dm)、PostgreSQL、瀚高(highgo)

**操作流程**:
1. 选择目标数据库类型
2. 选择产品类型（微服务 / 智信云）
3. 输入数据库连接信息（IP、端口、用户名、密码、Schema）
4. 自动修改所有节点的数据库连接配置（jdbc.properties / .env 文件）
5. 通过 Ansible 批量推送到所有节点

**涉及文件**:
- 微服务: `{base_path}/{service_name}.env` 中的 `--DATASOURCE_URL` 等配置
- 智信云: `{base_path}/{app_name}/WEB-INF/classes/jdbc.properties`

```
系统登录用户     : admin
系统登录用户密码 : xxxxxx
部署Wiki  : http://faq.egova.com.cn:7777/...
------------------------------------------
```

```bash
cat ansible/inventory/metadata.yml
```
