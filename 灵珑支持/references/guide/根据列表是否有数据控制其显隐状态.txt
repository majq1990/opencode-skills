根据列表是否有数据控制其显隐状态
1 使用场景
一个详情页面中有多个列表，当有的列表没有数据时仍然会显示暂无数据而不是隐藏自身，会导致页面看起来比较臃肿，所以要对没有数据的列表进行隐藏
具体场景：有一个改造计划的列表，通过点击计划名称跳转到详情页，详情页中有两个列表用来显示改计划关联的改造进展，改造进展分为两大类，显示的字段不同所以需要用两个列表进行区分显示，当列表没有数据的时候隐藏列表。
2 效果
该计划为立管类型，所以只有立管类型列表有数据，另外一个列表因为没有数据会被隐藏
3 配置
在详情页的列表加载事件中写入如下脚本
代码中出现的网格项id查看示例。
function main() {
    //获取列表中数据数量
    let isData = this.dataList.length;
    //获取网格项，此处列表放在了网格项中，需要将整个网格项都隐藏。网格项的id需要F12进行查看
    let list = document.querySelector("#root_26zapl #layout-grid-lite-item_2p9kuq8mad7g");
    //如果列表没有数据则隐藏存放该列表的网格项
    if (isData == 0) {
        list.style = "display:none";
    } else {
        list.style = "";
    }
}
