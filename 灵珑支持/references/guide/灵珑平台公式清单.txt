数据库公式
1、SQL_QUERY_AND  可将多个条件进行拼接
表达式：SQL_QUERY_AND([condition1, condition2...])
入参：List<String> conditions  SQL条件列表
返回值：
类型：String 文本
返回值规则：多个SQL条件用AND拼接成多个条件语句
示例：
SQL_QUERY_AND(["'name='小华'", "'age'=12"])
返回结果：'name'='小华'  AND  'age'=12
2、SQL_QUERY_EQ  过滤某个组件的值等于指定值的数据
表达式：SQL_QUERY_EQ(String pageId, String version, String columnId, Object value)
入参：
pageId：必须。表单id
version ：必须。 表单版本
columnId：必须。实体表字段的id
value 必须。字段的值
返回值：
类型：String 文本
返回值规则：根据传入的columnId获取数据库字段名，用value实际值，拼接陈SQL的一个等于条件语句
示例：
SQL_QUERY_EQ(String pageId, String version, String columnId, Object value)
返回结果：'column'='value'
3、SQL_QUERY_GT  过滤某个数字组件的值大于指定值的数据

入参：

10、SQL_COUNT 统计公式
表达式：SQL_COUNT(String tableId, , String conditions)
入参：
tableId：必须。数据库实体id
conditions  SQL条件语句
返回值：
类型：统计数 Long
返回值规则：通过传入实体ID和where条件语句，统计数据条数
示例：
SQL_COUNT('t_5c20f29945dd472a883b94fdf9590b2b', QUERY_AND(QUERY_EQ('level', 4),QUERY_EQ('location', '美国')))
转义成统计查询SQL为：select count(1) from XXX where level=4 and location='美国'，将根据条       件获取统计数量。

conditions  SQL条件语句
返回值：
类型：数值
返回值规则：通过传入实体ID和where条件语句，返回某字段的最小值
示例：
SQL_MIN('t_5c20f29945dd472a883b94fdf9590b2b', 'f_83358f79a5f94c17af2a05f213eb67eb', ENTITY_QUERY_EQ('b49a7f25-3a70-41e1-9539-bf6487df6e26',15))，
转义成查询SQL为：select min(1) from XXX where level=4 and location='美国'

时间公式
1、DATE  转换日期对象
表达式：DATE(Long... params)
入参：
params：整数数组
返回值：
类型：文本 String
返回值规则：DATE(timestamp) 或 DATE(year, month, day) 或 DATE(year, month, day, hour, minute, second) 返回时间为 yyyy-MM-dd'T'HH:mm:ss.SSS'Z'
示例：
. DATE(1582180320545),返回2020-02-20T14:32:00.545Z。
. DATE(2020, 2, 20)，返回2020-02-20T00:00:00.000Z。
. DATE(2020, 2, 20, 14, 32, 0)，返回2020-02-20T14:32:00.000Z

入参：(String date, int deltaDays, boolean isWorkDay)
date: 日期文本
deltaDays:  加/减天数
isWorkDay:  是否工作日
返回值：
类型：文本
返回值规则：
示例：
DATECALCULATE('2020-03-20T01:17:35.000Z',1,false)
返回 Sat Mar 21 09:17:35 CST 2020
