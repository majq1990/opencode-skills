按钮和地图位置联动
1 使用场景
列表和表单或详情部件在同一页面时，通过按钮向表单或详情部件传参。
具体的业务场景：列表中有一行的数据中存放了地址和x、y坐标，需要通过点击查看位置按钮使右侧地图进行定位操作，将对应的位置显示在地图上。
2 效果
用户点击一条数据中的查看按钮，右侧地图定位这条数据的位置。
3 配置
使用详情部件，在详情中使用地图位置组件，将视图中查询到的x和y坐标放入。
在页面中查看位置按钮点击事件中加入如下脚本。其中park_id是详情部件关联的视图中存在的数据，且这条数据中有x和y坐标才能实现定位。（由于详情部件和列表部件存在于同一个页面，导致无法通过弹窗或打开页面的方式进行传参，需要使用脚本传参）
function main() {
    //获取对应列表中的park_id值
    let parkId = this.params.park_id.value;
    //获取页面中详情部件
    let map = this.$$("page_detail_6yucro").$$getRenderElement();
    //为详情部件传参。这里的park_id为视图中的列名，不能自定义
    map.$$setExtraParams({ park_id: parkId })
    //刷新详情部件
    map.$$refreshData();

}
