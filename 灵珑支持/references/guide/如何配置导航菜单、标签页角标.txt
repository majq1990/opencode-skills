如何配置导航菜单、标签页角标
背景概述
以案卷 http://faq.egova.com.cn:7777/issues/349251 为背景，介绍如何配置导航菜单、标签页展示角标
如何配置
开启计数配置
在导航菜单、标签页展示角标，首先需要开启计数配置（默认关闭），每个导航菜单、标签页需要单独配置
导航配置部分，开启菜单计数配置，可设置计数样式、字体颜色、背景颜色
示例地址：http://10.250.1.39:30095/magic/linglong/workspace.html#/baeb2a1f-1758-4a95-b856-be8e098d65d9/nav
标签页部分
示例地址：http://10.250.1.39:30095/magic/linglong/workspace.html#/baeb2a1f-1758-4a95-b856-be8e098d65d9/page-build/page/1768522881070792704
配置角标数据源
开启计数配置后，还需要为角标配置角标数据源，灵珑平台提供内置方法，用于设置角标数据，配置人员需要在角标数据需要变化时，通过灵珑动作配置，在组件生命周期、组件动作中使用自定义方法更新角标数据源
内置方法说明
灵珑api接口：
PUBLISH_COUNTING_EVENT，主要用于更新导航菜单和标签页的角标显示
$$setTabCounting，主要用户更新标签页的角标显示，该方法为标签页组件提供的方法，需要先使用  $$element获取标签页组件
接口说明
PUBLISH_COUNTING_EVENT(
    self: 执行上下文,
    {
        type: "appMenu" | "tabs",
        counting: 以键值对设置对应值（key 为导航菜单编号、标签页显示标题）
    }
)
