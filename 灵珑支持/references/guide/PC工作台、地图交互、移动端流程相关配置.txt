1.地图轨迹播放
1.1pc端地图轨迹播放
1.步骤主要是给“地图”组件增加“轨迹图层”，添加触发轨迹图层的按钮或动作入口，添加动作脚本，打开表单时地图上就会显示轨迹位置和播放轨迹的工具栏。
在表单部件选中“地图”组件，在“图层”配置页点【增加图层】选择“轨迹图层”。
图层名称：根据需要修改，在列表里便于区分人员或车辆等；
图层启用：默认开启，图上显示轨迹工具栏；当关闭时图上不显示轨迹工具栏；
图层id：在触发轨迹图层的脚本里作为参数传入；
轨迹类型：人员轨迹和车辆轨迹，选中后分别可以选择人员或车辆的显示图标；
表单设计
图标样式：
（1）人员轨迹可选样式
（2）车辆轨迹可选样式
2.轨迹图层的属性配置。
轨迹宽度：值域范围[1-20]；
轨迹箭头：默认开启；
箭头间隔：默认50px，值域范围[1,50]；
可见层级：默认6，值域范围[1-19]；
显示轨迹的配置：
（1）第一种方式：地图组件“高级”增加“地图加载完成”动作，配置动作脚本
function main() {
    // 通过部件ID 获取地图组件：map_base_8qcsge 是当前页面的地图部件唯一标识
    // $$ 是平台内置方法，用于获取页面上的子组件/部件
    this.$$("map_base_8qcsge")
    
    // 调用地图部件的【显示本地轨迹】方法，用于在地图上绘制设备历史行驶轨迹
    .$$showLocalObjectTrace(
        // 第1个参数：轨迹图层ID
        "traceLayer_2redk9",
        
        // 第2个参数：查看轨迹的人员id
        100154,
        
        // 第3个参数：轨迹查询日期
        "2018-06-20",
        
        // 第4个参数：扩展筛选参数（当前为空，表示无额外条件）
        {},
        
        // 第5个参数：轨迹展示详细配置项（核心参数）
        {
            // 是否显示轨迹中断标记：false = 关闭，轨迹连续显示
            traceBreak: false,
            
            // 轨迹中断阈值：超过500（秒/米）判定为轨迹中断
            traceBreakThreshold: 500,
            
            // 是否显示轨迹热力图：false = 关闭，只显示普通轨迹线
            showHeatMap: false,
            
            // 是否显示无信号标签：true = 开启，设备无信号时地图显示标记
            nosignalLabel: true,
            
            // 请求类型：固定值1，平台内部定义的轨迹查询接口类型
            requestType: 1,
            
            // 轨迹开始时间：当天 08:00:00 开始查询
            startHour: "08:00:00",
            
            // 轨迹结束时间：当天 22:00:00 结束查询
            endHour: "22:00:00",
            
            // 是否显示轨迹详情/轨迹点：true = 开启
            tracedig: true
        }
    )
}
参数说明：
（2）第二种方式：在表单里增加【自定义按钮】点击时触发显示轨迹
function main() {
    this.$$("map_base_8qcsge").$$showLocalObjectTrace("traceLayer_2redk9", 100154, "2018-06-20", {}, {
        traceBreak: false,
        traceBreakThreshold: 500,
        showHeatMap: false,
        nosignalLabel: true,
        requestType: 1,
        startHour: "08:00:00",
        endHour: "22:00:00",
        tracedig: true
    })
}

3.3 配置表单公式
3.3.1 启动流程
公式：FLOW_START(流程表单id,文号)，根据该流程表单的ID，启动某文号对应某条数据的一个流程。
3.3.1 数据流转
公式：FLOW_BASE_ACTION_WITH_CONDITION(应用id,任务id,动作类型，动作意见, 操作的节点和人员信息,条件)
流程基础操作，比如批转，回退，加签，减签，同意 拒绝, 办结,作废 。 其中前三个参数不能为空，action对应值 [REDIRECT, RETURN, APPEND, REDUCE, AGREE, DISAGREE, FINISH,VERB]，
根据操作按钮的需求配置不同的动作类型
