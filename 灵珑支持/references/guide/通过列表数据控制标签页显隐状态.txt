通过列表数据控制标签页显隐状态
1 使用场景
列表详情或者点击按钮后跳转到一个新的页面，但是这个页面中有多个标签页，根据列表中的值判断标签页的显隐
具体的业务场景：列表中有一行的数据中包含一个是否完工的标识数据，根据这个是否完工的标识数据对目标页面中的月度进展填报标签页面进行显隐状态的控制。是否完工标识为已完成就隐藏月度进展填报这个标签页，不让用户进行月度进展填报的操作。是否完工标识为未完成就显示月度进展填报这个标签，让用户进行月度进展填报的操作。
2 效果
用户点击一条数据中的按钮或者详情链接，根据这条数据中的某个值对标签页进行显隐状态控制。（图中是根据是否完工这个标识对月度进展填报这个标签页进行显隐状态的控制）
3 配置
在按钮或者详情字段中传递需要判断的参数
（图中示例为给月度进展这个按钮的点击事件添加参数）
在目标页面的标签页中加载事件中添加如下脚本
function main(){
    const self = this;
    //获取传递过来的参数
    const finishFlag = (self.state.extraParams || {})["finish_flag"];
    // 已完成，则隐藏
    if(finishFlag == "是"){
    //这里需要自己通过F12查看页面中的元素进行替换。
    //#tabs_hfkhxz_csshandler_generate是页面中整个标签页的id值
    //.ant-tabs-tab:nth-child()为固定内容，括号里的数字代表第几个标签页
    //因为示例中月度进展上报标签页是第二个所以括号中填入2
        const tab = document.querySelector("#tabs_hfkhxz_csshandler_generate .ant-tabs-tab:nth-child(2)");
    //对获取到的标签页进行显隐控制，当display属性值为none时隐藏
        if(tab){
            tab.style.display = "none";
        }else{
          tab.style.display = "";
        }
    }
}
