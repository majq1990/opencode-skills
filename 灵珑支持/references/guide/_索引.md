# 灵珑低代码平台开发指南 (LingLong Low-Code Platform Guide)

## 概述

本 skill 是灵珑（LingLong）低代码平台的完整开发参考文档集，覆盖从基础到高级的全部配置场景。
灵珑是北京数字政通（EGOVA）旗下的低代码应用搭建平台，通过可视化配置 + JS 脚本 + 后端公式
的方式快速构建业务应用。

## 使用方式

当用户在灵珑平台上遇到配置问题或需要实现某个功能时：

1. 根据用户问题判断涉及的场景类别
2. 在 `references/` 目录中找到对应的参考文档
3. 读取文档内容，提取相关的配置步骤、脚本模板和注意事项
4. 结合文档提供准确的配置方案

## 常见开发流程

### 创建一个带查询的列表页面

1. 参考 `数据模型、高级检索.txt` 创建数据模型
2. 参考 `列表查询基于Hook查询.txt` 配置 Hook 查询脚本
3. 参考 `灵珑页面交互传参.txt` 配置页面间参数传递
4. 参考 `灵珑动作交互设计以及示例说明.txt` 配置操作列按钮动作

### 搭建一个数据看板

1. 参考 `基于页面的工作台配置.txt` 配置页面布局
2. 参考 `移动端领导看板配置示例.txt` 编写数据刷新脚本
3. 参考 `灵珑动作交互&js脚本示例模板.txt` 获取接口调用模板

### 调试一个 JS 脚本问题

1. 参考 `灵珑脚本调试方法.txt` 了解调试工具和方法
2. 在脚本中使用 `debugger` 关键字或 `console.log` 打印日志
3. 使用 F12 开发者工具查看变量状态和调用栈
